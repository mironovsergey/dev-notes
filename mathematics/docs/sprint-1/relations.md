# Отношения и функции

[← К содержанию спринта](README.md)

Отношение - это подмножество декартова произведения, и больше ничего. Из этого
скупого определения вырастают два инструмента, которыми пользуются постоянно:
эквивалентность, разбивающая множество на классы, и порядок, позволяющий
элементы сравнивать. Функция оказывается частным случаем отношения.

---

## 1.3 Отношения и функции

### 1.3.1 Бинарное отношение и способы задания

**Бинарное отношение** между `A` и `B` - произвольное подмножество
`R ⊆ A × B`. Отношение **на множестве** `A` - подмножество `A × A`. Вместо
`(a, b) ∈ R` пишут `a R b`.

Определение намеренно бедное: никаких требований к `R` не предъявляется.
Содержательными отношения становятся, когда на них накладывают свойства из
[1.3.2](#132-свойства-отношений).

Четыре способа задать отношение на конечном множестве:

| Способ | Пример для `A = {1, 2, 3}`, `R` = «меньше» |
| --- | --- |
| Перечисление пар | `{(1,2), (1,3), (2,3)}` |
| Условие | `a R b ⟺ a < b` |
| Матрица | см. ниже |
| Ориентированный граф | ребро `a → b` для каждой пары |

```
   Матрица отношения           Граф отношения

        1  2  3
     1  0  1  1                  1 ──→ 2
     2  0  0  1                  │     │
     3  0  0  0                  └──→ 3 ←┘
```

Последние два способа - одно и то же: **отношение на конечном множестве и
есть ориентированный граф**, а матрица отношения совпадает с
[матрицей смежности](../../../algorithms/docs/sprint-6/representation.md). Поэтому
вопросы об отношениях сводятся к вопросам о графах: транзитивное замыкание -
это достижимость, разбиение на классы эквивалентности - это компоненты
связности.

### 1.3.2 Свойства отношений

| Свойство | Определение | Как видно в матрице |
| --- | --- | --- |
| Рефлексивность | `∀a: a R a` | вся диагональ из единиц |
| Антирефлексивность | `∀a: ¬(a R a)` | вся диагональ из нулей |
| Симметричность | `∀a,b: a R b → b R a` | матрица симметрична |
| Антисимметричность | `∀a,b: a R b ∧ b R a → a = b` | нет пары единиц, симметричной относительно диагонали |
| Транзитивность | `∀a,b,c: a R b ∧ b R c → a R c` | из `a` достижимо `c` за два шага, значит есть и прямое ребро |

Примеры на числах:

| Отношение | Рефл. | Симм. | Антисимм. | Транз. |
| --- | --- | --- | --- | --- |
| `a = b` | да | да | да | да |
| `a ≤ b` | да | нет | да | да |
| `a < b` | нет | нет | да | да |
| `a` делится на `b` | да | нет | да | да |
| `a ≡ b (mod m)` | да | да | нет | да |
| `a ≠ b` | нет | да | нет | нет |

Строка равенства показывает, что **антисимметричность не есть отрицание
симметричности**: равенство обладает обоими свойствами сразу. Симметричность
требует, чтобы обратная пара всегда существовала; антисимметричность - чтобы
обратная пара встречалась только на диагонали. Совместимы они ровно на
подмножествах диагонали.

### 1.3.3 Отношение эквивалентности и разбиение

**Отношение эквивалентности** - рефлексивное, симметричное и транзитивное
отношение. Обозначается обычно `~`.

**Классом эквивалентности** элемента `a` называется множество
`[a] = {x ∈ A │ x ~ a}`.

**Теорема.** Классы эквивалентности образуют разбиение `A`: они непусты,
попарно не пересекаются и в объединении дают `A`. Обратно, всякое разбиение
задает отношение эквивалентности («лежать в одной части»).

Доказательство непересечения показательно, потому что использует все три
свойства. Пусть `[a] ∩ [b] ≠ ∅`, и `c` лежит в обоих классах. Тогда `c ~ a` и
`c ~ b`. По симметричности `a ~ c`, по транзитивности `a ~ b`. Отсюда любой
`x ~ a` даст `x ~ b`, то есть `[a] ⊆ [b]`, и симметричным рассуждением
`[b] ⊆ [a]`. Значит, пересекающиеся классы совпадают. Рефлексивность нужна
отдельно - она гарантирует `a ∈ [a]`, то есть непустоту классов и покрытие
всего `A`.

Множество классов называется **фактормножеством** `A / ~`.

Три примера, к которым конспект возвращается:

- **Сравнение по модулю `m`.** Классы - остатки `0, 1, ..., m − 1`; их ровно
  `m`. Это основа [арифметики по модулю](number-theory.md#174-арифметика-по-модулю-и-сравнения).
- **Компоненты связности графа.** Отношение «существует путь из `a` в `b`» -
  эквивалентность, классы - компоненты.
- **Система непересекающихся множеств.** Структура данных
  [DSU](../../../algorithms/docs/sprint-6/mst.md#система-непересекающихся-множеств)
  поддерживает ровно классы эквивалентности при постепенном добавлении пар:
  `union` объединяет два класса, `find` возвращает представителя класса.

### 1.3.4 Отношение порядка, ЧУМ, диаграмма Хассе

**Частичный порядок** - рефлексивное, антисимметричное и транзитивное
отношение; обозначается `≼`. Пара `(A, ≼)` называется **частично упорядоченным
множеством** (ЧУМ).

Слово «частичный» означает, что не всякие два элемента сравнимы. Если сравнимы
любые два, порядок называется **линейным** (полным).

| Пример | Линейный? |
| --- | --- |
| `≤` на `ℝ` | да |
| Делимость на `ℕ` | нет: 2 и 3 несравнимы |
| `⊆` на булеане | нет: `{a}` и `{b}` несравнимы |
| Лексикографический порядок строк | да |

**Диаграмма Хассе** изображает ЧУМ без избыточных ребер: рисуются только
непосредственные покрытия, ребра, следующие из транзитивности и
рефлексивности, опускаются, а направление задается расположением снизу вверх.

```
   Делимость на {1, 2, 3, 4, 6, 12}

   вправо - умножение на 2, вниз - умножение на 3

           2⁰      2¹      2²

    3⁰      1 ───── 2 ───── 4
            │       │       │
    3¹      3 ───── 6 ───── 12
```

Ребра `1 - 4` или `2 - 12` не рисуются: они восстанавливаются по
транзитивности. Ребро `1 - 12` тоже отсутствует, хотя 1 делит 12: покрытием
называется только непосредственное отношение, без промежуточных элементов.

**Минимальный и наименьший - разные понятия.** Элемент `m` **минимален**, если
ниже него нет ничего сравнимого; `m` **наименьший**, если он не больше любого
элемента. В ЧУМ подмножеств `{{a}, {b}}` оба элемента минимальны, а
наименьшего нет вовсе. В линейном порядке понятия совпадают.

**Линейное продолжение и топологическая сортировка.** Всякий конечный
частичный порядок можно доопределить до линейного, не нарушив имеющихся
сравнений. Алгоритмически это и есть
[топологическая сортировка](../../../algorithms/docs/sprint-6/dfs.md#634-топологическая-сортировка):
строгий частичный порядок на конечном множестве - в точности ациклический
ориентированный граф, а порядок обхода дает искомое продолжение. Отсюда же
следует, почему сортировка невозможна при наличии цикла: цикл нарушает
антисимметричность.

### 1.3.5 Функция как отношение

**Функция** `f: A → B` - отношение `f ⊆ A × B`, в котором каждому `a ∈ A`
соответствует ровно один `b ∈ B`. Слово «ровно» содержит два требования:
соответствие есть (**всюду определена**) и оно единственно (**однозначна**).

| Вид | Определение | Смысл |
| --- | --- | --- |
| Инъекция | `f(x) = f(y) → x = y` | разные аргументы дают разные значения |
| Сюръекция | `∀b ∈ B ∃a: f(a) = b` | образ покрывает все `B` |
| Биекция | инъекция и сюръекция | взаимно однозначное соответствие |

```
   инъекция              сюръекция             биекция
   не сюръекция          не инъекция

   a ──→ 1               a ──┐                 a ──→ 1
   b ──→ 2               b ──┴→ 1              b ──→ 2
         3               c ──→ 2               c ──→ 3
```

Подсчет функций при `|A| = m`, `|B| = n` - первое применение комбинаторных
правил:

| Что считается | Количество |
| --- | --- |
| Всех функций `A → B` | `nᵐ` |
| Инъекций | `n · (n − 1) · ... · (n − m + 1)` |
| Биекций (при `m = n`) | `n!` |

Первая формула - правило произведения: значение выбирается независимо для
каждого из `m` аргументов. Вторая - то же самое, но каждое следующее значение
берется из сузившегося запаса.

Отсюда сразу следует **принцип Дирихле**: при `m > n` произведение
`n · (n − 1) · ... · (n − m + 1)` содержит нулевой множитель, то есть инъекций
не существует и какие-то два аргумента обязаны получить одно значение.
Комбинаторная сторона разбирается в спринте 2, а прямое следствие для
программиста - неизбежность коллизий хеш-функции.

Биекция - это то самое соответствие, через которое в
[1.2.4](sets.md#124-мощность-множества-счетность-диагональный-метод) определяется
равномощность.

### 1.3.6 Композиция и обратная функция

**Композиция** `g ∘ f` определяется как `(g ∘ f)(x) = g(f(x))`; она требует,
чтобы область значений `f` лежала в области определения `g`.

Композиция **ассоциативна**: `(h ∘ g) ∘ f = h ∘ (g ∘ f)` - обе части при любом
`x` разворачиваются в `h(g(f(x)))`. **Коммутативной она не является**: для
`f(x) = x + 1` и `g(x) = 2x` получаем `g(f(1)) = 4`, но `f(g(1)) = 3`.

Свойства наследуются: композиция инъекций - инъекция, композиция сюръекций -
сюръекция, композиция биекций - биекция.

**Обратная функция** `f⁻¹` существует тогда и только тогда, когда `f` -
биекция. Условие необходимо с обеих сторон: без инъективности `f⁻¹` не была бы
однозначна, без сюръективности - не была бы всюду определена. Выполняются
`f⁻¹ ∘ f = id_A` и `f ∘ f⁻¹ = id_B`.

Композиция определена и для произвольных отношений: `a (S ∘ R) c`, если
найдется `b` с `a R b` и `b S c`. В матричной записи это булево умножение
матриц, а `n`-я степень матрицы отношения показывает достижимость за `n`
шагов.

### Типичные ошибки

1. **Антисимметричность понимается как отсутствие симметричности.** Равенство
   симметрично и антисимметрично одновременно.
2. **Рефлексивность выводится из симметричности и транзитивности.**
   Рассуждение «`a R b`, по симметричности `b R a`, по транзитивности `a R a`»
   выглядит убедительно, но молча предполагает, что у `a` вообще есть пара.
   Контрпример: `A = {1, 2}`, `R = {(1, 1)}` симметрично и транзитивно, однако
   `2 R 2` не выполняется. Пустое отношение - тот же случай.
3. **Минимальный элемент считается наименьшим.** Минимальных может быть
   несколько, наименьший, если существует, единствен.
4. **Сюръективность проверяется без указания `B`.** Одна и та же формула
   `f(x) = x²` сюръективна как функция `ℝ → [0, +∞)` и не сюръективна как
   `ℝ → ℝ`. Область значений - часть определения функции.
5. **Обратная функция строится для инъекции.** Инъективности достаточно лишь
   для обратимости на образе; для `f⁻¹: B → A` нужна биекция.
