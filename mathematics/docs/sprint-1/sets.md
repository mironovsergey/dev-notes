# Теория множеств

[← К содержанию спринта](README.md)

Множество - базовый строительный материал: через него определяются отношения,
функции, графы и вероятностные пространства. Раздел короткий, потому что почти
все его законы повторяют законы логики из [1.1.2](logic.md#112-таблицы-истинности-тавтологии-равносильности),
и это совпадение здесь объяснено.

---

## 1.2 Теория множеств

### 1.2.1 Множество, подмножество, способы задания

**Множество** - совокупность различимых объектов, рассматриваемая как единое
целое. Объекты называются **элементами**; запись `x ∈ A` означает, что `x`
принадлежит `A`, запись `x ∉ A` - что не принадлежит.

Множество определяется **только составом элементов**: ни порядок, ни
повторения не учитываются.

```
   {1, 2, 3} = {3, 2, 1} = {1, 2, 2, 3}
```

Три способа задать множество:

| Способ | Пример | Когда удобен |
| --- | --- | --- |
| Перечисление | `A = {2, 3, 5, 7}` | множество конечное и небольшое |
| Характеристическое свойство | `A = {x ∈ ℕ │ x < 10 и x простое}` | элементы описываются условием |
| Порождение | `0 ∈ A`; если `n ∈ A`, то `n + 2 ∈ A` | множество строится рекурсивно |

Третий способ - основа [структурной индукции](induction.md#143-структурная-индукция-и-связь-с-рекурсией):
множество задается базой и правилом порождения, и доказательства о нем ведутся
по той же схеме.

Стандартные обозначения: `∅` - пустое множество, `U` - универсум (множество
всех рассматриваемых объектов), `ℕ`, `ℤ`, `ℚ`, `ℝ` - натуральные, целые,
рациональные и вещественные числа.

**Подмножество.** `A ⊆ B`, если каждый элемент `A` принадлежит `B`:

```
   A ⊆ B   ≡   ∀x (x ∈ A → x ∈ B)
```

Отсюда сразу два часто забываемых факта: `∅ ⊆ A` при любом `A` (импликация
истинна, потому что посылка ложна - см. [пустую область](logic.md#113-предикаты-и-кванторы)),
и `A ⊆ A`. Запись `A ⊂ B` означает строгое включение: `A ⊆ B` и `A ≠ B`.

**Как доказывают равенство множеств.** Основной прием - двойное включение:

```
   A = B   ⟺   A ⊆ B  и  B ⊆ A
```

Он применяется почти всегда, потому что сводит равенство к двум импликациям,
каждая из которых доказывается прямо: берем произвольный элемент одной
стороны и показываем, что он лежит в другой.

**Ограничение наивного подхода.** Задавать множество произвольным свойством
нельзя: множество `R = {x │ x ∉ x}` приводит к противоречию, так как вопрос
`R ∈ R` не имеет непротиворечивого ответа (парадокс Рассела). В аксиоматике
свойством выделяют подмножество уже существующего множества, а не строят
множество «всех объектов со свойством». Для практики достаточно помнить, что
универсум `U` всегда фиксируется заранее.

### 1.2.2 Операции и законы алгебры множеств

| Операция | Запись | Определение |
| --- | --- | --- |
| Объединение | `A ∪ B` | `{x │ x ∈ A ∨ x ∈ B}` |
| Пересечение | `A ∩ B` | `{x │ x ∈ A ∧ x ∈ B}` |
| Разность | `A \ B` | `{x │ x ∈ A ∧ x ∉ B}` |
| Симметрическая разность | `A △ B` | `{x │ x ∈ A ⊕ x ∈ B}` |
| Дополнение | `Ā` | `{x ∈ U │ x ∉ A}` |

```
        A ∪ B                A ∩ B                A \ B               A △ B
    ┌───────┬───────┐    ┌───────┬───────┐    ┌───────┬───────┐   ┌───────┬───────┐
    │###┌───┼───┐###│    │   ┌───┼───┐   │    │###┌───┼───┐   │   │###┌───┼───┐###│
    │###│###│###│###│    │   │###│   │   │    │###│   │   │   │   │###│   │   │###│
    │###└───┼───┘###│    │   └───┼───┘   │    │###└───┼───┘   │   │###└───┼───┘###│
    └───────┴───────┘    └───────┴───────┘    └───────┴───────┘   └───────┴───────┘
```

**Почему законы множеств повторяют законы логики.** Каждая операция определена
через связку: `x ∈ A ∪ B` равносильно `x ∈ A ∨ x ∈ B`. Поэтому любое
тождество для множеств получается из соответствующей равносильности
подстановкой `∪ ↔ ∨`, `∩ ↔ ∧`, `дополнение ↔ ¬`. Учить второй список не нужно
- достаточно знать первый и правило перевода.

| Закон | Запись |
| --- | --- |
| Коммутативность | `A ∪ B = B ∪ A`, `A ∩ B = B ∩ A` |
| Ассоциативность | `(A ∪ B) ∪ C = A ∪ (B ∪ C)` |
| Дистрибутивность | `A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)` |
| Идемпотентность | `A ∪ A = A`, `A ∩ A = A` |
| Поглощение | `A ∪ (A ∩ B) = A` |
| Законы де Моргана | `‾A ∪ B‾ = Ā ∩ B̄`, `‾A ∩ B‾ = Ā ∪ B̄` |
| Дополнение | `A ∪ Ā = U`, `A ∩ Ā = ∅` |
| Разность через дополнение | `A \ B = A ∩ B̄` |

**Мощность объединения.** Для конечных множеств

```
   |A ∪ B| = |A| + |B| − |A ∩ B|
```

Вычитание необходимо: элементы пересечения при простом сложении учитываются
дважды. Обобщение на любое число множеств - принцип включений-исключений,
разбираемый в комбинаторике.

### 1.2.3 Декартово произведение и булеан

**Декартово произведение** `A × B` - множество всех упорядоченных пар, где
первый элемент взят из `A`, второй из `B`:

```
   A × B = {(a, b) │ a ∈ A, b ∈ B}
   |A × B| = |A| · |B|
```

В отличие от самих множеств, пара **упорядочена**: `(1, 2) ≠ (2, 1)`. Отсюда и
некоммутативность: `A × B ≠ B × A` при `A ≠ B`.

Степень `Aⁿ = A × ... × A` дает множество кортежей длины `n`. Через декартово
произведение определяются [отношения](relations.md#131-бинарное-отношение-и-способы-задания):
бинарное отношение - это подмножество `A × B`, и не более того.

**Булеан** `P(A)` - множество всех подмножеств `A`, включая `∅` и само `A`.

```
   A = {a, b, c}

   P(A) = { ∅, {a}, {b}, {c}, {a,b}, {a,c}, {b,c}, {a,b,c} }
```

```
   |P(A)| = 2^|A|
```

Доказательство короткое и полезное само по себе: подмножество однозначно
задается ответом «взят или не взят» на каждый из `n` элементов, то есть
двоичным вектором длины `n`. Векторов ровно `2ⁿ`, и соответствие между
векторами и подмножествами взаимно однозначно.

```
   маска │ 000  001  010  011  100  101  110  111
   ──────┼────────────────────────────────────────
   набор │  ∅   {a}  {b}  {a,b} {c} {a,c} {b,c} {a,b,c}
```

Это же соответствие используется в коде: перебор всех подмножеств пишется как
цикл по маске от `0` до `2ⁿ − 1`, где `i`-й бит означает наличие `i`-го
элемента. Отсюда и оценка `O(2ⁿ)` у [полного перебора подмножеств](../../../algorithms/docs/sprint-1/complexity.md).

### 1.2.4 Мощность множества, счетность, диагональный метод

Для конечного множества **мощность** `|A|` - число элементов. Чтобы говорить о
размере бесконечных множеств, определение переносят на язык соответствий:
множества `A` и `B` **равномощны**, если между ними существует
[биекция](relations.md#135-функция-как-отношение).

Определение выглядит формальным, но именно оно фиксирует то, что делают при
счете: пересчитать множество - значит установить биекцию с отрезком
натурального ряда.

**Счетное множество** - равномощное `ℕ`, то есть такое, элементы которого
можно занумеровать натуральными числами.

Счетно `ℤ`, хотя целых чисел «вдвое больше», чем натуральных:

```
   n    │ 0   1   2   3   4   5   6
   ─────┼────────────────────────────
   f(n) │ 0   1  −1   2  −2   3  −3
```

Счетно и `ℚ`: пары `(числитель, знаменатель)` обходятся по диагоналям, дроби с
повторяющимся значением пропускаются. Тот же обход применим к любому `A × B`
счетных `A` и `B`, а также к объединению счетного числа счетных множеств.

**`ℝ` несчетно.** Доказательство от противного - диагональный метод Кантора.
Пусть все вещественные числа отрезка `[0, 1]` занумерованы:

```
   x₁ = 0. a₁₁ a₁₂ a₁₃ ...
   x₂ = 0. a₂₁ a₂₂ a₂₃ ...
   x₃ = 0. a₃₁ a₃₂ a₃₃ ...
              ↘
```

Построим число `y = 0.b₁b₂b₃...`, где `bₖ` отличается от `aₖₖ` (например,
`bₖ = 1`, если `aₖₖ ≠ 1`, и `bₖ = 2` иначе; цифры 0 и 9 не используются, чтобы
избежать записей вида `0.4999... = 0.5`). Тогда `y` отличается от `xₖ` в `k`-м
знаке при каждом `k`, то есть не входит в нумерацию. Противоречие: нумерация
не может быть полной.

Тот же прием доказывает **теорему Кантора**: `|P(A)| > |A|` для любого `A`,
включая бесконечные. Бесконечности образуют строго возрастающую шкалу, а не
одну «бесконечность».

**Зачем это программисту.** Программа - конечная строка в конечном алфавите,
поэтому множество всех программ счетно. Множество функций `ℕ → {0, 1}`
равномощно `P(ℕ)` и потому несчетно. Счетное множество не может покрыть
несчетное, следовательно, **существуют функции, которые не вычисляет никакая
программа**, - и это установлено до всякого разговора о конкретных алгоритмах.

### Типичные ошибки

1. **`∈` подменяется на `⊆`.** Для `A = {1, 2}` верно `1 ∈ A` и `{1} ⊆ A`, но
   неверно `{1} ∈ A` и `1 ⊆ A`. Первое - об элементе, второе - о множестве.
2. **`∅` и `{∅}` считаются одним и тем же.** Первое пусто, второе содержит
   ровно один элемент: `|∅| = 0`, `|{∅}| = 1`.
3. **Разность считается симметричной.** `A \ B` и `B \ A` в общем случае
   различны; симметричная операция - это `A △ B`.
4. **Мощность объединения складывается без вычитания.** Формула
   `|A ∪ B| = |A| + |B|` верна только для непересекающихся множеств.
5. **Все бесконечности считаются одинаковыми.** `ℚ` счетно, `ℝ` нет, и разница
   между ними содержательна.
