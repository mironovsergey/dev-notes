# 1 Дискретная математика

Конспект первого раздела: язык, на котором записаны остальные три. Логика и
множества дают запись утверждений, отношения - способ структурировать
множество, индукция - способ доказывать, рекуррентные соотношения и теория
чисел - два инструмента, применяемых в анализе алгоритмов напрямую.

## Что вынесено за пределы раздела

Асимптотическая сложность и O-нотация разобраны в направлении алгоритмов
([complexity.md](../../../algorithms/docs/sprint-1/complexity.md)) и здесь не
дублируются. Из этой темы в раздел взята только основная теорема о
рекуррентных соотношениях - ее в конспекте алгоритмов нет.
