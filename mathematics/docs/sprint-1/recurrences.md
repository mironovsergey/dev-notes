# Рекуррентные соотношения

[← К содержанию спринта](README.md)

Рекуррентное соотношение задает член последовательности через предыдущие.
Для программиста это основной способ записать стоимость рекурсивного
алгоритма, а решение соотношения - способ превратить эту запись в
асимптотическую оценку.

---

## 1.6 Рекуррентные соотношения

### 1.6.1 Определение, примеры, начальные условия

**Рекуррентное соотношение порядка `k`** - равенство, выражающее `aₙ` через
`k` предыдущих членов последовательности. **Начальные условия** - значения
первых `k` членов.

Начальные условия - часть определения, а не формальность: одно и то же
соотношение при разных началах задает разные последовательности.

```
   Fₙ = Fₙ₋₁ + Fₙ₋₂

   F₀ = 0, F₁ = 1  →  0, 1, 1, 2,  3,  5,  8, 13, ...   числа Фибоначчи
   F₀ = 2, F₁ = 1  →  2, 1, 3, 4,  7, 11, 18, 29, ...   числа Люка
```

| Соотношение | Последовательность | Откуда берется |
| --- | --- | --- |
| `aₙ = aₙ₋₁ + d` | арифметическая прогрессия | добавление постоянной величины |
| `aₙ = q · aₙ₋₁` | геометрическая прогрессия | умножение на постоянный множитель |
| `Fₙ = Fₙ₋₁ + Fₙ₋₂` | числа Фибоначчи | два независимых предыдущих состояния |
| `Hₙ = 2Hₙ₋₁ + 1` | ханойские башни | задача сводится к двум копиям меньшего размера |
| `T(n) = 2T(n/2) + n` | сортировка слиянием | разбиение пополам плюс линейное слияние |

**Решить соотношение** - получить замкнутую формулу, в которой `aₙ` выражено
через `n` без обращения к предыдущим членам. Это дает не столько скорость
вычисления, сколько **видимую асимптотику**: из `Hₙ = 2Hₙ₋₁ + 1` рост не
очевиден, из `Hₙ = 2ⁿ − 1` очевиден.

Соотношения делятся на два класса, и решаются они разными приемами:

- **по вычитанию** - аргумент уменьшается на константу (`aₙ₋₁`, `aₙ₋₂`);
  решаются характеристическим уравнением ([1.6.2](#162-линейные-однородные-соотношения));
- **по делению** - аргумент делится на константу (`T(n/2)`); решаются деревом
  рекурсии и основной теоремой ([1.6.5](#165-дерево-рекурсии-и-метод-подстановки),
  [1.6.6](#166-основная-теорема)).

### 1.6.2 Линейные однородные соотношения

**Линейное однородное соотношение с постоянными коэффициентами**:

```
   aₙ = c₁·aₙ₋₁ + c₂·aₙ₋₂ + ... + c_k·aₙ₋ₖ
```

Слово «линейное» означает, что члены входят в первой степени и без
произведений, «однородное» - что свободного члена нет.

Метод решения основан на подстановке `aₙ = xⁿ`. После деления на `xⁿ⁻ᵏ`
получается **характеристическое уравнение**:

```
   xᵏ = c₁·xᵏ⁻¹ + c₂·xᵏ⁻² + ... + c_k
```

Если `r` - его корень, то `rⁿ` удовлетворяет соотношению. Соотношение
линейно, поэтому любая линейная комбинация решений тоже решение, - и этого
достаточно, чтобы описать все решения.

**Различные корни.** При `k` различных корнях `r₁, ..., r_k`

```
   aₙ = α₁·r₁ⁿ + α₂·r₂ⁿ + ... + α_k·r_kⁿ
```

Коэффициенты `αᵢ` находятся из начальных условий - получается система из `k`
линейных уравнений.

Пример: `aₙ = 5aₙ₋₁ − 6aₙ₋₂`, `a₀ = 1`, `a₁ = 4`.

```
   x² = 5x − 6   →   x² − 5x + 6 = 0   →   r₁ = 2, r₂ = 3

   aₙ = α·2ⁿ + β·3ⁿ

   n = 0:   α + β = 1
   n = 1:  2α + 3β = 4      →   β = 2, α = −1

   aₙ = 2·3ⁿ − 2ⁿ
```

**Кратные корни.** Корень `r` кратности `m` дает не одно решение, а `m`:
`rⁿ, n·rⁿ, ..., nᵐ⁻¹·rⁿ`. Без этого правила решений не хватило бы, чтобы
удовлетворить всем начальным условиям.

Пример: `aₙ = 4aₙ₋₁ − 4aₙ₋₂`, `a₀ = 1`, `a₁ = 4`.

```
   x² − 4x + 4 = 0   →   r = 2 кратности 2

   aₙ = (α + βn)·2ⁿ

   n = 0:  α = 1
   n = 1:  (1 + β)·2 = 4   →   β = 1

   aₙ = (n + 1)·2ⁿ
```

### 1.6.3 Формула Бине

Числа Фибоначчи - линейное однородное соотношение второго порядка, и общий
метод дает для них замкнутую формулу.

```
   x² = x + 1   →   x² − x − 1 = 0

   φ = (1 + √5)/2 ≈ 1.6180339887      ψ = (1 − √5)/2 ≈ −0.6180339887
```

Из `F₀ = 0` и `F₁ = 1` получается **формула Бине**:

```
   Fₙ = (φⁿ − ψⁿ) / √5
```

Формула замечательна тем, что выражает целые числа через иррациональные:
слагаемые по отдельности иррациональны, разность всегда целая.

Так как `|ψ| ≈ 0.618 < 1`, величина `ψⁿ` быстро стремится к нулю, и при
`n ≥ 0` выполняется

```
   Fₙ = round(φⁿ / √5)
```

Отсюда же асимптотика `Fₙ ~ φⁿ/√5`: числа Фибоначчи растут экспоненциально с
основанием `φ`. Это и объясняет, почему наивное рекурсивное вычисление
`fib(n)` требует примерно `Fₙ` вызовов и потому непригодно - разбор в
[динамическом программировании](../../../algorithms/docs/sprint-7/dynamic.md).

**Ограничение точности.** В арифметике `double` формула Бине дает верный
результат до `n = 70`; при `n = 71` округленное значение отличается от
истинного `F₇₁ = 308 061 521 170 129`. Граница найдена перебором и
зафиксирована в проверочном скрипте: для точных вычислений формула Бине
непригодна, нужен итеративный подсчет или `BigInt`.

### 1.6.4 Неоднородные соотношения

**Неоднородное соотношение** содержит слагаемое, не зависящее от предыдущих
членов:

```
   aₙ = c₁·aₙ₋₁ + ... + c_k·aₙ₋ₖ + f(n)
```

Общее решение складывается из двух частей:

```
   общее решение   =   общее решение   +   любое частное решение
   неоднородного       однородного         неоднородного
```

Частное решение подбирается по виду `f(n)`:

| Вид `f(n)` | Форма частного решения |
| --- | --- |
| Многочлен степени `d` | многочлен степени `d` |
| `b · sⁿ` | `C · sⁿ` |
| `s` совпадает с корнем характеристического уравнения кратности `m` | предыдущую форму умножить на `nᵐ` |

**Пример: ханойские башни.** Перенос `n` дисков сводится к переносу `n − 1`
дисков, перемещению самого большого и повторному переносу `n − 1`:

```
   Hₙ = 2Hₙ₋₁ + 1,   H₁ = 1
```

Однородная часть: `x = 2`, решение `C·2ⁿ`. Правая часть постоянна, единица не
является корнем, поэтому частное решение ищется в виде константы `A`:

```
   A = 2A + 1   →   A = −1
```

Складываем и подставляем начальное условие:

```
   Hₙ = C·2ⁿ − 1,    H₁ = 2C − 1 = 1   →   C = 1

   Hₙ = 2ⁿ − 1
```

### 1.6.5 Дерево рекурсии и метод подстановки

Для соотношений вида `T(n) = a·T(n/b) + f(n)` характеристическое уравнение
неприменимо: аргумент делится, а не уменьшается на константу. Работает подсчет
по уровням дерева вызовов.

```
   T(n) = 2T(n/2) + n

   уровень 0            n                     вклад: n
                      /   \
   уровень 1       n/2     n/2                вклад: 2 · n/2 = n
                  /  \     /  \
   уровень 2   n/4  n/4  n/4  n/4             вклад: 4 · n/4 = n
                        ...
   уровень log₂n    1  1  ...  1              вклад: n
```

Каждый уровень стоит `n`, уровней `log₂ n + 1`, поэтому `T(n) = Θ(n log n)` -
оценка сортировки слиянием.

Если изменить внешнюю работу, картина меняется качественно:

| Соотношение | Вклад уровня `i` | Сумма | Итог |
| --- | --- | --- | --- |
| `T(n) = 2T(n/2) + n` | `n` | одинаковые слагаемые | `Θ(n log n)` |
| `T(n) = 2T(n/2) + n²` | `n²/2ⁱ` | убывающая геометрическая | `Θ(n²)` |
| `T(n) = 4T(n/2) + n` | `2ⁱ·n` | растущая геометрическая | `Θ(n²)` |

В первом случае вклад распределен по всем уровням, во втором сосредоточен в
корне, в третьем - в листьях. Основная теорема ([1.6.6](#166-основная-теорема))
формализует именно это разделение на три случая.

**Метод подстановки** - угадать ответ и доказать его индукцией. Здесь есть
ловушка, на которой ошибаются регулярно.

Попробуем доказать неверное утверждение `T(n) = O(n)` для `T(n) = 2T(n/2) + n`,
то есть найти `c` с `T(n) ≤ c·n`. Предположение для `n/2` дает

```
   T(n) ≤ 2 · c·(n/2) + n = c·n + n
```

Получено `c·n + n`, а требовалось `c·n`. Разница в одно слагаемое `n`, и
никакой выбор `c` ее не устраняет - переход не проходит, потому что
утверждение ложно. Ошибка возникает, когда лишнее слагаемое объявляют
поглощенным `O`-нотацией: индукция ведется по точному неравенству с
конкретной константой, и `O` внутри перехода использовать нельзя.

Тот же прием работает и в обратную сторону: если переход не сходится на
константу, иногда помогает **усилить** предположение, доказывая
`T(n) ≤ c·n − d` вместо `T(n) ≤ c·n`, - вычитаемое дает запас, за счет
которого неравенство замыкается (см. [1.4.4](induction.md#144-типичные-ошибки)).

### 1.6.6 Основная теорема

**Основная теорема о рекуррентных соотношениях** решает соотношения вида

```
   T(n) = a·T(n/b) + f(n),   a ≥ 1,  b > 1
```

Сравнивается внешняя работа `f(n)` с величиной `n^(log_b a)` - суммарной
стоимостью листьев дерева рекурсии.

| Случай | Условие | Ответ | Где сосредоточена работа |
| --- | --- | --- | --- |
| 1 | `f(n) = O(n^(log_b a − ε))` | `T(n) = Θ(n^(log_b a))` | в листьях |
| 2 | `f(n) = Θ(n^(log_b a))` | `T(n) = Θ(n^(log_b a) · log n)` | равномерно по уровням |
| 3 | `f(n) = Ω(n^(log_b a + ε))` и `a·f(n/b) ≤ c·f(n)` при `c < 1` | `T(n) = Θ(f(n))` | в корне |

Дополнительное условие в третьем случае (**условие регулярности**) требует,
чтобы работа убывала при спуске по дереву достаточно быстро; без него сумма
по уровням не обязана определяться корнем.

| Алгоритм | Соотношение | `log_b a` | Случай | Оценка |
| --- | --- | --- | --- | --- |
| Бинарный поиск | `T(n) = T(n/2) + O(1)` | `0` | 2 | `Θ(log n)` |
| Обход дерева | `T(n) = 2T(n/2) + O(1)` | `1` | 1 | `Θ(n)` |
| Сортировка слиянием | `T(n) = 2T(n/2) + Θ(n)` | `1` | 2 | `Θ(n log n)` |
| Умножение Карацубы | `T(n) = 3T(n/2) + Θ(n)` | `log₂3 ≈ 1.585` | 1 | `Θ(n^1.585)` |
| Умножение матриц по Штрассену | `T(n) = 7T(n/2) + Θ(n²)` | `log₂7 ≈ 2.807` | 1 | `Θ(n^2.807)` |

**Когда теорема неприменима.** Три случая не покрывают всех возможностей:
между ними есть зазоры. Для `T(n) = 2T(n/2) + n log n` имеем
`n^(log_b a) = n`, и `f(n) = n log n` растет быстрее `n`, но не быстрее
`n^(1+ε)` ни при каком `ε > 0`. Ни один случай не подходит; подсчет по
уровням дает `Θ(n log² n)`. Теорема не работает также при переменном `a`,
при `f(n)`, не являющемся многочленом, и при неравных размерах подзадач.

Все оценки таблицы согласуются с разбором соответствующих алгоритмов в
[конспекте по сложности](../../../algorithms/docs/sprint-1/complexity.md).
