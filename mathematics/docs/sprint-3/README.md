# 3 Теория графов

Конспект третьего раздела. Изложена **теоретическая** сторона: определения,
критерии, доказательства. Реализации обходов, кратчайших путей и остовных
деревьев разобраны с кодом в
[направлении алгоритмов](../../../algorithms/docs/sprint-6/README.md) и здесь
не пересказываются - на них стоят ссылки. Освободившееся место отдано темам,
которых там нет: деревьям как классу графов, мостам и компонентам сильной
связности, паросочетаниям, потокам, планарности и раскраске.
