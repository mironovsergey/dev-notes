# Потоки в сетях

[← К содержанию спринта](README.md)

Задача о максимальном потоке - одна из немногих, к которым сводится
неожиданно много других: паросочетания, разрезы, расписания, задачи о
назначениях с ограничениями. Центральный результат - равенство максимума
потока и минимума разреза, из которого теоремы Менгера и Кенига получаются как
частные случаи.

---

## 3.8 Потоки в сетях

### 3.8.1 Сеть, поток, разрез

**Сеть** - ориентированный граф с неотрицательной **пропускной способностью**
`c(u, v)` на каждой дуге и двумя выделенными вершинами: **источником** `s` и
**стоком** `t`.

**Поток** - функция `f(u, v)`, удовлетворяющая двум условиям:

```
   ограничение пропускной способности:   0 ≤ f(u, v) ≤ c(u, v)

   сохранение потока:   для любой вершины v, кроме s и t,
                        сумма входящего потока равна сумме исходящего
```

**Величина потока** `│f│` - суммарный поток, выходящий из источника за вычетом
входящего в него.

**Разрез** `(S, T)` - разбиение вершин на две части с `s ∈ S` и `t ∈ T`. Его
**пропускная способность**

```
   c(S, T) = Σ c(u, v)   по дугам с u ∈ S и v ∈ T
```

Считаются только дуги, идущие **из** `S` **в** `T`; обратные дуги в
пропускную способность разреза не входят.

**Лемма.** Для любого потока и любого разреза величина потока равна суммарному
потоку через разрез: `│f│ = f(S, T) − f(T, S)`.

Доказательство - суммирование условия сохранения потока по всем вершинам `S`:
внутренние дуги входят в сумму дважды с противоположными знаками и
уничтожаются, остаются только дуги, пересекающие разрез.

**Следствие (слабая двойственность).** `│f│ ≤ c(S, T)` для любых потока и
разреза: поток через разрез не превосходит его пропускной способности, а
обратный поток неотрицателен.

### 3.8.2 Остаточная сеть и дополняющий путь

**Остаточная пропускная способность**:

```
   c_f(u, v) = c(u, v) − f(u, v)   сколько еще можно пропустить вперед
   c_f(v, u) = f(u, v)             сколько уже пропущено и можно отменить
```

Запись дана для сети без пар противоположно направленных дуг; при их наличии
слагаемые складываются: `c_f(v, u) = c(v, u) − f(v, u) + f(u, v)`.

Дуги с `c_f > 0` образуют **остаточную сеть**. **Дополняющий путь** - путь из
`s` в `t` по остаточной сети; вдоль него поток увеличивается на минимальную
остаточную пропускную способность.

**Зачем нужны обратные дуги.** Они позволяют отменить часть ранее принятого
решения, и без них жадное увеличение застревает.

```
   Сеть, все пропускные способности равны 1:

        s ──→ a ──→ t
        │     │     ↑
        │     ↓     │
        └───→ b ────┘

   Дуги: s→a, s→b, a→b, a→t, b→t

   Шаг 1: выбран путь s → a → b → t, поток 1.
          Теперь s→a, a→b, b→t насыщены.

   Прямого пути из s в t больше нет: у s свободна только дуга s→b,
   а из b вперед ничего не осталось.

   Шаг 2: в остаточной сети есть обратная дуга b→a (отмена единицы по a→b).
          Путь s → b → a → t дает еще единицу.

   Максимальный поток равен 2, и без обратной дуги он не был бы найден.
```

Застревание зависит от того, какой путь выбран первым: если бы на шаге 1 был
взят путь `s → a → t`, обратная дуга не понадобилась бы. Именно поэтому
обратные дуги и нужны - они делают метод корректным **при любом** выборе пути,
а не только при удачном.

Обратная дуга не «возвращает» поток физически: она переписывает уже принятое
распределение так, что суммарный результат становится лучше. Это тот же прием
обмена, что и в доказательстве
[свойства разреза](paths-and-mst.md#364-свойство-разреза).

### 3.8.3 Теорема о максимальном потоке и минимальном разрезе

**Теорема.** Для любой сети три утверждения равносильны:

1. поток `f` максимален;
2. в остаточной сети нет пути из `s` в `t`;
3. существует разрез с `│f│ = c(S, T)`.

**(1) ⟹ (2).** Если путь есть, поток можно увеличить, значит, он не был
максимальным.

**(2) ⟹ (3).** Возьмем `S` - множество вершин, достижимых из `s` в остаточной
сети, и `T` - остальные. По условию `t ∈ T`, то есть это разрез. Для любой
дуги `u → v` с `u ∈ S`, `v ∈ T` остаточная пропускная способность нулевая, то
есть дуга насыщена: `f(u, v) = c(u, v)`. Для любой дуги `v → u` в обратную
сторону нулевым должен быть сам поток, иначе была бы обратная остаточная дуга
`u → v` и вершина `v` попала бы в `S`. Подставляя в лемму из 3.8.1, получаем
`│f│ = c(S, T)`.

**(3) ⟹ (1).** По слабой двойственности никакой поток не превосходит
`c(S, T)`, а этот его достигает.

Отсюда основной результат:

```
   максимальный поток = минимальный разрез
```

Теорема двойственна по форме: максимум одной величины равен минимуму другой, и
любое допустимое значение одной ограничивает другую. **Теорема Менгера** - ее
частный случай: если положить все пропускные способности равными единице,
максимальный поток становится числом реберно непересекающихся путей, а
минимальный разрез - числом ребер, разделяющих `s` и `t`.

### 3.8.4 Алгоритмы

**Форд-Фалкерсон** - общая схема: пока в остаточной сети есть дополняющий путь,
пустить по нему поток.

**Теорема о целочисленности.** Если все пропускные способности целые, то
существует максимальный поток, все значения которого целые, и метод
Форда-Фалкерсона его находит: каждая итерация добавляет целую величину. Это
свойство и позволяет сводить к потоку комбинаторные задачи, где дробный ответ
бессмыслен.

**Слабое место схемы - выбор пути.** Если путь выбирается произвольно, число
итераций зависит от величины потока, а не от размера графа.

```
   c(s,a) = c(s,b) = c(a,t) = c(b,t) = 1000000,   c(a,b) = 1

   Неудачный выбор: s → a → b → t, затем s → b → a → t, и так далее.
   Каждая итерация добавляет единицу, всего их 2 000 000.
   Удачный выбор: s → a → t и s → b → t - две итерации.
```

При иррациональных пропускных способностях процесс может вообще не завершиться.

**Эдмондс-Карп** устраняет проблему: дополняющий путь ищется поиском в ширину,
то есть берется кратчайший по числу ребер. Расстояние от `s` до каждой вершины
в остаточной сети при этом не убывает, а каждое ребро может стать «узким» лишь
`O(n)` раз, откуда `O(n·m)` итераций и `O(n·m²)` общего времени - **независимо
от величин пропускных способностей**.

| Алгоритм | Время | Когда применяется |
| --- | --- | --- |
| Форд-Фалкерсон | `O(│f│ · m)` | малые целые пропускные способности |
| Эдмондс-Карп | `O(n · m²)` | общий случай |
| Диница | `O(n² · m)` | общий случай, на практике быстрее |
| Диница на единичных | `O(m · √n)` | паросочетания |

### 3.8.5 Сведение паросочетания к потоку

Двудольный граф с долями `X` и `Y` превращается в сеть:

```
   s → x   пропускная способность 1   для каждой x ∈ X
   x → y   пропускная способность 1   для каждого ребра графа
   y → t   пропускная способность 1   для каждой y ∈ Y
```

Целочисленный поток величины `k` соответствует паросочетанию из `k` ребер:
ограничение в единицу на дугах из `s` и в `t` означает, что каждая вершина
занята не более одного раза. Значит, максимальный поток равен наибольшему
паросочетанию, а
[алгоритм Куна](matchings.md#375-алгоритм-куна) - это в точности
Форд-Фалкерсон на такой сети.

**Теорема Кенига как следствие.** Минимальный разрез в этой сети состоит из
дуг вида `s → x` и `y → t`; соответствующие вершины `x` и `y` образуют
вершинное покрытие исходного графа, причем наименьшее. По теореме о потоке и
разрезе его размер равен максимальному потоку, то есть наибольшему
паросочетанию, - а это и есть
[теорема Кенига](matchings.md#374-теорема-кенига).

Так теорема о максимальном потоке объединяет три результата раздела: сама
она, теорема Менгера и теорема Кенига - три прочтения одного факта.

### Типичные ошибки

1. **В пропускную способность разреза включают обратные дуги.** Считаются
   только дуги из `S` в `T`; поток по обратным вычитается из величины потока,
   но в `c(S, T)` не входит.
2. **Обратные дуги в остаточной сети не создают.** Без них алгоритм находит
   максимальное по включению, а не максимальное по величине решение.
3. **Считают Форда-Фалкерсона полиномиальным.** Оценка `O(│f│ · m)` зависит от
   значений в условии, а не от размера входа; для полиномиальности нужен
   Эдмондс-Карп.
4. **Из максимальности потока делают вывод о единственности.** Минимальных
   разрезов и максимальных потоков может быть много; совпадает только их
   величина.
