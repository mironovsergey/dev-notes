# Двудольные графы и паросочетания

[← К содержанию спринта](README.md)

Паросочетание - формализация задачи о назначениях: сопоставить работников
задачам, студентов местам, устройства каналам. В двудольном случае задача
решается полностью, и решение опирается на две теоремы, каждая из которых
связывает максимум одной величины с минимумом другой.

---

## 3.7 Двудольные графы и паросочетания

### 3.7.1 Критерий двудольности

**Теорема.** Граф двудолен тогда и только тогда, когда не содержит циклов
нечетной длины.

**Необходимость.** Обход цикла в двудольном графе чередует доли: каждое ребро
переводит из одной в другую. Вернуться в исходную вершину, а значит и в
исходную долю, можно только за четное число шагов.

**Достаточность.** Пусть нечетных циклов нет. Раскрасим вершины каждой
компоненты обходом в ширину: вершина получает цвет по четности своего слоя.
Ребро между вершинами одного цвета означало бы, что их слои одинаковой
четности, и вместе с путями до корня обхода такое ребро замкнуло бы цикл
нечетной длины. Значит, все ребра идут между цветами, и цвета задают доли.

Доказательство конструктивно: проверка двудольности - это раскраска в два
цвета обходом за `O(n + m)`, попутно выдающая либо разбиение на доли, либо
нечетный цикл как свидетельство.

### 3.7.2 Паросочетания и дополняющие пути

**Паросочетание** `M` - множество ребер, попарно не имеющих общих вершин.
Вершина **насыщена**, если инцидентна ребру из `M`.

**Два разных «максимальных».** Паросочетание **максимально по включению**,
если к нему нельзя добавить ни одного ребра; **наибольшее** - если в графе нет
паросочетания большей мощности. Первое слабее второго.

```
   Путь из четырех вершин:   a ── b ── c ── d

   M₁ = {b−c}        максимально по включению: ни a−b, ни c−d добавить нельзя
   M₂ = {a−b, c−d}   наибольшее, вдвое больше
```

Жадный алгоритм всегда дает максимальное по включению паросочетание и, как
видно из примера, может ошибиться вдвое. Наибольшее строится иначе.

**Чередующийся путь** - путь, ребра которого попеременно не принадлежат и
принадлежат `M`. **Дополняющий путь** - чередующийся путь, оба конца которого
не насыщены.

Дополняющий путь всегда нечетной длины и содержит на одно ребро вне `M`
больше, чем в `M`. Поэтому если поменять принадлежность всех его ребер -
взять симметрическую разность `M △ P`, - получится паросочетание на единицу
большее.

```
   M = {b−c},   дополняющий путь  a − b − c − d

   было:   a   b══c   d          ══ ребро из M
   стало:  a══b   c══d           паросочетание выросло с 1 до 2
```

**Теорема Бержа.** Паросочетание `M` наибольшее тогда и только тогда, когда в
графе нет дополняющего пути относительно `M`.

Необходимость только что показана. Достаточность: пусть `M'` больше `M`.
Рассмотрим `M △ M'`. Каждая вершина инцидентна не более чем одному ребру из
каждого паросочетания, поэтому в этом графе все степени не больше двух, а
значит, он распадается на пути и циклы, в которых ребра `M` и `M'` чередуются.
Циклы содержат поровну ребер обоих видов. Раз `M'` больше, найдется путь, где
ребер `M'` больше, - и это дополняющий путь относительно `M`.

Теорема Бержа превращает задачу поиска наибольшего паросочетания в
последовательность поисков дополняющего пути.

### 3.7.3 Теорема Холла

Пусть граф двудолен с долями `X` и `Y`. Для `A ⊆ X` обозначим `N(A)` -
множество вершин `Y`, смежных хотя бы с одной вершиной `A`.

**Теорема Холла.** Паросочетание, насыщающее все вершины `X`, существует тогда
и только тогда, когда

```
   │N(A)│ ≥ │A│   для любого A ⊆ X
```

**Необходимость** очевидна: `│A│` вершин насыщаются `│A│` различными вершинами
из `N(A)`.

**Достаточность** доказывается индукцией по `│X│` с разбором двух случаев: либо
для всякого непустого `A ⊊ X` выполняется строгое неравенство `│N(A)│ > │A│` -
тогда можно взять любое ребро и применить предположение к остатку, - либо
найдется `A` с равенством, и тогда граф разбивается на две части, к каждой из
которых предположение применимо.

Условие Холла называют **условием свадеб**: если каждая группа из `k` человек
знакома в совокупности хотя бы с `k` кандидатами, всех можно переженить.

```
   Нарушение условия:   X = {1, 2, 3},  все трое знакомы только с {a, b}

   A = {1, 2, 3},  │N(A)│ = 2 < 3 = │A│    паросочетания, насыщающего X, нет
```

**Следствие.** В `k`-регулярном двудольном графе (`k ≥ 1`) есть совершенное
паросочетание. Действительно, ребер из `A` выходит ровно `k·│A│`, и все они
попадают в `N(A)`, где ребер не больше `k·│N(A)│`, откуда `│N(A)│ ≥ │A│`.

### 3.7.4 Теорема Кенига

**Вершинное покрытие** - множество вершин, которому принадлежит хотя бы один
конец каждого ребра. **Независимое множество** - множество попарно несмежных
вершин.

Понятия двойственны: `C` - вершинное покрытие тогда и только тогда, когда
`V ∖ C` независимо. Ребро не покрыто ровно тогда, когда оба его конца лежат вне
`C`. Отсюда для любого графа

```
   α(G) + τ(G) = n
```

где `α` - размер наибольшего независимого множества, `τ` - наименьшего
вершинного покрытия.

**Теорема Кенига.** В двудольном графе размер наибольшего паросочетания равен
размеру наименьшего вершинного покрытия:

```
   ν(G) = τ(G)
```

Неравенство `ν ≤ τ` верно в любом графе: ребра паросочетания попарно не имеют
общих вершин, поэтому на их покрытие нужно не меньше `ν` вершин. Равенство -
свойство именно двудольных графов.

**В общем графе теорема неверна.** Треугольник: наибольшее паросочетание - одно
ребро, `ν = 1`; но одной вершиной три ребра не покрыть, `τ = 2`.

Практическая ценность: в двудольном графе три задачи, каждая из которых в общем
случае NP-трудна, решаются за полиномиальное время и сводятся друг к другу -
наибольшее паросочетание, наименьшее вершинное покрытие и наибольшее
независимое множество, размер которого равен `n − ν`.

### 3.7.5 Алгоритм Куна

Алгоритм строит наибольшее паросочетание в двудольном графе, опираясь на
теорему Бержа: пока дополняющий путь существует, он найдется поиском в глубину.

```
   Для каждой вершины u левой доли:
       запустить поиск дополняющего пути из u

   Поиск из u:
       для каждого соседа v, не просмотренного на этом запуске:
           если v не насыщена  ИЛИ  из ее пары удается найти путь заново,
           то сопоставить u ↔ v и вернуть успех
```

Ключевое место - «удается найти путь заново»: рекурсивный вызов пытается
переназначить текущую пару вершины `v`, освободив ее. Это и есть переворот
ребер вдоль чередующегося пути.

```
   Стоимость: O(n · m) - по одному поиску за O(m) на каждую вершину левой доли
```

Алгоритм Хопкрофта-Карпа ищет сразу максимальное множество кратчайших
дополняющих путей и работает за `O(m·√n)`. Оба сводятся к поиску потока
([3.8.5](flows.md#385-сведение-паросочетания-к-потоку)), и алгоритм Куна - это
в точности Форд-Фалкерсон на построенной там сети.

### Типичные ошибки

1. **Максимальное по включению принимают за наибольшее.** Жадный выбор ребер
   дает первое и может ошибиться вдвое.
2. **Условие Холла проверяют только для одноэлементных множеств.** Требуется
   для **всех** подмножеств; нарушение обычно возникает как раз на больших.
3. **Теорему Кенига применяют к произвольному графу.** Равенство `ν = τ` верно
   только для двудольных; в общем случае `ν ≤ τ ≤ 2ν`.
4. **Двудольность проверяют по отсутствию треугольников.** Мешают все нечетные
   циклы, а не только длины 3: цикл `C₅` треугольников не содержит и двудольным
   не является.
5. **В алгоритме Куна не сбрасывают отметки посещения.** Массив просмотренных
   вершин обнуляется перед каждым новым запуском поиска, иначе часть
   дополняющих путей не будет найдена.
