## 3.6 Кратчайшие пути и остовные деревья

### 3.6.1 Оптимальная подструктура и релаксация

**Лемма о подпути.** Всякий участок кратчайшего пути сам является кратчайшим
путем между своими концами.

Доказательство обменом: если бы участок `u → v` можно было заменить более
коротким, замена уменьшила бы и весь путь, что противоречит его
кратчайшести.

Лемма и делает задачу решаемой: она позволяет строить ответ из ответов для
частей, не перебирая пути целиком.

**Релаксация** ребра `(u, v)` с весом `w`:

```
   если  d[u] + w < d[v],  то  d[v] := d[u] + w
```

Оценка `d[v]` всегда остается верхней границей истинного расстояния - никакая
релаксация не может сделать ее меньше достижимого.

**Почему Дейкстра требует неотрицательных весов.** Алгоритм извлекает вершину
с наименьшей текущей оценкой и объявляет ее расстояние окончательным. Это
верно, потому что любой другой путь до нее выходит за пределы уже обработанного
множества через какую-то вершину с не меньшей оценкой, а дальнейшие ребра могут
только добавить веса. Последний шаг рассуждения опирается на неотрицательность
и без нее рушится.

```
   s ──2──→ a
   │        ↑
   3        │
   ↓      (−2)
   b ──────┘

   Дейкстра из s: наименьшая оценка у a, равна 2 - фиксируется d[a] = 2
   Истинный кратчайший путь: s → b → a, вес 3 + (−2) = 1
```

Нарушается именно **инвариант**: значение, объявленное окончательным в момент
извлечения вершины, окончательным не является.

Отдельно стоит отметить, что реализация, не запрещающая повторно улучшать уже
извлеченную вершину, на этом примере выдаст верное значение 1: релаксация
ребра `b → a` произойдет позже. Ошибкой это не отменяется - гарантия
корректности потеряна, а вершины начинают извлекаться повторно, из-за чего
время работы в худшем случае перестает быть `O((n + m) log n)` и может стать
экспоненциальным. Для отрицательных весов существует
[Беллман-Форд](#362-отрицательные-веса-и-отрицательные-циклы), и пользоваться
надо им.

### 3.6.2 Отрицательные веса и отрицательные циклы

Если в графе есть цикл отрицательного веса, достижимый из источника, понятия
кратчайшего пути не существует: проходя по циклу еще раз, вес всегда можно
уменьшить. Поэтому корректная постановка - либо запретить такие циклы, либо
требовать простых путей, но последняя задача NP-полна.

**Алгоритм Беллмана-Форда** обходится без неотрицательности: он релаксирует все
ребра `n − 1` раз подряд.

**Почему `n − 1` итераций достаточно.** Кратчайший путь, если он существует,
можно взять простым - удаление циклов неотрицательного веса его не удлиняет.
Простой путь содержит не более `n − 1` ребра. После `k`-й итерации верны все
оценки, достижимые путями из `k` ребер: это доказывается индукцией по `k`,
поскольку каждая итерация релаксирует все ребра и потому продлевает любой уже
найденный путь на одно ребро.

**Критерий отрицательного цикла.** Если `n`-я итерация все еще улучшает
какую-то оценку, значит, существует путь из `n` ребер лучше всех путей из
`n − 1` ребра. Путь из `n` ребер содержит повтор вершины, то есть цикл; раз он
дал улучшение, вес цикла отрицателен.

### 3.6.3 Алгоритм Флойда-Уоршелла

Задача о кратчайших путях между **всеми** парами решается динамикой по иному
параметру: не по длине пути, а по множеству разрешенных промежуточных вершин.

```
   d[k][i][j] = кратчайший путь из i в j, промежуточные вершины
                которого лежат в {1, ..., k}

   d[k][i][j] = min( d[k−1][i][j],  d[k−1][i][k] + d[k−1][k][j] )
```

Переход разбирает два случая: путь либо не пользуется вершиной `k`, либо
проходит через нее ровно один раз. «Ровно один» - потому что повторное
посещение образует цикл, а циклы неотрицательного веса выгодно выбросить.

Индекс `k` можно не хранить: значения `d[k−1][i][k]` и `d[k−1][k][j]` при
переходе совпадают с `d[k][i][k]` и `d[k][k][j]`, поскольку добавление `k` в
число разрешенных промежуточных вершин не улучшает путь, у которого `k` -
конец. Поэтому достаточно двумерного массива и трех вложенных циклов, где
внешний идет по `k`.

```
   Стоимость: O(n³) времени, O(n²) памяти
```

Наличие отрицательного цикла обнаруживается по условию `d[i][i] < 0`.

**Транзитивное замыкание** получается заменой `min` на «или», а сложения - на
«и»; это алгоритм Уоршелла. Сравнение с
[возведением матрицы смежности в степень](representation.md#323-степени-матрицы-смежности)
поучительно: там параметром индукции была длина маршрута, и требовалось
`O(n³ log n)`; здесь параметр - номер наибольшей промежуточной вершины, и
хватает `O(n³)`. Выбор параметра индукции решает, войдет ли в оценку
логарифмический множитель.

### 3.6.4 Свойство разреза

**Разрез** `(S, V ∖ S)` - разбиение вершин на две непустые части. Ребро
**пересекает** разрез, если его концы лежат в разных частях.

**Свойство разреза.** Если ребро `e` - строго наименьшее по весу среди
пересекающих некоторый разрез, то оно входит в каждое минимальное остовное
дерево.

**Доказательство обменным аргументом.** Пусть `T` - минимальное остовное
дерево, не содержащее `e = {u, v}`. В `T` есть путь из `u` в `v`; добавив `e`,
получим цикл. Этот цикл начинается в `S` и заканчивается в `S`, значит,
пересекает разрез четное число раз и, кроме `e`, содержит еще хотя бы одно
пересекающее ребро `f`. По условию `w(e) < w(f)`. Заменим `f` на `e`: связность
сохранится (цикл разорван в одном месте, а замкнут в другом), число ребер не
изменится, значит, снова получилось остовное дерево, и его вес строго меньше -
противоречие с минимальностью `T`.

Обменный аргумент здесь тот же, что и в
[жадных алгоритмах](../../../algorithms/docs/sprint-7/greedy.md#как-доказывают-жадные-алгоритмы):
берется предполагаемое оптимальное решение и переделывается в сторону
жадного выбора без ухудшения.

Оба классических алгоритма - прямые следствия свойства:

| Алгоритм | Какой разрез используется |
| --- | --- |
| Прим | `S` - уже построенное поддерево, добавляется минимальное выходящее ребро |
| Крускал | при рассмотрении ребра `S` - компонента, содержащая один из его концов |

Двойственное утверждение - **свойство цикла**: строго наибольшее ребро любого
цикла не входит ни в одно минимальное остовное дерево. Оно обосновывает
обратный ход рассуждения: такое ребро всегда можно выбросить.

### 3.6.5 Единственность минимального остовного дерева

**Теорема.** Если все веса ребер попарно различны, минимальное остовное дерево
единственно.

**Доказательство.** Пусть `T₁ ≠ T₂` - два минимальных остовных дерева. Среди
ребер, входящих ровно в одно из них, возьмем ребро `e` наименьшего веса; пусть
`e ∈ T₁`. Добавим `e` к `T₂` - образуется цикл. В этом цикле есть ребро `f`, не
принадлежащее `T₁`: иначе весь цикл лежал бы в `T₁`, а дерево циклов не
содержит. Ребро `f` входит ровно в одно из деревьев, значит, по выбору `e`
выполняется `w(e) < w(f)`. Замена `f` на `e` дает остовное дерево меньшего
веса, чем `T₂`, - противоречие.

Условие различия весов существенно только в одну сторону: **при совпадающих
весах дерево может быть как единственным, так и нет**. Путь из трех вершин с
весами ребер `1` и `1` имеет единственное остовное дерево - сам себя, - хотя
веса равны. Треугольник со всеми весами `1` имеет три разных остовных дерева.

Практическое следствие: если веса заданы вещественными числами из измерений,
дерево почти наверняка единственно, и разные корректные реализации Прима и
Крускала дадут один и тот же ответ. Если веса целые и мелкие, ответы могут
законно различаться, и сравнивать реализации следует по суммарному весу, а не
по набору ребер.

### Типичные ошибки

1. **Дейкстру применяют к графу с отрицательными ребрами.** Отрицательный
   цикл не обязателен: достаточно одного отрицательного ребра, чтобы ответ
   стал неверным.
2. **Считают, что Беллман-Форд находит кратчайшие пути при отрицательном
   цикле.** При его наличии кратчайших путей не существует; алгоритм только
   сообщает о факте.
3. **В Флойде-Уоршелле цикл по `k` ставят не первым.** Порядок циклов здесь не
   вопрос стиля: при внешнем цикле по `i` или `j` динамика считает не то, что
   нужно.
4. **Из равенства весов заключают неединственность MST.** Различие весов -
   достаточное условие единственности, но не необходимое.
5. **Свойство разреза формулируют без строгости неравенства.** При равных
   весах минимальное пересекающее ребро входит **в некоторое** MST, но не
   обязательно во все.
