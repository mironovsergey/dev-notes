# Эйлеровы и гамильтоновы графы

[← К содержанию спринта](README.md)

Два вопроса, звучащих почти одинаково: пройти по всем **ребрам** ровно один
раз и пройти по всем **вершинам** ровно один раз. Первый решается за линейное
время простым критерием, второй - NP-полная задача. Пара показательна: она
демонстрирует, что похожесть формулировок ничего не говорит о сложности.

---

## 3.5 Эйлеровы и гамильтоновы графы

### 3.5.1 Эйлеров цикл и критерий существования

**Эйлеров цикл** - замкнутый маршрут, проходящий по каждому ребру графа ровно
один раз. **Эйлеров путь** - то же, но без требования замкнутости.

**Теорема Эйлера.** Связный граф (изолированные вершины не в счет) содержит
эйлеров цикл тогда и только тогда, когда степени всех вершин четны. Эйлеров
путь существует тогда и только тогда, когда вершин нечетной степени ровно ноль
или две; в последнем случае путь начинается в одной из них и заканчивается в
другой.

**Необходимость** доказывается подсчетом. Каждое прохождение через вершину
использует два инцидентных ей ребра - одно на вход, другое на выход. Если
маршрут замкнут, это верно и для стартовой вершины. Значит, все ребра каждой
вершины разбиваются на пары, и степень четна. Для незамкнутого пути в паре не
участвует по одному ребру у начала и у конца, откуда ровно две нечетные
степени.

**Достаточность** конструктивна: ее дает алгоритм из следующего пункта.

Условие локальное - оно проверяется по степеням за `O(n + m)`, без всякого
построения маршрута.

```
   Кенигсбергские мосты, 1736

   Четыре части суши, семь мостов; степени вершин 3, 3, 3, 5.
   Сумма степеней 14 = 2 · 7 - лемма о рукопожатиях выполнена.
   Нечетных вершин четыре, а допустимо не больше двух,
   поэтому обойти все мосты по разу нельзя ни замкнутым маршрутом, ни открытым.
```

Для орграфа критерий такой же по духу: эйлеров цикл существует тогда и только
тогда, когда `deg⁻(v) = deg⁺(v)` для каждой вершины и все вершины с ребрами
лежат в одной компоненте сильной связности.

### 3.5.2 Алгоритм Хирхольцера

Алгоритм строит эйлеров цикл за `O(m)`.

1. Из произвольной вершины пройти по неиспользованным ребрам, пока не
   вернемся в исходную. Возврат гарантирован: войдя в вершину, мы использовали
   нечетное число ее ребер, значит, есть чем выйти, - кроме стартовой вершины.
2. Если остались неиспользованные ребра, найти на построенном цикле вершину,
   у которой они есть, и построить из нее второй цикл по тем же правилам.
3. Вклеить второй цикл в первый в этой вершине.
4. Повторять, пока неиспользованные ребра есть.

Ключ к шагу 1 - четность: она гарантирует, что застрять можно только там, где
начали. Ключ к шагу 2 - связность: если ребра остались, хотя бы одно из них
инцидентно вершине уже построенного цикла.

На практике алгоритм реализуют стеком: спускаться по неиспользованным ребрам,
а при отсутствии выхода снимать вершину со стека в ответ. Получившаяся
последовательность, прочитанная в обратном порядке, и есть эйлеров цикл.

### 3.5.3 Гамильтоновы циклы

**Гамильтонов цикл** - цикл, проходящий через каждую вершину ровно один раз.
**Гамильтонов путь** - то же без замыкания.

Критерия, подобного эйлерову, не существует. Известны лишь достаточные условия,
и все они требуют, чтобы граф был достаточно плотным.

**Теорема Дирака.** Если `n ≥ 3` и `δ(G) ≥ n/2`, то граф гамильтонов.

**Теорема Оре.** Если `n ≥ 3` и для любых **несмежных** `u` и `v` выполняется
`deg(u) + deg(v) ≥ n`, то граф гамильтонов.

Теорема Оре сильнее: из `δ(G) ≥ n/2` сразу следует `deg(u) + deg(v) ≥ n` для
любой пары, в том числе несмежной. Обратное неверно.

```
   n = 5: вершина 1 смежна с 2 и 3; вершины 2, 3, 4, 5 образуют K₄

   Степени: deg(1) = 2, deg(2) = deg(3) = 4, deg(4) = deg(5) = 3

   Дирак:  δ = 2 < 2.5   условие не выполнено
   Оре:    несмежные пары - (1,4) и (1,5), сумма степеней 2 + 3 = 5 ≥ 5   выполнено

   Гамильтонов цикл существует:  1 - 2 - 4 - 5 - 3 - 1
```

**Оба условия достаточны, но не необходимы.** Простой цикл `C₅` гамильтонов по
построению, но `δ = 2 < 2.5`, а сумма степеней несмежных вершин равна `4 < 5`:
ни одна из теорем его не улавливает. Плотные достаточные условия по своей
природе не могут покрыть разреженные гамильтоновы графы.

**Необходимое условие.** Если удаление `k` вершин оставляет более `k` компонент
связности, гамильтонова цикла нет: цикл, проходя через все вершины, заходит в
каждую компоненту и выходит из нее, а на это нужны разные удаленные вершины.
Условие удобно как быстрый отсев, но достаточным не является.

### 3.5.4 Почему одна задача проста, а вторая нет

| | Эйлеров цикл | Гамильтонов цикл |
| --- | --- | --- |
| Объект обхода | ребра | вершины |
| Критерий | четность всех степеней | не известен |
| Проверка условия | `O(n + m)` | - |
| Построение | `O(m)`, алгоритм Хирхольцера | NP-полная задача |
| Лучшее известное точное решение | - | `O(2ⁿ · n²)`, динамика по подмножествам |

Причина различия - в том, что эйлерово условие **локально и склеиваемо**.
Четность степеней проверяется в каждой вершине независимо, а построенные
куски маршрута соединяются друг с другом, не нарушая уже достигнутого:
вклеивание цикла в цикл в шаге 3 алгоритма Хирхольцера ничего не портит.
Задача распадается на независимые части, и жадное построение доходит до конца.

Гамильтоново условие глобально. Использование вершины в одном месте маршрута
запрещает использовать ее во всех остальных, поэтому частичные решения не
комбинируются: два хороших куска пути могут проходить через одну вершину и
потому не склеиваться. Локального признака, по которому это можно предвидеть,
нет, и перебор в общем случае не сокращается.

Точное решение дает
[динамика по подмножествам](../../../algorithms/docs/sprint-7/dynamic.md):
состояние - пара «множество посещенных вершин, текущая вершина», переходов
`n`, состояний `2ⁿ · n`. Это метод Хелда-Карпа, `O(2ⁿ · n²)` времени и
`O(2ⁿ · n)` памяти; практический предел - примерно `n = 20`.

Задача коммивояжера - тот же гамильтонов цикл с минимизацией суммарного веса,
и она наследует всю сложность.

### Типичные ошибки

1. **Забывают проверить связность.** Четность степеней необходима, но не
   достаточна: граф из двух непересекающихся треугольников имеет все степени
   четными и эйлерова цикла не имеет.
2. **Эйлеров путь путают с эйлеровым циклом.** Для пути допустимы две вершины
   нечетной степени, для цикла - ни одной.
3. **Теоремы Дирака и Оре применяют как критерии.** Они достаточны, но не
   необходимы; невыполнение условия ничего не доказывает.
4. **Из существования эйлерова цикла выводят гамильтонов и наоборот.** Связи
   между ними нет: `K₅` имеет оба, звезда `K₍₁,₃₎` - ни одного, цикл `Cₙ` -
   оба, а граф «бабочка» из двух треугольников с общей вершиной эйлеров, но не
   гамильтонов.
