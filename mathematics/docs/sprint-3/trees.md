# Деревья

[← К содержанию спринта](README.md)

Дерево - самый частый частный случай графа, и определить его можно шестью
разными способами, которые оказываются равносильны. В
[конспекте алгоритмов](../../../algorithms/docs/sprint-5/binary-trees.md)
дерево рассматривается как структура данных; здесь - как класс графов, со
свойствами, которые из этого следуют.

---

## 3.3 Деревья

### 3.3.1 Шесть эквивалентных определений

**Дерево** - связный граф без циклов. Для графа `G` на `n` вершинах следующие
условия равносильны.

| № | Условие |
| --- | --- |
| 1 | `G` связен и не содержит циклов |
| 2 | `G` связен и `m = n − 1` |
| 3 | `G` не содержит циклов и `m = n − 1` |
| 4 | между любыми двумя вершинами существует ровно один простой путь |
| 5 | `G` связен, но удаление любого ребра нарушает связность |
| 6 | `G` ацикличен, но добавление любого ребра создает цикл |

Полезно уметь доказывать хотя бы часть переходов: в задачах обычно проверяется
одно условие, а пользуются другим.

**Лемма о длиннейшем пути.** Если в конечном графе все степени не меньше 2, то
в нем есть цикл.

Возьмем самый длинный простой путь `v₀ v₁ ... v_k`. У вершины `v₀` степень не
меньше 2, значит, помимо `v₁` у нее есть еще сосед `u`. Если бы `u` не лежал на
пути, путь `u v₀ v₁ ... v_k` был бы длиннее - противоречие. Значит, `u = vᵢ`
для некоторого `i ≥ 2`, и участок `v₀ v₁ ... vᵢ v₀` - цикл.

**(1) ⟹ (4).** Связность дает хотя бы один путь между любыми двумя вершинами.
Если бы путей было два различных, их объединение содержало бы цикл: пути
расходятся в какой-то вершине и снова сходятся, и участок между этими точками
замкнут.

**(4) ⟹ (1).** Существование пути дает связность. Цикла быть не может: любые
две вершины цикла соединены двумя разными путями - по циклу в одну сторону и в
другую.

**(1) ⟹ (2).** Индукция по `n`. При `n = 1` ребер нет. Пусть `n ≥ 2`. Все
степени не меньше 1 из-за связности, и по лемме о длиннейшем пути не может
быть, чтобы все степени были не меньше 2, - иначе появился бы цикл. Значит,
есть вершина степени 1. Удалим ее вместе с ребром: связность и ацикличность
сохраняются, вершин стало `n − 1`, а ребер по предположению индукции
`n − 2`. Возвращая вершину, получаем `n − 1`.

**(2) ⟹ (1).** Если бы цикл был, удаление любого его ребра сохранило бы
связность, и связный граф получился бы с `n − 2` ребрами - что противоречит
[нижней границе](basics.md#314-связность-и-компоненты) `m ≥ n − 1`.

Остальные переходы доказываются так же - подсчетом ребер и рассуждением о
цикле.

### 3.3.2 Ребра, листья, лес

```
   m = n − 1
```

**Лист** - вершина степени 1.

**Утверждение.** В дереве с `n ≥ 2` вершинами не менее двух листьев.

Доказательство тем же приемом: концы самого длинного простого пути - листья.
Если бы у конца была вторая инцидентная вершина, она либо продлила бы путь,
либо замкнула цикл; ни то ни другое в дереве невозможно.

Второе доказательство - через лемму о рукопожатиях: сумма степеней равна
`2(n − 1) = 2n − 2`, все степени не меньше 1, поэтому суммарный «излишек» над
единицами равен `n − 2`. Если бы листьев было меньше двух, сумма степеней
оказалась бы не меньше `2n − 1`.

**Лес** - граф без циклов, не обязательно связный. Каждая его компонента -
дерево, и если компонент `k`, то

```
   m = n − k
```

Формула объединяет три частных случая: `k = 1` дает дерево, `k = n` - граф без
ребер, а само равенство - способ определить число компонент леса, не обходя
его.

### 3.3.3 Корневые деревья

**Корневое дерево** - дерево с выделенной вершиной-корнем. Выделение корня
задает на вершинах отношение «предок - потомок», которое, как нетрудно
проверить, является [частичным порядком](../sprint-1/relations.md#134-отношение-порядка-чум-диаграмма-хассе).

- **Глубина** вершины - длина пути от корня до нее; у корня она равна 0.
- **Высота** дерева - максимальная глубина.

Число вершин ограничено высотой и максимальным числом потомков. Если у каждой
вершины не более `k` потомков, то на глубине `d` вершин не более `kᵈ`, и
всего

```
   n ≤ 1 + k + k² + ... + kʰ = (kʰ⁺¹ − 1)/(k − 1)
```

Для бинарного дерева (`k = 2`) это `n ≤ 2ʰ⁺¹ − 1`, откуда

```
   h ≥ log₂(n + 1) − 1
```

Неравенство и есть причина, по которой деревья поиска
[балансируют](../../../algorithms/docs/sprint-5/balanced.md): логарифмическая
высота - наилучшая возможная, и достигается она только при равномерном
заполнении уровней.

### 3.3.4 Остовные деревья, формула Кэли, код Прюфера

**Остовное дерево** - остовный подграф, являющийся деревом: те же вершины,
часть ребер. Существует тогда и только тогда, когда граф связен; строится
любым обходом. Задача о минимальном по весу остовном дереве разобрана в
[конспекте алгоритмов](../../../algorithms/docs/sprint-6/mst.md#67-минимальное-остовное-дерево),
теоретическая часть - в [3.6.4](paths-and-mst.md#364-свойство-разреза).

**Формула Кэли.** Число различных деревьев на `n` помеченных вершинах равно

```
   n^(n−2)
```

| `n` | 1 | 2 | 3 | 4 | 5 | 6 |
| --- | --- | --- | --- | --- | --- | --- |
| Деревьев | 1 | 1 | 3 | 16 | 125 | 1296 |

Результат неочевиден: при `n = 4` из `C(6,3) = 20` наборов по три ребра
деревьями оказываются 16, остальные четыре содержат треугольник.

**Код Прюфера** доказывает формулу
[правилом биекции](../sprint-2/basics.md#213-правило-биекции): строится
взаимно однозначное соответствие между деревьями на `n` помеченных вершинах и
последовательностями длины `n − 2` из чисел `1 ... n`. Последовательностей
ровно `n^(n−2)` по правилу произведения, значит, столько же и деревьев.

**Кодирование.** Пока в дереве больше двух вершин: взять лист с наименьшим
номером, записать в код его единственного соседа, удалить лист.

```
   Дерево на шести вершинах:

           1
            ╲
        2 ── 4 ── 5 ── 6
            ╱
           3

   Шаг │ Наименьший лист │ Записано в код │ Вершины после удаления
   ────┼─────────────────┼────────────────┼───────────────────────
    1  │        1        │       4        │  2, 3, 4, 5, 6
    2  │        2        │       4        │  3, 4, 5, 6
    3  │        3        │       4        │  4, 5, 6
    4  │        4        │       5        │  5, 6

   Код Прюфера: (4, 4, 4, 5)
```

Длина кода всегда `n − 2`: процесс останавливается на двух вершинах.

**Декодирование** восстанавливает дерево однозначно, и в этом суть биекции:
вершина, не встречающаяся в оставшейся части кода, - лист; она соединяется с
первым элементом кода, после чего оба вычеркиваются.

Полезное свойство кода: вершина встречается в нем ровно `deg(v) − 1` раз.
Отсюда сразу видно, что листья - это в точности вершины, отсутствующие в коде.

Для произвольного графа число остовных деревьев дает **матричная теорема о
деревьях** (теорема Кирхгофа): оно равно любому алгебраическому дополнению
матрицы `D − A`, где `D` - диагональная матрица степеней. Формула Кэли -
частный случай для `Kₙ`.

### Типичные ошибки

1. **Условие `m = n − 1` считают достаточным для дерева.** Само по себе - нет:
   нужна еще связность либо ацикличность. Граф из треугольника и изолированной
   вершины имеет `n = 4`, `m = 3`, но деревом не является.
2. **Формулу Кэли применяют к непомеченным деревьям.** `n^(n−2)` считает
   деревья на **помеченных** вершинах; неизоморфных деревьев на 6 вершинах
   всего 6, а не 1296.
3. **Забывают, что у леса `m = n − k`.** Формула `n − 1` верна только для
   связного случая.
4. **Высоту и глубину путают.** Глубина - у вершины, высота - у дерева, и
   высота равна наибольшей глубине.
