# Раскраска графов

[← К содержанию спринта](README.md)

Раскраска - способ формализовать конфликты: вершины, соединенные ребром, не
могут получить одно значение. В этой постановке оказываются задачи о
распределении регистров, составлении расписаний и назначении частот. Точное
значение хроматического числа найти трудно, поэтому основная работа идет с
оценками.

---

## 3.10 Раскраска графов

### 3.10.1 Хроматическое число

**Правильная раскраска** - назначение вершинам цветов так, чтобы смежные
вершины получили разные цвета. **Хроматическое число** `χ(G)` - наименьшее
число цветов, при котором правильная раскраска существует.

Малые значения читаются сразу:

| Значение | Равносильное условие |
| --- | --- |
| `χ(G) = 1` | ребер нет |
| `χ(G) ≤ 2` | граф двудолен, то есть [не содержит нечетных циклов](matchings.md#371-критерий-двудольности) |
| `χ(Kₙ) = n` | все вершины попарно смежны |
| `χ(Cₙ) = 2` при четном `n`, `3` при нечетном | цикл двудолен только при четной длине |

На `χ ≤ 2` заканчивается легкая часть: **проверка `χ(G) ≤ 3` уже NP-полна**, а
вычисление `χ(G)` NP-трудно. Скачок между двумя и тремя цветами - один из самых
резких переходов от полиномиальной задачи к трудной.

### 3.10.2 Оценки и теорема Брукса

**Нижняя оценка через клику.** Если в графе есть клика (полный подграф) на `k`
вершинах, ее вершинам нужны разные цвета:

```
   χ(G) ≥ ω(G)
```

где `ω(G)` - размер наибольшей клики. Равенства здесь нет: цикл `C₅` не
содержит треугольников, поэтому `ω = 2`, но двудольным не является, и
`χ = 3`. Разрыв между `ω` и `χ` может быть сколь угодно большим.

**Нижняя оценка через независимое множество.** Каждый цвет образует
[независимое множество](matchings.md#374-теорема-кенига), поэтому цветов не
меньше, чем `n / α(G)`.

**Верхняя оценка.** `χ(G) ≤ Δ(G) + 1`, где `Δ` - наибольшая степень. Она
следует из жадного алгоритма: у любой вершины не более `Δ` соседей, и среди
`Δ + 1` цветов найдется свободный.

**Теорема Брукса.** Для связного графа `χ(G) ≤ Δ(G)`, за исключением двух
случаев: полных графов и нечетных циклов, где `χ = Δ + 1`.

Исключения не случайны: у `Kₙ` имеем `Δ = n − 1` и `χ = n`, у `C₍₂ₖ₊₁₎` имеем
`Δ = 2` и `χ = 3`. Теорема утверждает, что других исключений нет.

### 3.10.3 Теоремы о пяти и четырех красках

**Теорема о пяти красках.** Всякий планарный граф раскрашивается в пять цветов.

Доказательство индукцией по числу вершин опирается на следствие из
[оценки числа ребер](planarity.md#393-оценка-числа-ребер): в планарном графе
есть вершина `v` степени не больше 5. Удалим ее, раскрасим остаток по
предположению индукции и вернем обратно.

Если `deg(v) ≤ 4` или среди соседей использовано не более четырех цветов,
свободный цвет находится сразу. Остается случай, когда соседей ровно пять и все
цвета различны. Здесь применяется **прием Кемпе**: рассматривается подграф,
образованный вершинами двух цветов - скажем, первого и третьего. Если соседи
`v` этих цветов лежат в разных связных компонентах такого подграфа, цвета в
одной из компонент меняются местами, и цвет освобождается. Если же они лежат в
одной компоненте, то путь между ними вместе с `v` образует замкнутый контур,
внутри и снаружи которого оказываются оставшиеся два соседа, - и тогда
аналогичная замена срабатывает для второй пары цветов, потому что путь между
ними обязан пересечь уже построенный контур, что для планарной укладки
невозможно.

**Теорема о четырех красках.** Всякий планарный граф раскрашивается в четыре
цвета.

История поучительна. Кемпе опубликовал «доказательство» в 1879 году, и оно
считалось верным одиннадцать лет, пока Хивуд не нашел ошибку - в случае с
двумя одновременными перекрашиваниями цепей. Из разрушенного доказательства
удалось спасти теорему о пяти красках, изложенную выше. Полное доказательство
получено Аппелем и Хакеном в 1976 году перебором 1936 конфигураций с помощью
компьютера; в 2005 году Гонтье формально проверил его в системе Coq.

Четырех цветов достаточно, и меньше нельзя: `K₄` планарен и требует четырех.

### 3.10.4 Жадная раскраска и порядок вершин

**Жадный алгоритм** перебирает вершины в заданном порядке и назначает каждой
наименьший цвет, не занятый ее уже раскрашенными соседями.

Алгоритм всегда укладывается в `Δ + 1` цвет и работает за `O(n + m)`, но
**результат зависит от порядка**.

```
   Двудольный граф: доли {u₁, u₂, u₃} и {v₁, v₂, v₃},
   ребро uᵢ - vⱼ проведено при i ≠ j

   Порядок u₁, v₁, u₂, v₂, u₃, v₃:

      u₁ → 1      v₁ не смежна с u₁          → 1
      u₂ смежна с v₁ (цвет 1)                → 2
      v₂ смежна с u₁ (цвет 1)                → 2
      u₃ смежна с v₁, v₂ (цвета 1, 2)        → 3
      v₃ смежна с u₁, u₂ (цвета 1, 2)        → 3

   Использовано 3 цвета, хотя граф двудолен и χ = 2
```

Порядок, при котором жадный алгоритм даст ровно `χ(G)` цветов, существует
всегда - достаточно перечислять вершины по классам оптимальной раскраски. Но
найти такой порядок не проще, чем решить исходную задачу.

Практические эвристики: перебирать вершины по убыванию степени (Уэлш-Пауэлл)
или использовать **вырожденность** - упорядочивание, при котором каждая
вершина имеет не более `d` уже раскрашенных соседей. Второе дает оценку
`χ(G) ≤ d + 1` и для планарных графов сразу дает шесть цветов, поскольку
[вершина степени не выше 5](planarity.md#393-оценка-числа-ребер) находится
всегда.

### 3.10.5 Применения

**Распределение регистров.** Вершины - переменные программы, ребро проводится,
если время жизни двух переменных пересекается и они не могут занять один
регистр. Цвета - регистры процессора. Задача компилятора: раскрасить граф в
число цветов, равное числу доступных регистров; если не удается, часть
переменных вытесняется в память. Метод предложен Чейтином и лежит в основе
регистровой аллокации большинства компиляторов.

**Составление расписания.** Вершины - занятия, ребро - конфликт (общий
преподаватель, общая аудитория, общая группа). Цвета - временные слоты.
Минимальное число слотов и есть хроматическое число.

**Назначение частот.** Вершины - передатчики, ребра - пары, находящиеся
достаточно близко, чтобы мешать друг другу. Цвета - частоты.

Во всех трех случаях граф разреженный, и на практике применяются эвристики -
жадная раскраска с хорошим порядком, - а не точное решение.

### Типичные ошибки

1. **Считают `χ(G) = ω(G)`.** Клика дает только нижнюю оценку; `C₅` -
   наименьший контрпример.
2. **Теорему Брукса применяют без исключений.** Для полных графов и нечетных
   циклов `χ = Δ + 1`, а не `Δ`.
3. **От жадного алгоритма ждут оптимума.** Он гарантирует лишь `Δ + 1` цвет;
   на двудольном графе может использовать сколь угодно много.
4. **Теорему о четырех красках применяют к непланарным графам.** `K₅` требует
   пяти цветов, `Kₙ` - `n`.
5. **Из «двух цветов не хватает» заключают, что нужно четыре.** Промежуточное
   значение `χ = 3` встречается чаще всех остальных.
