# Принцип включений-исключений

[← К содержанию спринта](README.md)

Принцип включений-исключений - систематический ответ на вопрос, что делать с
пересекающимися случаями, когда правило суммы неприменимо. Идея: посчитать с
избытком, вычесть лишнее, вернуть вычтенное дважды и так далее до конца.

---

## 2.4 Принцип включений-исключений

### 2.4.1 Два и три множества

```
   │A ∪ B│ = │A│ + │B│ − │A ∩ B│
```

Элементы пересечения при сложении учтены дважды, поэтому один их экземпляр
вычитается.

Для трех множеств одного вычитания мало:

```
   │A ∪ B ∪ C│ = │A│ + │B│ + │C│
                 − │A ∩ B│ − │A ∩ C│ − │B ∩ C│
                 + │A ∩ B ∩ C│
```

```
        ┌─────────────┐
        │      A      │
        │   ┌─────────┼───┐
        │   │  A∩B    │ B │
        │ ┌─┼───┬─────┼─┐ │
        │ │ │A∩B│     │ │ │
        │ │ │ ∩C│ B∩C │ │ │
        └─┼─┼───┴─────┼─┘ │
          │ │    C    │   │
          │ └─────────┼───┘
          └───────────┘
```

Элемент из тройного пересечения посчитан трижды в первой строке, вычтен
трижды во второй и потому исчез бы совсем - третья строка возвращает его
ровно один раз.

```
   Сколько чисел от 1 до 100 делятся на 2, 3 или 5?

   50 + 33 + 20 − 16 − 10 − 6 + 3 = 74
```

### 2.4.2 Общий случай

```
   │A₁ ∪ ... ∪ Aₙ│ =  Σ │Aᵢ│
                    − Σ │Aᵢ ∩ Aⱼ│
                    + Σ │Aᵢ ∩ Aⱼ ∩ A_k│
                    − ...
                    + (−1)ⁿ⁻¹ │A₁ ∩ ... ∩ Aₙ│
```

Знак чередуется, а `k`-е слагаемое суммируется по всем `C(n,k)` наборам из
`k` множеств.

**Доказательство.** Возьмем произвольный элемент и посмотрим, сколько раз он
учтен правой частью. Пусть он принадлежит ровно `m` множествам из `n`, причем
`m ≥ 1`. В сумме по одиночным множествам он встретится `m` раз, в сумме по
парам - `C(m,2)` раз (пара выбирается только из тех множеств, которым он
принадлежит), в сумме по тройкам - `C(m,3)` раз. Итого он учтен

```
   C(m,1) − C(m,2) + C(m,3) − ... = − Σ (−1)ᵏ C(m,k),   k = 1 ... m
```

По [знакопеременному тождеству](binomial.md#233-основные-тождества) полная
сумма `Σ (−1)ᵏ C(m,k)` при `k = 0 ... m` равна нулю, а слагаемое при `k = 0`
равно `C(m,0) = 1`. Значит, сумма без нулевого слагаемого равна `−1`, и
искомая величина равна `1`.

Каждый элемент объединения учтен ровно один раз, элементы вне объединения -
ноль раз (для них `m = 0`). Это и есть требуемое равенство.

**Стоимость.** Формула содержит `2ⁿ − 1` слагаемых, поэтому применяется либо
при малом `n`, либо когда мощности пересечений считаются по общей формуле и
сумма сворачивается аналитически - как в следующих двух пунктах.

### 2.4.3 Задача о беспорядках

**Беспорядок** - перестановка без неподвижных точек: ни один элемент не стоит
на своем месте.

Пусть `Aᵢ` - множество перестановок, в которых `i`-й элемент остался на месте.
Тогда беспорядки - это дополнение к `A₁ ∪ ... ∪ Aₙ`. Пересечение любых `k`
множеств фиксирует `k` элементов и оставляет свободными `n − k`, поэтому его
мощность равна `(n − k)!` и зависит только от `k`. Слагаемых с данным `k`
ровно `C(n,k)`:

```
   D(n) = Σ (−1)ᵏ · C(n,k) · (n−k)!  =  n! · Σ (−1)ᵏ / k!,   k = 0 ... n
```

| `n` | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| `D(n)` | 1 | 0 | 1 | 2 | 9 | 44 | 265 | 1854 |
| `D(n)/n!` | 1 | 0 | 0.5 | 0.333 | 0.375 | 0.367 | 0.368 | 0.368 |

Сумма `Σ (−1)ᵏ/k!` - частичная сумма ряда для `e⁻¹`, поэтому

```
   D(n) / n! → 1/e ≈ 0.3679
```

Доля беспорядков практически не зависит от `n`: при `n = 6` она отличается от
`1/e` меньше чем на `0.0002`, при `n = 7` - меньше чем на `0.00003`. Как
вероятность это утверждение разбирается в
[теории вероятностей](../sprint-4/README.md).

Есть и рекуррентная форма, удобная для вычислений:

```
   D(n) = (n − 1) · (D(n−1) + D(n−2)),   D(0) = 1, D(1) = 0
```

### 2.4.4 Подсчет сюръекций

Сколько существует **сюръекций** из `m`-элементного множества в
`n`-элементное, то есть функций, при которых используется каждое из `n`
значений?

Пусть `Aᵢ` - множество функций, **не** использующих значение `i`. Пересечение
`k` таких множеств - это функции в оставшиеся `n − k` значений, их
`(n − k)^m`. Сюръекции - дополнение к объединению:

```
   Surj(m, n) = Σ (−1)ᵏ · C(n,k) · (n−k)^m,   k = 0 ... n
```

| `m` \ `n` | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- |
| 2 | 1 | 2 | 0 | 0 |
| 3 | 1 | 6 | 6 | 0 |
| 4 | 1 | 14 | 36 | 24 |
| 5 | 1 | 30 | 150 | 240 |

Нули при `m < n` закономерны: покрыть `n` значений `m` аргументами невозможно.
Ту же таблицу дал перебор функций в
[спринте 1](../sprint-1/relations.md#135-функция-как-отношение) - там значения
`14` и `6` получены прямым перечислением.

Величина `Surj(m,n)` связана с числами Стирлинга второго рода
([2.7.3](numbers.md#273-числа-стирлинга-и-числа-белла)):

```
   Surj(m, n) = n! · S(m, n)
```

Сюръекция задается разбиением области определения на `n` непустых блоков
(`S(m,n)` способов) и назначением блокам значений (`n!` способов).

### Типичные ошибки

1. **Знаки чередуются не с того места.** Первое слагаемое всегда со знаком
   плюс; при записи через дополнение (беспорядки, сюръекции) сумма начинается
   с `k = 0`, и первое слагаемое - это полное число объектов.
2. **Слагаемое считают один раз вместо `C(n,k)`.** Формула суммирует по всем
   наборам из `k` множеств; если мощности пересечений одинаковы, множитель
   `C(n,k)` обязателен.
3. **Формулу применяют при большом `n` буквально.** `2ⁿ − 1` слагаемых
   практичны примерно до `n = 20`.
4. **`D(n)/n!` считают стремящимся к нулю.** Доля беспорядков стремится к
   `1/e`, а не к нулю: беспорядок - типичная перестановка, а не редкая.
