# Биномиальные коэффициенты

[← К содержанию спринта](README.md)

`C(n,k)` встречается в комбинаторике чаще любой другой величины, и почти
всякое тождество для него допускает два доказательства: алгебраическое -
преобразованием факториалов, и комбинаторное - подсчетом одного и того же
множества двумя способами. Второе короче и запоминается лучше.

---

## 2.3 Биномиальные коэффициенты

### 2.3.1 Треугольник Паскаля

```
   n = 0                    1
   n = 1                 1     1
   n = 2              1     2     1
   n = 3           1     3     3     1
   n = 4        1     4     6     4     1
   n = 5     1     5    10    10     5     1
   n = 6  1     6    15    20    15     6     1
```

Каждое число - сумма двух стоящих над ним. Это **тождество Паскаля**:

```
   C(n,k) = C(n−1, k−1) + C(n−1, k)
```

**Комбинаторное доказательство.** Зафиксируем один элемент множества. Всякое
`k`-элементное подмножество либо содержит его, либо нет. В первом случае
остается выбрать `k − 1` элемент из оставшихся `n − 1`, во втором - `k`
элементов из тех же `n − 1`. Случаи не пересекаются и покрывают все
подмножества, поэтому по правилу суммы величины складываются.

Тождество Паскаля дает способ вычислять `C(n,k)` без факториалов, за `O(n²)`
сложений и без переполнения на промежуточных значениях, - это стандартная
таблица в динамическом программировании.

### 2.3.2 Бином Ньютона

```
   (a + b)ⁿ = Σ  C(n,k) · aᵏ · bⁿ⁻ᵏ,   k = 0 ... n
```

**Почему коэффициент именно `C(n,k)`.** Произведение `(a + b)(a + b)...(a + b)`
из `n` скобок раскрывается перебором: из каждой скобки берется либо `a`, либо
`b`. Слагаемое `aᵏbⁿ⁻ᵏ` получается ровно тогда, когда `a` взято из `k` скобок,
а выбрать эти `k` скобок из `n` можно `C(n,k)` способами.

Отсюда и второе название `C(n,k)` - биномиальный коэффициент.

### 2.3.3 Основные тождества

| Название | Тождество |
| --- | --- |
| Симметрия | `C(n,k) = C(n, n−k)` |
| Сумма строки | `Σ C(n,k) = 2ⁿ` |
| Знакопеременная сумма | `Σ (−1)ᵏ C(n,k) = 0` при `n ≥ 1` |
| Тождество Паскаля | `C(n,k) = C(n−1,k−1) + C(n−1,k)` |
| Поглощение | `k · C(n,k) = n · C(n−1, k−1)` |
| Свертка Вандермонда | `Σ C(m,i) · C(n, k−i) = C(m+n, k)` |
| Хоккейная клюшка | `Σ C(i,r) = C(n+1, r+1)`, `i = r ... n` |

**Симметрия.** Выбрать `k` элементов - то же самое, что выбрать `n − k`
элементов, которые останутся. Соответствие «подмножество ↔ его дополнение»
взаимно однозначно.

**Сумма строки.** Слева считаются подмножества по размерам, справа - все
подмножества сразу. Обе величины равны `2ⁿ`. То же получается подстановкой
`a = b = 1` в бином Ньютона.

**Знакопеременная сумма.** Подстановка `a = 1, b = −1` дает `(1 − 1)ⁿ = 0`.
Содержательно это означает, что подмножеств четного размера ровно столько же,
сколько нечетного. Тождество понадобится при доказательстве принципа
включений-исключений ([2.4.2](inclusion-exclusion.md#242-общий-случай)).

**Свертка Вандермонда.** Выбираем `k` элементов из объединения двух
непересекающихся множеств размеров `m` и `n`. Разберем случаи по числу `i`
элементов, взятых из первого множества: способов `C(m,i) · C(n, k−i)`.
Суммирование по `i` и дает `C(m+n, k)`.

**Хоккейная клюшка.** Сумма по столбцу треугольника Паскаля равна элементу,
стоящему на одну строку ниже и на один столбец правее. В треугольнике выше:
`1 + 3 + 6 + 10 = 20`, то есть `C(2,2) + C(3,2) + C(4,2) + C(5,2) = C(6,3)`.

### 2.3.4 Формула Стирлинга и оценки

Факториал не имеет замкнутого выражения через элементарные функции, но хорошо
приближается **формулой Стирлинга**:

```
   n! ≈ √(2πn) · (n/e)ⁿ
```

Относительная погрешность убывает как `1/(12n)`:

| `n` | `n!` | Приближение | Погрешность | `1/(12n)` |
| --- | --- | --- | --- | --- |
| 5 | 120 | 118.02 | 1.651 % | 1.667 % |
| 10 | 3 628 800 | 3.5987 · 10⁶ | 0.830 % | 0.833 % |
| 20 | 2.4329 · 10¹⁸ | 2.4228 · 10¹⁸ | 0.416 % | 0.417 % |
| 50 | 3.0414 · 10⁶⁴ | 3.0363 · 10⁶⁴ | 0.167 % | 0.167 % |

Практическая ценность формулы не в точности, а в том, что она делает видимой
скорость роста: `n!` растет как `nⁿ` с точностью до множителей меньшего
порядка, то есть быстрее любой экспоненты `cⁿ`.

**Оценки биномиального коэффициента.** Для `1 ≤ k ≤ n`

```
   (n/k)ᵏ  ≤  C(n,k)  ≤  (e·n/k)ᵏ
```

Обе границы получаются из `C(n,k) = n(n−1)...(n−k+1) / k!`: числитель
заключен между `(n−k+1)ᵏ` и `nᵏ`, а знаменатель оценивается через ту же
формулу Стирлинга. При `n = 20`, `k = 5` границы дают `1024 ≤ 15504 ≤ 151975`
- порядок величины они улавливают, точное значение нет.

Центральный коэффициент - наибольший в строке:

```
   C(2n, n) ≈ 4ⁿ / √(πn)
```

При `n = 10` это `184 756` против приближения `187 079`.

Оценки нужны там, где `C(n,k)` появляется как число вариантов перебора: они
сразу показывают, полиномиален перебор или экспоненциален. Строка `C(n,k)` при
фиксированном `k` растет как `nᵏ` - полиномиально; сумма всей строки растет
как `2ⁿ` - экспоненциально. Это то же разделение, что и в
[классах сложности](../../../algorithms/docs/sprint-1/complexity.md).

### Типичные ошибки

1. **`C(n,k)` вычисляется через факториалы напрямую.** Уже при `n = 21`
   значение `n!` выходит за точный диапазон чисел с плавающей точкой, хотя сам
   коэффициент мал. Считать нужно последовательным умножением и делением или
   по тождеству Паскаля.
2. **Забывают, что `C(n,k) = 0` при `k > n` и при `k < 0`.** В тождествах вроде
   свертки Вандермонда суммирование формально идет по всем `i`, и лишние
   слагаемые обнуляются именно этим соглашением.
3. **Формулу Стирлинга применяют к малым `n`.** При `n = 1` погрешность около
   8 %.
4. **Знакопеременную сумму считают равной нулю при `n = 0`.** При `n = 0` она
   равна `C(0,0) = 1`.
