# Правила подсчета

[← К содержанию спринта](README.md)

Вся комбинаторика вырастает из трех правил: сумма, произведение и биекция.
Формулы для перестановок и сочетаний - не отдельные факты, которые нужно
помнить, а следствия этих правил, и вывод каждой занимает две строки.

---

## 2.1 Правила подсчета

### 2.1.1 Правило суммы

**Правило суммы.** Если множества `A` и `B` не пересекаются, то

```
   │A ∪ B│ = │A│ + │B│
```

Условие непересечения обязательно. Без него верна лишь формула из
[1.2.2](../sprint-1/sets.md#122-операции-и-законы-алгебры-множеств) с
вычитанием пересечения.

На языке выбора правило суммы отвечает союзу **«или»**: объект берется либо из
первой группы, либо из второй, и группы не перекрываются.

Обобщение на `k` попарно непересекающихся множеств получается индукцией:

```
   │A₁ ∪ ... ∪ A_k│ = │A₁│ + ... + │A_k│
```

### 2.1.2 Правило произведения

**Правило произведения.** Если объект строится последовательным выбором из `k`
шагов, причем на `i`-м шаге доступно ровно `nᵢ` вариантов **независимо от
сделанного ранее**, то объектов

```
   n₁ · n₂ · ... · n_k
```

Оговорка про независимость требует уточнения: зависеть от предыдущих шагов
может **состав** доступных вариантов, но не их **количество**. При выборе двух
разных букв из алфавита состав второго шага зависит от первого, а количество
всегда `n − 1`, и правило применимо.

На языке выбора это союз **«и»**: сначала одно, потом другое.

```
   Номер вида «две буквы, три цифры» из алфавита в 26 букв:

   26 · 26 · 10 · 10 · 10 = 676 000
```

Формально правило произведения - это утверждение
`│A × B│ = │A│ · │B│` из [1.2.3](../sprint-1/sets.md#123-декартово-произведение-и-булеан),
распространенное на `k` сомножителей.

### 2.1.3 Правило биекции

**Правило биекции.** Если между `A` и `B` существует
[биекция](../sprint-1/relations.md#135-функция-как-отношение), то
`│A│ = │B│`.

Как правило подсчета оно означает следующее: задачу можно заменить другой,
если между их объектами установлено взаимно однозначное соответствие. Это
самый мощный из трех приемов, потому что позволяет перевести задачу в область,
где ответ уже известен.

**Пример 1. Число подмножеств.** Подмножество `n`-элементного множества
однозначно кодируется двоичным вектором длины `n`. Векторов `2ⁿ` по правилу
произведения, значит, и подмножеств `2ⁿ` - тот же вывод, что в
[1.2.3](../sprint-1/sets.md#123-декартово-произведение-и-булеан).

**Пример 2. Пути в решетке.** Сколько монотонных путей ведет из `(0, 0)` в
`(m, n)`, если разрешены шаги вправо и вверх?

```
   (0,0) → (3,2)

     ┌───┬───┬───┐            один из путей:
     │   │   │   │            В П П В П
     ├───┼───┼───┤
     │   │   │   │
     └───┴───┴───┘
```

Каждый путь состоит ровно из `m` шагов вправо и `n` шагов вверх, а порядок
шагов произволен. Значит, путь однозначно задается строкой из `m` букв `П` и
`n` букв `В`, и соответствие взаимно однозначно. Число таких строк - число
способов выбрать `m` позиций из `m + n`, то есть `C(m + n, m)`.

Задача о путях в решетке возникла из ничего, а решается уже известной
величиной: в этом и состоит смысл правила биекции.

### 2.1.4 Правило деления и двойной учет

**Правило деления.** Если при подсчете каждый объект учтен ровно `k` раз, то
их количество равно `N / k`, где `N` - результат подсчета с повторами.

**Пример. Круглый стол.** Сколькими способами `n` человек садятся за круглый
стол, если важен только порядок соседей, а не абсолютные места? Линейных
расстановок `n!`, но каждая рассадка получается `n` раз - по одной на каждый
поворот. Ответ: `n! / n = (n − 1)!`.

При `n = 4` линейных расстановок 24, различных рассадок 6 - проверено прямым
перебором с приведением к каноническому виду.

**Двойной учет как ошибка.** Правило суммы применяют к пересекающимся
множествам чаще, чем к любым другим.

```
   Сколько чисел от 1 до 100 делятся на 2 или на 3?

   Неверно:  50 + 33 = 83
   Верно:    50 + 33 − 16 = 67
```

Вычесть нужно числа, делящиеся сразу на 6: они попали в оба слагаемых.
Систематический способ обращаться с такими пересечениями - принцип
включений-исключений ([2.4](inclusion-exclusion.md#24-принцип-включений-исключений)).

### Типичные ошибки

1. **Правило суммы применяется к пересекающимся множествам.** Разбиение на
   случаи должно быть не только полным, но и **непересекающимся**.
2. **Правило произведения применяется, когда число вариантов на шаге
   меняется.** Если после первого выбора остается то 3, то 5 вариантов,
   произведение неприменимо: нужен разбор случаев.
3. **Порядок учитывается там, где он не важен.** Признак: если перестановка
   выбранных элементов дает тот же объект, результат надо делить на число
   таких перестановок.
4. **Смешение «или» и «и».** Слово «или» в условии почти всегда означает
   сложение, «и» - умножение; расхождение с этим правилом - повод перечитать
   условие.
