# 2 Комбинаторика

Конспект второго раздела: как считать количество объектов, не перечисляя их.
Три правила подсчета дают четыре формулы выборок, из них вырастают
биномиальные коэффициенты, а включения-исключения, принцип Дирихле и
производящие функции покрывают остальные типовые постановки.

| Бином Ньютона | `(a+b)ⁿ = Σ C(n,k) aᵏ bⁿ⁻ᵏ` | [2.3.2](binomial.md#232-бином-ньютона) |

| Оценки `C(n,k)` | `(n/k)ᵏ ≤ C(n,k) ≤ (en/k)ᵏ` | [2.3.4](binomial.md#234-формула-стирлинга-и-оценки) |
| Включения-исключения | чередование знаков по всем пересечениям | [2.4.2](inclusion-exclusion.md#242-общий-случай) |
| Беспорядки | `D(n) = n!·Σ(−1)ᵏ/k!`, `D(n)/n! → 1/e` | [2.4.3](inclusion-exclusion.md#243-задача-о-беспорядках) |
| Сюръекции | `Σ(−1)ᵏ C(n,k)(n−k)^m = n!·S(m,n)` | [2.4.4](inclusion-exclusion.md#244-подсчет-сюръекций) |
| Принцип Дирихле | `N` предметов в `n` ящиках дают ящик с `⌈N/n⌉` | [2.5.1](pigeonhole.md#251-формулировки) |

| Фибоначчи | замощения полосы `F₍ₙ₊₁₎`, строки без соседних единиц `F₍ₙ₊₂₎` | [2.7.1](numbers.md#271-числа-фибоначчи) |
| Каталан | `Cₙ = C(2n,n)/(n+1)`; скобки, пути, деревья | [2.7.2](numbers.md#272-числа-каталана) |
