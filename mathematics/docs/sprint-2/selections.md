# Выборки

[← К содержанию спринта](README.md)

Четыре базовые формулы комбинаторики отвечают на один вопрос: сколькими
способами выбрать `k` элементов из `n`. Ответов четыре, потому что вопрос
неполон - его уточняют два независимых признака: важен ли порядок и
разрешены ли повторения.

---

## 2.2 Выборки

### 2.2.1 Классификация

| | **Без повторений** | **С повторениями** |
| --- | --- | --- |
| **Порядок важен** | размещения `A(n,k) = n!/(n−k)!` | `nᵏ` |
| **Порядок не важен** | сочетания `C(n,k) = n!/(k!(n−k)!)` | `C(n+k−1, k)` |

Прежде чем брать формулу, отвечают на два вопроса:

1. **Даст ли перестановка выбранных элементов другой объект?** Если да -
   порядок важен.
2. **Может ли один элемент быть выбран дважды?** Если да - повторения
   разрешены.

Ошибка на этом шаге не исправляется никакими вычислениями дальше.

### 2.2.2 Перестановки

**Перестановка** `n` различных элементов - расположение их в ряд. По правилу
произведения на первое место `n` вариантов, на второе `n − 1` и так далее:

```
   Pₙ = n!
```

Факториал растет быстрее любой экспоненты, и это ограничивает применимость
полного перебора перестановок:

| `n` | `n!` |
| --- | --- |
| 5 | 120 |
| 10 | 3 628 800 |
| 13 | 6 227 020 800 |
| 20 | ≈ 2.4 · 10¹⁸ |

Перебор перестановок практичен примерно до `n = 11`; дальше нужен другой
подход - отсюда и место факториальной сложности в
[классификации](../../../algorithms/docs/sprint-1/complexity.md).

### 2.2.3 Размещения

**Размещение** - упорядоченная выборка `k` различных элементов из `n`. Первый
элемент выбирается `n` способами, второй `n − 1`, последний `n − k + 1`:

```
   A(n,k) = n · (n−1) · ... · (n−k+1) = n! / (n−k)!
```

При `k = n` получается `A(n,n) = n!` - перестановка есть частный случай
размещения. Ту же величину дал подсчет
[инъекций](../sprint-1/relations.md#135-функция-как-отношение) в спринте 1:
инъекция из `k`-элементного множества в `n`-элементное и есть упорядоченная
выборка без повторений.

### 2.2.4 Сочетания

**Сочетание** - неупорядоченная выборка `k` различных элементов из `n`.

Формула выводится правилом деления. Каждое сочетание порождает `k!`
размещений - по одному на каждый порядок выбранных элементов, - и разных
сочетаний размещения не порождают. Значит, при подсчете размещений каждое
сочетание учтено ровно `k!` раз:

```
   C(n,k) = A(n,k) / k! = n! / (k! · (n−k)!)
```

Обозначения `C(n,k)`, `Cₙᵏ` и `(n над k)` означают одно и то же.

### 2.2.5 Выборки с повторениями

**Упорядоченные с повторениями.** Каждый из `k` шагов независим и дает `n`
вариантов, поэтому их `nᵏ`. Это же число функций из `k`-элементного множества
в `n`-элементное.

**Неупорядоченные с повторениями** считаются приемом **«звезды и палочки»**.
Выборка задается тем, сколько раз взят каждый из `n` типов; изобразим
количества звездами, а границы между типами - палочками:

```
   n = 4 типа, k = 6 элементов, выбрано: 3 первого, 0 второго, 2 третьего, 1 четвертого

   ★ ★ ★ │ │ ★ ★ │ ★

   всего 6 звезд и 3 палочки, строка длины 9
```

Соответствие взаимно однозначно: по строке количества восстанавливаются
однозначно, по количествам строка тоже. Строка задается выбором позиций для
`k` звезд среди `k + n − 1` мест, поэтому

```
   C(n + k − 1, k)
```

Палочек ровно `n − 1`, а не `n`: границ между `n` группами на единицу меньше,
чем самих групп. Это место ошибаются чаще всего.

### 2.2.6 Перестановки с повторениями

Если среди `n` элементов есть одинаковые - `n₁` элементов первого типа, `n₂`
второго и так далее, - то различных перестановок меньше, чем `n!`. Каждая из
них при подсчете `n!` учтена `n₁!·n₂!·...·n_k!` раз, по одному разу на каждую
перестановку одинаковых элементов между собой. Правило деления дает
**мультиномиальный коэффициент**:

```
   n! / (n₁! · n₂! · ... · n_k!)
```

```
   АБРАКАДАБРА:  11 букв,  А - 5,  Б - 2,  Р - 2,  К - 1,  Д - 1

   11! / (5! · 2! · 2! · 1! · 1!) = 39 916 800 / 480 = 83 160
```

При `k = 2` мультиномиальный коэффициент превращается в биномиальный:
`n!/(n₁!·n₂!) = C(n, n₁)`. Это и есть связь между выбором подмножества и
перестановкой строки из двух символов, использованная в
[пути по решетке](basics.md#213-правило-биекции).

**Мультиномиальная теорема** обобщает бином Ньютона:

```
   (x₁ + ... + x_k)ⁿ = Σ  n!/(n₁!·...·n_k!) · x₁^n₁ · ... · x_k^n_k
```

сумма берется по всем наборам неотрицательных `nᵢ` с `n₁ + ... + n_k = n`.
Число слагаемых - это число неупорядоченных выборок с повторениями,
`C(n + k − 1, n)`.

### 2.2.7 Перебор выборок в коде

**Подмножества** перебираются циклом по битовой маске (см.
[1.5.5](../sprint-1/boolean-algebra.md#155-битовые-операции-как-булева-алгебра)):

```js
const elements = ['a', 'b', 'c'];

for (let mask = 0; mask < 1 << elements.length; mask++) {
  // Бит i маски означает, что элемент i входит в подмножество.
  const subset = elements.filter((element, i) => (mask >> i & 1) === 1);

  console.log(mask.toString(2).padStart(elements.length, '0'), subset.join('') || '∅');
}
```

**Перестановки** перебираются алгоритмом следующей перестановки. Он выдает
перестановки в лексикографическом порядке и работает на месте, без рекурсии:

```js
/**
 * Переводит массив в следующую перестановку в лексикографическом порядке.
 *
 * Алгоритм: находится самая правая позиция i с a[i] < a[i+1]; правее нее
 * последовательность убывает, то есть является наибольшей возможной. Элемент
 * a[i] меняется с наименьшим большим его элементом справа, после чего хвост
 * разворачивается, превращаясь в наименьший возможный.
 *
 * Время: O(n) в худшем случае, O(1) амортизированно. Память: O(1).
 *
 * @param {number[]} values Массив, изменяемый на месте.
 * @returns {boolean} false, если перестановка была последней.
 */
function nextPermutation(values) {
  let i = values.length - 2;

  while (i >= 0 && values[i] >= values[i + 1]) {
    i--;
  }

  if (i < 0) {
    return false;
  }

  let j = values.length - 1;

  while (values[j] <= values[i]) {
    j--;
  }

  [values[i], values[j]] = [values[j], values[i]];

  // Хвост убывает, разворот делает его возрастающим, то есть минимальным.
  for (let left = i + 1, right = values.length - 1; left < right; left++, right--) {
    [values[left], values[right]] = [values[right], values[left]];
  }

  return true;
}
```

**Сочетания** перебираются рекурсией с отсечением по остатку: выбирать `k`
элементов из хвоста длины меньше `k` бессмысленно. Схема разобрана в
[переборе с возвратом](../../../algorithms/docs/sprint-3/recursion.md#313-рекурсивный-перебор-вариантов).

### Типичные ошибки

1. **Размещения путают с сочетаниями.** Признак сочетаний: перестановка
   выбранных элементов не создает нового объекта.
2. **В «звездах и палочках» берут `n` палочек.** Границ между `n` группами
   ровно `n − 1`.
3. **Формула `nᵏ` применяется к неупорядоченным выборкам.** `nᵏ` считает
   упорядоченные наборы; для неупорядоченных нужна `C(n+k−1, k)`, и делением
   на `k!` из `nᵏ` она не получается - повторения делают группы разного
   размера.
4. **Мультиномиальный коэффициент считают как `n!/k!`.** Делить нужно на
   произведение факториалов **всех** кратностей, включая единичные.
