# Ключевые распределения

[← К содержанию спринта](README.md)

Распределений бесконечно много, но в задачах повторяется десяток, и каждое
отвечает своей схеме опыта. Полезно помнить не столько формулы плотностей,
сколько **условия применимости**: биномиальное требует независимости и
постоянной вероятности успеха, пуассоновское - редкости событий,
экспоненциальное - отсутствия памяти. Подстановка распределения, схема
которого не выполнена, - самая дорогая ошибка раздела.

---

## 4.5 Ключевые распределения

### 4.5.1 Бернулли и биномиальное распределение

**Схема Бернулли** - `n` независимых испытаний с двумя исходами и постоянной
вероятностью успеха `p`. Обозначение `q = 1 − p`.

Одно испытание дает **распределение Бернулли**:

```
   P(X = 1) = p,   P(X = 0) = q
   E X = p,   D X = pq
```

Дисперсия `pq` максимальна при `p = 1/2` и обращается в нуль при `p = 0` и
`p = 1`: определенность исхода означает отсутствие разброса.

Число успехов в `n` испытаниях имеет **биномиальное распределение**
`X ~ Bin(n, p)`:

```
   P(X = k) = C(n,k) · p^k · q^(n−k),   k = 0 ... n

   E X = np,   D X = npq
```

Множитель `C(n,k)` считает, какими наборами испытаний могли реализоваться
успехи; сама вероятность каждого такого набора равна `p^k q^(n−k)`.
Нормировка - это [бином Ньютона](../sprint-2/binomial.md):
`Σ C(n,k) p^k q^(n−k) = (p + q)ⁿ = 1`.

Характеристики получаются мгновенно представлением `X` как суммы `n`
независимых индикаторов и применением
[линейности](expectation.md#441-математическое-ожидание-линейность): ожидания
складываются всегда, дисперсии - благодаря независимости.

**Условия применимости**: число испытаний фиксировано, испытания независимы,
`p` постоянна. При выборке **без возвращения** третье условие нарушается, и
верным является гипергеометрическое распределение из
[4.1.3](probability-space.md#413-классическое-определение-и-комбинаторный-подсчет);
биномиальное служит для него приближением, когда выборка мала по сравнению с
генеральной совокупностью.

### 4.5.2 Геометрическое распределение

Число испытаний Бернулли **до первого успеха включительно**:

```
   P(X = k) = q^(k−1) · p,   k = 1, 2, 3, ...

   E X = 1/p,   D X = q/p²
   P(X > k) = q^k
```

Ожидание `1/p` согласуется со здравым смыслом: при вероятности успеха `1/100`
в среднем требуется 100 попыток. Ответ выводится и анализом по первому шагу,
см. [4.4.5](expectation.md#445-условное-математическое-ожидание).

Существует **вторая версия** того же распределения - число **неудач** до
первого успеха, `P(Y = k) = q^k · p` при `k = 0, 1, 2, ...` и `E Y = q/p`.
Версии различаются сдвигом на единицу, и расхождение в определениях - обычный
источник ошибок; при использовании формулы или библиотечной функции следует
проверять, какая из них подразумевается.

**Отсутствие памяти.** Для геометрического распределения

```
   P(X > m + k | X > m) = P(X > k)
```

Проверка: `q^(m+k) / q^m = q^k`. Содержательно: серия неудач не повышает
шансов на ближайший успех. Геометрическое - **единственное** дискретное
распределение с таким свойством. Отсюда следует несостоятельность
представления, что после длинной череды неудач успех «назрел».

### 4.5.3 Распределение Пуассона

Возникает как предел биномиального при большом числе испытаний и малой
вероятности успеха, когда среднее число успехов остается конечным:

```
   n → ∞,   p → 0,   np → λ
```

```
   P(X = k) = (λ^k / k!) · e^(−λ),   k = 0, 1, 2, ...

   E X = λ,   D X = λ
```

Совпадение ожидания и дисперсии - признак, по которому пуассоновость
проверяют на данных: заметное превышение дисперсии над средним означает, что
события приходят не независимо, а группами.

**Набросок предельного перехода.** Подстановка `p = λ/n` в биномиальную
формулу:

```
   C(n,k) p^k q^(n−k) = [n(n−1)...(n−k+1) / n^k] · (λ^k / k!) · (1 − λ/n)^(n−k)
                          ↓ → 1                              ↓ → e^(−λ)
```

Первый множитель стремится к единице при фиксированном `k`, последний - к
`e^(−λ)` по второму замечательному пределу.

**Область применения** - подсчет редких событий на большом числе возможностей:
число запросов за интервал времени, число коллизий при хешировании, число
опечаток на страницу, число отказов дисков в кластере. Практическое правило
приближения: `n ≥ 100` и `np ≤ 10`.

Сумма независимых пуассоновских величин с параметрами `λ₁` и `λ₂` -
пуассоновская с параметром `λ₁ + λ₂`, что делает распределение удобным при
объединении потоков событий.

### 4.5.4 Равномерное и экспоненциальное распределения

**Равномерное на отрезке** `U(a, b)`:

```
   f(x) = 1 / (b − a)  на [a, b],  0 вне отрезка
   F(x) = (x − a) / (b − a)  на [a, b]

   E X = (a + b) / 2,   D X = (b − a)² / 12
```

Это распределение, соответствующее
[геометрической вероятности](probability-space.md#415-геометрическая-вероятность)
на отрезке, и исходный материал для
[метода обратной функции](random-variables.md#432-функция-распределения-и-ее-свойства):
стандартный генератор дает `U(0, 1)`, остальные распределения получаются
преобразованием.

**Экспоненциальное** `Exp(λ)`:

```
   f(x) = λ · e^(−λx),  x ≥ 0
   F(x) = 1 − e^(−λx)

   E X = 1/λ,   D X = 1/λ²
```

Экспоненциальное распределение - непрерывный аналог геометрического и
**единственное непрерывное** распределение без памяти:

```
   P(X > s + t | X > s) = P(X > t)
```

Содержательно: время до отказа не зависит от того, сколько устройство уже
проработало. Предположение реалистично для процессов без износа и
неприменимо там, где износ есть.

Связь с Пуассоном: если число событий за время `t` пуассоновское с параметром
`λt`, то промежутки между соседними событиями экспоненциальны с параметром
`λ`. Два распределения описывают один поток - счетом событий и промежутками
между ними.

Полезное свойство: минимум независимых экспоненциальных величин с параметрами
`λ₁, ..., λₙ` экспоненциален с параметром `λ₁ + ... + λₙ`. Отсюда стандартная
оценка времени до первого отказа в системе из `n` компонентов.

### 4.5.5 Нормальное распределение и правило трех сигм

`X ~ N(μ, σ²)` с плотностью

```
   f(x) = (1 / (σ√(2π))) · e^(−(x − μ)² / (2σ²))

   E X = μ,   D X = σ²
```

**Стандартизация** сводит любое нормальное распределение к `N(0, 1)`:

```
   Z = (X − μ) / σ  ~  N(0, 1)
```

**Правило трех сигм** - доли вероятности в симметричных окрестностях среднего:

| Интервал | Вероятность |
| --- | --- |
| `μ ± σ` | 0.6827 |
| `μ ± 2σ` | 0.9545 |
| `μ ± 3σ` | 0.9973 |

Выход за три сигмы происходит примерно в трех случаях из тысячи, что и делает
это правило основой контроля отклонений.

Особое положение нормального распределения объясняется
[центральной предельной теоремой](limit-theorems.md#464-центральная-предельная-теорема):
сумма большого числа независимых слагаемых сопоставимого масштаба
приближенно нормальна независимо от распределения слагаемых. Условие
«сопоставимого масштаба» существенно, и его нарушение - обычная причина
неприменимости нормальной модели.

**Предостережение для инженерных данных.** Время отклика сервиса, размеры
файлов и длительности сессий имеют **тяжелые хвосты**: редкие большие
значения встречаются несопоставимо чаще, чем предсказывает нормальная модель.
Для таких данных правило трех сигм систематически занижает риск, и вместо
среднего и `σ` используют квантили - медиану, `p95`, `p99`.

### 4.5.6 Сводная таблица

| Распределение | Схема | `E X` | `D X` |
| --- | --- | --- | --- |
| Бернулли `p` | одно испытание | `p` | `pq` |
| Биномиальное `Bin(n,p)` | число успехов в `n` испытаниях | `np` | `npq` |
| Геометрическое `p` | испытаний до первого успеха | `1/p` | `q/p²` |
| Гипергеометрическое | выборка без возвращения | `nK/N` | - |
| Пуассона `λ` | редкие события за интервал | `λ` | `λ` |
| Равномерное `U(a,b)` | точка наудачу на отрезке | `(a+b)/2` | `(b−a)²/12` |
| Экспоненциальное `λ` | время до события без памяти | `1/λ` | `1/λ²` |
| Нормальное `N(μ,σ²)` | сумма многих малых вкладов | `μ` | `σ²` |

Связи между строками таблицы существеннее самих формул:

```
   Бернулли ──сумма n независимых──▸ Биномиальное
                                        │
                                        │ n → ∞, p → 0, np → λ
                                        ▾
                                     Пуассона ◂──счет событий──┐
                                                               │
   Геометрическое ──непрерывный аналог──▸ Экспоненциальное ────┘
                                                          промежутки

   Биномиальное ──n → ∞ при фиксированном p (Муавр-Лаплас)──▸ Нормальное
```

### Типичные ошибки

1. **Путают две версии геометрического распределения.** Число испытаний дает
   `E = 1/p`, число неудач - `E = q/p`. Расхождение на единицу.
2. **Биномиальное применяют к выборке без возвращения.** Вероятность успеха
   меняется от испытания к испытанию; верно гипергеометрическое.
3. **Приближение Пуассона используют при большом `p`.** Предельный переход
   требует `p → 0` при `np → λ`; при `p = 0.5` приближение грубо.
4. **Правило трех сигм применяют к ненормальным данным.** Для распределений
   с тяжелыми хвостами - времен отклика, размеров файлов - оно занижает
   вероятность больших отклонений.
5. **Плотность нормального распределения путают с вероятностью.** В точке
   максимума `f(μ) = 1/(σ√(2π))`, и при малом `σ` это число превышает
   единицу.
6. **Отсутствие памяти переносят на процессы с износом.** Экспоненциальная
   модель не описывает старение: у изношенного оборудования вероятность
   отказа растет со временем работы.
7. **Считают, что `D = λ` выполняется для любого потока событий.** Равенство
   характеризует именно пуассоновский поток; группировка событий увеличивает
   дисперсию сверх среднего.
