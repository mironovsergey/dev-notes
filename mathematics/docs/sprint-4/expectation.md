# Числовые характеристики

[← К содержанию спринта](README.md)

Полное распределение известно редко, и обычно оно не нужно: для оценок и
сравнений достаточно двух чисел - центра и разброса. Математическое ожидание
линейно **без всяких предположений о зависимости**, и это свойство делает его
главным вычислительным инструментом раздела: величину, распределение которой
неизвестно, раскладывают в сумму индикаторов и складывают вероятности.

---

## 4.4 Числовые характеристики

### 4.4.1 Математическое ожидание, линейность

```
   Дискретная величина:   E X = Σ xᵢ · pᵢ
   Непрерывная величина:  E X = ∫ x · f(x) dx
```

Ожидание - взвешенное среднее значений, центр масс распределения. Оно не
обязано быть достижимым значением: ожидание числа очков на кости равно 3.5.

Ряд может расходиться, и тогда ожидания **не существует**. Пример -
распределение Коши с плотностью `1 / (π(1 + x²))`: интеграл расходится, и
среднее арифметическое выборки с ростом объема ни к чему не сходится. Любое
утверждение вида «среднее приближается к истинному значению» молча
предполагает существование ожидания.

**Ожидание функции** считается без нахождения распределения `g(X)`:

```
   E g(X) = Σ g(xᵢ) · pᵢ
```

**Линейность** - ключевое свойство:

```
   E(aX + bY + c) = a·E X + b·E Y + c
```

Независимость `X` и `Y` **не требуется**. Причина видна из определения через
исходы: `E X = Σ X(ω)·P(ω)`, а сумма функций суммируется поисходно
независимо от того, как эти функции связаны.

Для произведения дело обстоит иначе:

```
   E(XY) = E X · E Y   только при независимости
```

**Формула через хвосты.** Для неотрицательной целочисленной величины

```
   E X = Σ P(X ≥ k),   k = 1, 2, 3, ...
```

Вывод - перестановка порядка суммирования: значение `X = m` учитывается в
слагаемых `k = 1 ... m`, то есть ровно `m` раз. Формула незаменима, когда
`P(X ≥ k)` считается легко, а `P(X = k)` - нет: типичный случай -
максимум нескольких величин.

**Неравенство Йенсена.** Для выпуклой функции `g`

```
   E g(X) ≥ g(E X)
```

для вогнутой - знак противоположный. Отсюда `E X² ≥ (E X)²` и
`E (1/X) ≥ 1 / E X` для положительной `X`. Практический вывод: подставлять
среднее значение аргумента в нелинейную функцию нельзя - среднее время
отклика при средней нагрузке систематически меньше среднего времени отклика
при переменной нагрузке той же средней величины.

### 4.4.2 Дисперсия и стандартное отклонение

**Дисперсия** - ожидаемый квадрат отклонения от среднего:

```
   D X = E (X − E X)²
```

Раскрытие скобок с использованием линейности дает рабочую формулу:

```
   D X = E X² − (E X)²
```

Из нее сразу следует `E X² ≥ (E X)²`, то есть частный случай Йенсена, и
критерий вырожденности: `D X = 0` равносильно тому, что `X` почти наверное
равна константе.

**Стандартное отклонение** `σ = √(D X)` измеряется в тех же единицах, что и
сама величина, и потому пригодно для содержательных сравнений.

**Свойства.**

```
   D(aX + b) = a² · D X          сдвиг не влияет, масштаб входит квадратом
   D(X + Y) = D X + D Y + 2·cov(X, Y)
   D(X + Y) = D X + D Y          при независимости (достаточно
                                 некоррелированности)
```

Отсутствие линейности у дисперсии - причина, по которой оценки разброса
нельзя складывать напрямую, а стандартные отклонения независимых слагаемых
складываются «по теореме Пифагора»: `σ² = σ₁² + σ₂²`.

Для суммы `n` независимых одинаково распределенных величин

```
   D(X₁ + ... + Xₙ) = n·σ²,   σ(суммы) = σ√n
   D(среднего) = σ²/n,        σ(среднего) = σ/√n
```

Второе равенство - количественная основа
[закона больших чисел](limit-theorems.md#463-закон-больших-чисел) и оценки
точности метода Монте-Карло: чтобы уменьшить погрешность вдесятеро, объем
выборки нужно увеличить в сто раз.

### 4.4.3 Метод индикаторов

Прием состоит в разложении величины в сумму индикаторов и применении
линейности:

```
   X = I₁ + I₂ + ... + Iₙ   ⟹   E X = P(A₁) + P(A₂) + ... + P(Aₙ)
```

Зависимость индикаторов роли не играет - в этом вся сила метода. Ниже -
четыре стандартных применения.

**1. Неподвижные точки случайной перестановки.** `Iₖ = 1`, если элемент `k`
остался на месте; `P(Iₖ = 1) = 1/n`.

```
   E X = n · (1/n) = 1
```

Ожидаемое число неподвижных точек равно единице при любом `n`. Результат
согласуется с
[задачей о беспорядках](../sprint-2/inclusion-exclusion.md): доля перестановок
без неподвижных точек стремится к `1/e`.

**2. Число инверсий в случайной перестановке.** `I_ij = 1` для пары `i < j`,
стоящей в обратном порядке; по симметрии `P = 1/2`.

```
   E X = C(n,2) · (1/2) = n(n−1)/4
```

Величина задает среднее число обменов в сортировке вставками и объясняет ее
квадратичное поведение на случайных данных.

**3. Пустые ячейки.** `m` шаров независимо и равновероятно бросаются в `n`
ячеек. Для ячейки `k` вероятность остаться пустой равна `(1 − 1/n)^m`.

```
   E(пустых) = n · (1 − 1/n)^m ≈ n · e^(−m/n)
```

При `m = n` пустыми остаются примерно `n/e ≈ 0.37n` ячеек - оценка занятости
хеш-таблицы при коэффициенте заполнения 1.

**4. Число различных значений.** Из того же расчета: занятых ячеек в среднем
`n(1 − e^(−m/n))`.

Общий признак применимости: величина считает количество наступивших событий,
а найти ее распределение трудно.

### 4.4.4 Ковариация и коэффициент корреляции

**Ковариация** измеряет совместное отклонение от средних:

```
   cov(X, Y) = E[(X − E X)(Y − E Y)] = E(XY) − E X · E Y
```

Ковариация зависит от единиц измерения, поэтому ее нормируют:

```
   ρ(X, Y) = cov(X, Y) / (σ_X · σ_Y),   −1 ≤ ρ ≤ 1
```

Границы вытекают из неравенства Коши-Буняковского. Равенство `|ρ| = 1`
достигается тогда и только тогда, когда `Y = aX + b` почти наверное:
коэффициент корреляции измеряет **линейную** связь и ничего больше.

```
   Независимость  ⟹  cov = 0  ⟹  ρ = 0
   Обратное неверно
```

**Контрпример.** `X` принимает значения `−1, 0, 1` с вероятностью `1/3`,
`Y = X²`.

```
   E X = 0,  E(XY) = E X³ = 0   ⟹   cov = 0
   При этом Y полностью определяется X: зависимость функциональная
```

Некоррелированность означает отсутствие линейной связи, а не отсутствие
связи. Исключение - совместно нормальные величины: для них некоррелированность
равносильна независимости.

Для суммы нескольких величин

```
   D(X₁ + ... + Xₙ) = Σ D Xᵢ + 2 · Σ cov(Xᵢ, Xⱼ)  по парам i < j
```

Именно попарные ковариации мешают переносить метод индикаторов с ожидания на
дисперсию: ожидание суммы всегда равно сумме ожиданий, а дисперсия суммы -
нет.

### 4.4.5 Условное математическое ожидание

`E(X|B)` - ожидание, вычисленное в
[условном распределении](conditional.md#421-определение-условной-вероятности-теорема-умножения):

```
   E(X|B) = Σ xᵢ · P(X = xᵢ | B)
```

**Формула полного математического ожидания** повторяет структуру формулы
полной вероятности:

```
   E X = Σ E(X|Hᵢ) · P(Hᵢ)   по полной группе гипотез
```

Ее употребительная форма - **анализ по первому шагу**: неизвестная величина
выражается через саму себя после одного шага процесса.

**Пример 1. Число бросков монеты до первого герба.** Гипотезы по результату
первого броска:

```
   E = 1 + (1/2)·0 + (1/2)·E   ⟹   E = 2
```

Ответ совпадает с ожиданием
[геометрического распределения](distributions.md#452-геометрическое-распределение)
`1/p` при `p = 1/2`.

**Пример 2. Число бросков до серии «герб, герб».** Одного уравнения мало:
состояние процесса - длина уже набранной серии. Обозначив `E₀` и `E₁`
ожидаемое оставшееся число бросков при серии длины 0 и 1:

```
   E₀ = 1 + (1/2)E₁ + (1/2)E₀
   E₁ = 1 + (1/2)·0 + (1/2)E₀

   Решение:  E₀ = 6,  E₁ = 4
```

Для серии «герб, решка» тот же способ дает 4, а не 6, хотя обе пары
равновероятны: после неудачи в первом случае прогресс теряется полностью, во
втором - частично сохраняется. Расхождение показывает, что интуиция
«равновероятные события ждутся одинаково» неверна.

Пример 2 - готовый образец расчета для
[поглощающих цепей Маркова](markov-chains.md#483-классификация-состояний-достижимость-периодичность-поглощение),
где такие системы уравнений составляются механически.

### Типичные ошибки

1. **Для линейности требуют независимости.** `E(X + Y) = E X + E Y` верно
   всегда. Независимость нужна для `E(XY) = E X · E Y` и для
   `D(X + Y) = D X + D Y`.
2. **Дисперсию складывают для зависимых величин.** В общем случае добавляется
   удвоенная сумма попарных ковариаций.
3. **`D(aX) = a·D X`.** Масштаб входит в дисперсию квадратом: `a²·D X`.
4. **Подстановка среднего в нелинейную функцию.** `E g(X) ≠ g(E X)`; по
   Йенсену для выпуклой `g` левая часть не меньше правой.
5. **Некоррелированность принимают за независимость.** Обратное следствие
   верно только для совместно нормальных величин.
6. **Ожидание считают существующим всегда.** У распределения Коши его нет, и
   выборочное среднее не стабилизируется.
7. **Метод индикаторов переносят на дисперсию.** Складывать без учета
   ковариаций можно только ожидания.
