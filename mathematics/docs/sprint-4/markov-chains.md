# Цепи Маркова

[← К содержанию спринта](README.md)

Цепь Маркова описывает процесс, у которого будущее зависит от настоящего, но
не от того, как настоящее было достигнуто. Это самое слабое ограничение,
которое еще позволяет считать: вся динамика умещается в одну матрицу, вопросы
о поведении через `n` шагов сводятся к возведению ее в степень, а вопросы о
поведении в пределе - к решению линейной системы. Модель одновременно
вероятностная и графовая: носитель цепи - ориентированный взвешенный граф, и
классификация состояний повторяет понятия достижимости и сильной связности.

## 4.8 Цепи Маркова

### 4.8.1 Марковское свойство, матрица переходов

Последовательность случайных величин `X₀, X₁, X₂, ...` со значениями в
конечном множестве состояний образует **цепь Маркова**, если

```
   P(X_{n+1} = j | Xₙ = i, X_{n−1} = ..., X₀ = ...) = P(X_{n+1} = j | Xₙ = i)
```

Прошлое влияет на будущее только через настоящее. Если вероятности переходов
не зависят от номера шага, цепь **однородна**; далее рассматриваются только
такие.

**Матрица переходов** `P` размера `k × k`:

```
   P[i][j] = P(X_{n+1} = j | Xₙ = i)

   P[i][j] ≥ 0,   Σⱼ P[i][j] = 1  для каждой строки
```

Матрица со строчными суммами, равными единице, называется **стохастической**.
Каждая строка - распределение вероятностей выхода из состояния.

```
   Погода: Я - ясно, Д - дождь

           Я     Д
       Я  0.8   0.2          Из ясного дня в ясный переходят
       Д  0.4   0.6          с вероятностью 0.8
```

Эквивалентное представление - **граф переходов**: ориентированный граф, дуги
которого помечены вероятностями, а сумма меток исходящих дуг равна единице.
Такое представление делает применимыми понятия
[достижимости и сильной связности](../sprint-3/traversal.md#345-компоненты-сильной-связности).

**Выбор состояния определяет марковость.** Одна и та же система может быть
марковской при одном описании состояния и немарковской при другом. Процесс
ожидания серии «герб, герб» не марковский, если состоянием считать результат
последнего броска и число шагов, но становится марковским, когда состоянием
объявлена длина уже набранной серии - именно так он разобран в
[4.4.5](expectation.md#445-условное-математическое-ожидание). Общий прием:
расширить состояние, включив в него ту часть истории, от которой зависит
будущее.

### 4.8.2 Распределение через n шагов

Пусть `π₀` - строка начального распределения. Распределение после одного шага
получается умножением на матрицу справа, после `n` шагов - на ее степень:

```
   π₁ = π₀ · P
   πₙ = π₀ · Pⁿ
```

Элемент `(Pⁿ)[i][j]` равен вероятности перейти из `i` в `j` ровно за `n`
шагов. Это в точности **уравнение Чапмена-Колмогорова**:

```
   P^(n+m) = Pⁿ · P^m,   то есть  (P^(n+m))[i][j] = Σₖ (Pⁿ)[i][k] · (P^m)[k][j]
```

Формула читается как разбор по промежуточному состоянию `k` на шаге `n` - то
есть как [формула полной вероятности](conditional.md#423-формула-полной-вероятности)
с гипотезами «на шаге `n` цепь была в состоянии `k`».

Утверждение дословно повторяет теорему о
[степенях матрицы смежности](../sprint-3/representation.md#323-степени-матрицы-смежности),
где `(Aⁿ)[i][j]` считает маршруты длины `n`: разница лишь в том, что вместо
подсчета маршрутов суммируются их вероятности. Отсюда и совпадение приемов -
`Pⁿ` вычисляется
[быстрым возведением в степень](../sprint-1/number-theory.md#176-малая-теорема-ферма-и-быстрое-возведение-в-степень)
за `O(k³ log n)`.

### 4.8.3 Классификация состояний: достижимость, периодичность, поглощение

**Достижимость.** Состояние `j` достижимо из `i`, если `(Pⁿ)[i][j] > 0` для
некоторого `n ≥ 0`. Состояния **сообщаются**, если достижимы взаимно;
сообщаемость - отношение эквивалентности, и его классы называются **классами
сообщаемости**. Это те же
[компоненты сильной связности](../sprint-3/traversal.md#345-компоненты-сильной-связности)
графа переходов.

Цепь **неразложима** (неприводима), если класс один: из любого состояния
достижимо любое.

**Периодичность.** Период состояния `i` - наибольший общий делитель длин всех
циклов, по которым цепь возвращается в `i`:

```
   d(i) = НОД{ n ≥ 1 : (Pⁿ)[i][i] > 0 }
```

Состояние **апериодично**, если `d(i) = 1`. У состояний одного класса
сообщаемости период общий. Достаточное условие апериодичности - наличие петли
`P[i][i] > 0`.

```
   Периодическая цепь с периодом 2

       0 ⇄ 1        P = ⎡0 1⎤     Из состояния 0 цепь попадает
                        ⎣1 0⎦     в 0 только на четных шагах
```

**Возвратность и поглощение.** Состояние **возвратно**, если возвращение в
него происходит с вероятностью 1, и **невозвратно** иначе. Состояние
**поглощающее**, если `P[i][i] = 1`: попав в него, цепь остается навсегда.
В конечной цепи возвратны в точности состояния тех классов, из которых нет
выхода.

**Поглощающие цепи** решаются анализом по первому шагу. Обозначив `hᵢ`
вероятность поглощения в заданном состоянии при старте из `i` или `tᵢ`
ожидаемое время до поглощения, получаем линейные системы:

```
   hᵢ = Σⱼ P[i][j] · hⱼ,     h = 1 в целевом поглощающем состоянии, 0 в прочих
   tᵢ = 1 + Σⱼ P[i][j] · tⱼ,  t = 0 в поглощающих состояниях
```

**Разорение игрока.** Капитал меняется на `±1` за шаг; игра заканчивается при
`0` или `N`. При вероятности выигрыша `p` и `q = 1 − p`:

```
   Справедливая игра (p = 1/2):
      P(достичь N из i) = i/N
      ожидаемая длительность = i·(N − i)

   Несправедливая игра (p ≠ 1/2), r = q/p:
      P(достичь N из i) = (1 − rⁱ) / (1 − r^N)
```

При `p < 1/2` вероятность разорения экспоненциально близка к единице даже при
крошечном перевесе против игрока - количественная форма утверждения о
преимуществе заведения.

### 4.8.4 Стационарное распределение, эргодическая теорема

Распределение `π` **стационарно**, если оно не меняется при шаге цепи:

```
   π = π · P,   Σ πᵢ = 1,   πᵢ ≥ 0
```

Это система линейных уравнений: `π` - левый собственный вектор матрицы `P` с
собственным значением 1. Такой вектор существует у любой конечной
стохастической матрицы, но единственность и сходимость к нему требуют условий.

**Эргодическая теорема.** Если конечная цепь неразложима и апериодична, то

```
   1. Стационарное распределение существует и единственно
   2. πₙ → π при n → ∞ из любого начального распределения
   3. Pⁿ сходится к матрице, все строки которой равны π
   4. πᵢ = 1 / E(время возвращения в i)
```

Пункт 4 дает содержательное истолкование: `πᵢ` - доля времени, которую цепь
проводит в состоянии `i` на длинном горизонте.

**Роль каждого условия видна из контрпримеров.**

| Нарушено | Следствие |
| --- | --- |
| Неразложимость | стационарных распределений много, предел зависит от старта |
| Апериодичность | `π` единственно, но `πₙ` не сходится - колеблется |

Периодическая цепь `0 ⇄ 1` имеет `π = (0.5, 0.5)`, однако из состояния 0
распределение вечно чередуется между `(1, 0)` и `(0, 1)`. **Стационарное
распределение и предельное - разные вещи**, и совпадают они лишь при
апериодичности.

**Случайное блуждание по графу.** Для связного неориентированного графа без
изолированных вершин переход в равновероятного соседа дает цепь со
стационарным распределением

```
   π_v = deg(v) / (2m),   m - число ребер
```

Проверка прямой подстановкой: `Σ_u π_u · P[u][v] = Σ_{u ~ v} (deg(u)/2m) ·
(1/deg(u)) = deg(v)/2m`. Формула показывает, что случайное блуждание
задерживается в вершинах пропорционально их степени - соображение, лежащее в
основе всех мер центральности, основанных на блуждании.

Блуждание по двудольному графу периодично с периодом 2, поэтому предела не
имеет, хотя стационарное распределение у него есть.

### 4.8.5 Применение: PageRank

Модель: пользователь идет по случайной ссылке текущей страницы, а с
вероятностью `1 − d` переходит на случайную страницу сети. Значимость
страницы - ее вероятность в стационарном распределении такой цепи.

```
   G = d · P + ((1 − d) / n) · J,   J - матрица из единиц,  d ≈ 0.85
```

`P` строится по графу ссылок: строка страницы с `k` исходящими ссылками
содержит `1/k` в соответствующих позициях.

**Демпфирование решает три проблемы сразу.**

| Проблема | Без демпфирования | С демпфированием |
| --- | --- | --- |
| Страницы без ссылок | строка нулевая, матрица не стохастическая | строка заменяется равномерной |
| Замкнутые группы страниц | поглощают весь вес | утечка `1 − d` наружу |
| Периодичность | предела может не быть | все переходы положительны |

Матрица `G` строго положительна, поэтому цепь неразложима и апериодична, и по
эргодической теореме стационарное распределение существует, единственно и
достигается из любого начального приближения.

**Вычисление - степенной метод**, то есть буквально пункт 2 эргодической
теоремы:

```
   π ← равномерное распределение
   повторять:  π ← π · G
   до стабилизации
```

Скорость сходимости определяется вторым по модулю собственным значением,
которое для такой матрицы не превосходит `d`. При `d = 0.85` погрешность
убывает примерно в 6.7 раза за десять итераций, и на практике хватает
нескольких десятков проходов. Матрица `G` плотная, но при умножении она не
строится: слагаемое `((1 − d)/n)·J` дает одинаковую добавку ко всем
координатам, а `P` разрежена, и итерация стоит `O(число ссылок)`.

### Типичные ошибки

1. **Стационарное распределение отождествляют с предельным.** У периодической
   цепи `π` существует, но `πₙ` не сходится. Предел требует апериодичности.
2. **Эргодическую теорему применяют к разложимой цепи.** При нескольких
   классах сообщаемости стационарных распределений бесконечно много, и
   результат зависит от старта.
3. **Путают строчную и столбцовую стохастичность.** При записи `π = πP`
   распределение - строка, а единице равны суммы по **строкам** `P`. При
   противоположном соглашении `π = Pπ` матрицу нужно транспонировать.
4. **Марковское свойство проверяют, не уточнив состояние.** Немарковский
   процесс часто становится марковским после расширения состояния.
5. **Считают, что достижимость гарантирует возвращение.** В конечной цепи
   возвратны только состояния классов без выхода; из невозвратного состояния
   цепь уходит навсегда.
6. **PageRank считают без демпфирования.** Замкнутые группы страниц соберут
   весь вес, а страницы без исходящих ссылок нарушат стохастичность матрицы.
7. **В разорении игрока пренебрегают малым перевесом.** При `p < 1/2`
   вероятность разорения стремится к единице экспоненциально по величине
   начального капитала.
