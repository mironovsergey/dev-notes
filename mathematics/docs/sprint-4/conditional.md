# Условная вероятность и независимость

[← К содержанию спринта](README.md)

Условная вероятность отвечает на вопрос, как меняется оценка события при
поступлении новой информации. Формально это простое деление, но именно здесь
сосредоточена основная часть ошибок: `P(A|B)` и `P(B|A)` подменяют друг друга,
базовую частоту отбрасывают, а независимость проверяют попарно вместо
совокупной.

---

## 4.2 Условная вероятность и независимость

### 4.2.1 Определение условной вероятности, теорема умножения

При `P(B) > 0`

```
   P(A|B) = P(A ∩ B) / P(B)
```

Смысл определения - сужение пространства: известно, что исход лежит в `B`,
поэтому `B` становится новым достоверным событием, а вероятности внутри него
пересчитываются пропорционально, чтобы сумма снова равнялась единице.

При фиксированном `B` функция `A ↦ P(A|B)` сама является вероятностью: она
неотрицательна, `P(Ω|B) = 1`, и она счетно-аддитивна. Поэтому все следствия
аксиом переносятся на условные вероятности без изменений, в частности
`P(Ā|B) = 1 − P(A|B)`.

Существенно, что `P(A|B̄)` с `P(A|B)` формулой дополнения **не**
связано: дополняется событие, а не условие.

**Теорема умножения.** Определение, переписанное иначе:

```
   P(A ∩ B) = P(B) · P(A|B) = P(A) · P(B|A)
```

**Цепное правило** для `n` событий:

```
   P(A₁ ∩ ... ∩ Aₙ) = P(A₁) · P(A₂|A₁) · P(A₃|A₁ ∩ A₂) · ...
```

Это основной способ считать вероятности последовательных выборов. Пример -
вероятность отсутствия совпадений среди `k` дней рождения при `n = 365`:
каждый следующий человек должен попасть в еще не занятый день,

```
   P = (1 − 1/n) · (1 − 2/n) · ... · (1 − (k−1)/n)
```

Величина разобрана в [4.7.1](algorithms.md#471-парадокс-дней-рождения).

### 4.2.2 Независимость событий: попарная и в совокупности

События `A` и `B` **независимы**, если

```
   P(A ∩ B) = P(A) · P(B)
```

При `P(B) > 0` это равносильно `P(A|B) = P(A)`: знание о `B` не меняет оценку
`A`. Определение через произведение предпочтительнее - оно симметрично и не
требует положительности.

Независимость - утверждение о **мере**, а не о причинных связях. Одни и те же
события могут быть независимы при одном распределении и зависимы при другом.

**Независимость и несовместность - разные вещи, почти противоположные.** Если
`A ∩ B = ∅` и обе вероятности положительны, то `P(A ∩ B) = 0`, тогда как
`P(A)·P(B) > 0`, значит события **зависимы**: наступление одного полностью
исключает другое, то есть дает о нем максимум информации.

**Независимость в совокупности** для `A₁, ..., Aₙ` требует, чтобы равенство

```
   P(A_i₁ ∩ ... ∩ A_ik) = P(A_i₁) · ... · P(A_ik)
```

выполнялось для **всех** поднаборов, а не только для пар. Всего условий
`2ⁿ − n − 1`.

**Пример Бернштейна.** Тетраэдр, грани которого окрашены: первая в красный,
вторая в синий, третья в зеленый, четвертая содержит все три цвета. Бросаем
и смотрим на грань, на которую тетраэдр упал.

```
   A = «есть красный», B = «есть синий», C = «есть зеленый»

   P(A) = P(B) = P(C) = 2/4 = 1/2
   P(A ∩ B) = 1/4 = P(A)·P(B)      попарно независимы, и так для всех пар
   P(A ∩ B ∩ C) = 1/4 ≠ 1/8        в совокупности зависимы
```

Попарная независимость слабее совокупной, и обратной импликации нет.

Независимость может исчезать при обусловливании. Два независимых броска
монеты перестают быть независимыми, если известна четность суммы гербов: там
результат второго броска однозначно определяется первым.

### 4.2.3 Формула полной вероятности

Пусть `H₁, ..., Hₙ` - полная группа событий (гипотезы) с `P(H_i) > 0`. Тогда

```
   P(A) = Σ P(H_i) · P(A|H_i),   i = 1 ... n
```

Вывод: `A` разбивается на несовместные части `A ∩ H_i`, к ним применяется
аддитивность, каждое слагаемое раскрывается теоремой умножения.

```
   Два ящика. В первом 3 белых и 7 черных шаров, во втором 6 белых и 4 черных.
   Ящик выбирается равновероятно, из него берется один шар.

   P(белый) = 1/2 · 3/10 + 1/2 · 6/10 = 9/20 = 0.45
```

Формула - вероятностный аналог разбора случаев, и в этом качестве она лежит в
основе **анализа по первому шагу**: вероятность или ожидание для процесса
выражается через те же величины после одного шага. Прием применяется в
[4.4.5](expectation.md#445-условное-математическое-ожидание) и в
[цепях Маркова](markov-chains.md).

### 4.2.4 Формула Байеса, априорная и апостериорная вероятность

Подстановка полной вероятности в теорему умножения дает

```
   P(H_i|A) = P(H_i) · P(A|H_i) / Σ P(H_j) · P(A|H_j)
```

Терминология: `P(H_i)` - **априорная** вероятность гипотезы (до наблюдения),
`P(A|H_i)` - **правдоподобие** наблюдения при гипотезе, `P(H_i|A)` -
**апостериорная** вероятность (после наблюдения).

Для двух гипотез удобнее форма через **шансы**: знаменатель, одинаковый для
всех гипотез, сокращается.

```
   P(H|A)     P(H)     P(A|H)
   ────── =  ────── · ────────
   P(H̄|A)     P(H̄)     P(A|H̄)

   апостериорные   априорные    отношение
      шансы          шансы    правдоподобий
```

Запись показывает суть: наблюдение не задает вероятность гипотезы, а лишь
**умножает** прежние шансы на коэффициент. Если априорные шансы малы, сильное
правдоподобие может их не перебить.

### 4.2.5 Парадокс базовой частоты

Тест на заболевание выявляет больного с вероятностью 0.99 и ошибочно
срабатывает на здоровом с вероятностью 0.01. Заболеванием страдает 0.1%
населения. Тест положителен - какова вероятность болезни?

Подсчет на 100 000 человек делает ответ очевидным без формул:

| Группа | Человек | Тест положителен |
| --- | --- | --- |
| Больны | 100 | 99 |
| Здоровы | 99 900 | 999 |
| Всего положительных | | 1098 |

```
   P(болен | тест положителен) = 99 / 1098 ≈ 0.090
```

Около 9%, а не 99%. Причина - **базовая частота**: здоровых в тысячу раз
больше, поэтому их редкие ошибочные срабатывания численно перевешивают
верные срабатывания на больных. В форме шансов: априорные шансы `1 : 999`,
отношение правдоподобий `99`, апостериорные шансы `99 : 999`.

Тот же расчет объясняет поведение любых систем обнаружения редких событий:
мониторинг с отличной по отдельности точностью при редкой аварии выдает
поток ложных срабатываний, и снизить их можно только повышением
специфичности либо сокращением числа проверок.

**Задача Монти Холла** - тот же эффект в другом виде. Три двери, за одной
приз; игрок выбирает дверь, ведущий, знающий расположение приза, открывает
одну из оставшихся - пустую - и предлагает сменить выбор.

```
   P(приз за первоначальной дверью) = 1/3      априорно
   Ведущий открывает пустую дверь всегда, поэтому его действие
   не несет информации о первоначальной двери: P остается 1/3.
   Вся оставшаяся вероятность 2/3 переходит на единственную
   нераскрытую дверь.  Менять выбор выгодно вдвое.
```

Существенно, что ведущий знает, где приз, и открывает заведомо пустую дверь.
Если бы он открывал дверь наугад и она случайно оказалась пустой,
правдоподобия сравнялись бы и обе двери имели бы по `1/2`. Условие
эксперимента, а не арифметика, определяет ответ.

### Типичные ошибки

1. **Подмена `P(A|B)` на `P(B|A)`.** Известна как «ошибка прокурора»: из того,
   что совпадение улик при невиновности маловероятно, не следует, что
   маловероятна невиновность. Величины связаны формулой Байеса и совпадают
   только при `P(A) = P(B)`.
2. **Игнорирование базовой частоты.** Ответ 99% вместо 9% в примере выше.
   Априорная вероятность входит в формулу и при редком событии определяет
   результат.
3. **Попарную независимость принимают за совокупную.** Пример Бернштейна:
   все пары независимы, тройка - нет.
4. **Несовместность считают независимостью.** Несовместные события с
   положительными вероятностями всегда зависимы.
5. **Обусловливание на событие нулевой вероятности.** Выражение `P(A|B)` при
   `P(B) = 0` не определено; для непрерывных величин требуется отдельная
   конструкция условной плотности.
6. **Забывают, что независимость не сохраняется при обусловливании.**
   Независимые события могут стать зависимыми при известном третьем событии,
   и наоборот.
7. **В задаче Монти Холла считают `1/2`.** Ответ зависит от протокола
   действий ведущего; при осведомленном ведущем смена выбора дает `2/3`.
