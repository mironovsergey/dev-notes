# Неравенства и предельные теоремы

[← К содержанию спринта](README.md)

Раздел отвечает на вопрос, насколько сильно случайная величина может
отклониться от своего среднего. Ответы выстраиваются по возрастанию
требований и точности: Марков использует только ожидание, Чебышев добавляет
дисперсию, Чернов - независимость слагаемых, и каждое следующее условие
превращает полиномиальную оценку в экспоненциальную. Предельные теоремы
описывают тот же предмет в пределе: закон больших чисел - куда сходится
среднее, центральная предельная теорема - как выглядит отклонение.

---

## 4.6 Неравенства и предельные теоремы

### 4.6.1 Неравенство Маркова

Для **неотрицательной** случайной величины `X` и любого `a > 0`

```
   P(X ≥ a) ≤ E X / a
```

**Доказательство** в одну строку. Из неотрицательности

```
   E X ≥ E(X · I[X ≥ a]) ≥ a · P(X ≥ a)
```

первое неравенство отбрасывает вклад исходов `X < a`, второе заменяет `X` на
`a` там, где `X ≥ a`.

Неравенство слабое, но требует только существования ожидания и никаких
сведений о распределении. Эквивалентная запись `P(X ≥ k · E X) ≤ 1/k` читается
так: превысить среднее в `k` раз можно не чаще, чем в доле `1/k` случаев.

Условие неотрицательности существенно: для величины, принимающей значения
обоих знаков, оценка неверна.

### 4.6.2 Неравенство Чебышева

Для величины с конечной дисперсией и любого `ε > 0`

```
   P(|X − E X| ≥ ε) ≤ D X / ε²
```

**Доказательство** - применение неравенства Маркова к неотрицательной
величине `Y = (X − E X)²` при `a = ε²`:

```
   P(|X − E X| ≥ ε) = P(Y ≥ ε²) ≤ E Y / ε² = D X / ε²
```

В единицах стандартного отклонения, при `ε = kσ`:

```
   P(|X − E X| ≥ kσ) ≤ 1/k²
```

Отклонение более чем на три сигмы имеет вероятность не выше `1/9 ≈ 0.111`
**для любого распределения**. Сравнение с
[правилом трех сигм](distributions.md#455-нормальное-распределение-и-правило-трех-сигм),
где та же вероятность равна `0.0027`, показывает цену универсальности:
оценка Чебышева верна всегда и потому груба на порядки для конкретных
распределений.

Оценка неулучшаема в классе всех распределений: существует величина, для
которой она достигается с равенством.

### 4.6.3 Закон больших чисел

Пусть `X₁, X₂, ...` независимы, одинаково распределены, `E Xᵢ = μ`, дисперсия
конечна. Обозначим выборочное среднее `X̄ₙ = (X₁ + ... + Xₙ)/n`.

**Закон больших чисел в форме Чебышева (слабый).** Для любого `ε > 0`

```
   P(|X̄ₙ − μ| ≥ ε) → 0   при n → ∞
```

**Доказательство.** Ожидание среднего равно `μ`, дисперсия равна `σ²/n`
(см. [4.4.2](expectation.md#442-дисперсия-и-стандартное-отклонение)).
Подстановка в неравенство Чебышева:

```
   P(|X̄ₙ − μ| ≥ ε) ≤ σ² / (n ε²) → 0
```

**Усиленный закон больших чисел (Колмогоров)** утверждает больше: `X̄ₙ → μ`
почти наверное, то есть с вероятностью 1 последовательность средних сходится
к `μ`, и достаточно существования ожидания.

Частный случай для индикаторов - **теорема Бернулли**: частота наступления
события сходится к его вероятности. Именно она связывает аксиоматическое
определение вероятности с наблюдаемыми частотами и оправдывает измерение
вероятностей экспериментом, включая
[метод Монте-Карло](algorithms.md#475-метод-монте-карло-алгоритмы-лас-вегаса-и-монте-карло).

**Что закон не утверждает.** Сходится **среднее**, а не сумма. Для
симметричного блуждания

```
   Sₙ − n/2  имеет порядок √n  и неограниченно растет
   Sₙ/n − 1/2  имеет порядок 1/√n  и стремится к нулю
```

Абсолютное отклонение числа гербов от `n/2` увеличивается; к нулю стремится
лишь отклонение доли. Заблуждение, будто отставший исход обязан «догонять», -
ошибка игрока, и она прямо противоречит
[отсутствию памяти](distributions.md#452-геометрическое-распределение) у
независимых испытаний.

### 4.6.4 Центральная предельная теорема

Закон больших чисел говорит, куда сходится среднее. ЦПТ описывает **форму**
отклонения.

Пусть `X₁, X₂, ...` независимы, одинаково распределены, `E Xᵢ = μ`,
`D Xᵢ = σ² < ∞`. Тогда

```
   Sₙ − nμ
   ───────  ⟶  N(0, 1)   по распределению при n → ∞
    σ√n
```

Равносильная запись: `X̄ₙ ≈ N(μ, σ²/n)`.

Замечательна независимость предела от распределения слагаемых: нужны лишь
конечная дисперсия и сопоставимость вкладов. Этим объясняется повсеместность
нормального распределения - величина, складывающаяся из множества мелких
независимых воздействий, приближенно нормальна.

**Теорема Муавра-Лапласа** - исторически первый случай: биномиальное
распределение при больших `n` приближается нормальным с параметрами `np` и
`npq`. Приближение считается приемлемым при `npq > 9`.

**Практическое следствие - точность выборочных оценок.** Из `σ(X̄ₙ) = σ/√n` и
нормальности:

```
   доверительный интервал 95%:   X̄ₙ ± 1.96 · σ/√n
```

Погрешность убывает как `1/√n`, а не как `1/n`. Отсюда правило, определяющее
стоимость любых симуляций: **дополнительный верный знак требует стократного
увеличения выборки**.

**Границы применимости.** Требуется конечная дисперсия: для распределения
Коши ЦПТ неприменима, и среднее `n` наблюдений распределено так же, как одно
наблюдение. Требуется и сопоставимость слагаемых - если одно слагаемое
доминирует над суммой остальных, предельного перехода к нормальности нет.

### 4.6.5 Оценки Чернова

Чебышев дает убывание вероятности отклонения лишь степенным образом. Если
известно, что величина - **сумма независимых** слагаемых, оценку можно
усилить до экспоненциальной.

Пусть `X = X₁ + ... + Xₙ`, слагаемые независимы и принимают значения `0` и
`1`, `μ = E X`. Тогда для `δ > 0`

```
   P(X ≥ (1 + δ)μ) ≤ exp( −δ²μ / (2 + δ) )
   P(X ≤ (1 − δ)μ) ≤ exp( −δ²μ / 2 ),   0 < δ < 1
```

Метод доказательства - **экспоненциальное преобразование**: неравенство
Маркова применяется к `e^(tX)`, ожидание произведения распадается по
независимости, параметр `t` подбирается оптимально. Именно на шаге
факторизации используется независимость, и без нее оценка неверна.

**Сравнение на одном примере.** `n = 1000` бросков симметричной монеты,
`μ = 500`, `σ ≈ 15.8`. Оценки вероятности `P(X ≥ 600)`:

| Метод | Использует | Оценка |
| --- | --- | --- |
| Марков | `E X` | `≈ 0.83` |
| Чебышев | `E X`, `D X` | `≈ 0.025` |
| Чернов | независимость слагаемых | `≈ 1.1 · 10⁻⁴` |
| Точное значение | все распределение | `≈ 1.4 · 10⁻¹⁰` |

Разрыв в четыре порядка между Чебышевым и Черновым - причина, по которой в
анализе рандомизированных алгоритмов используют именно оценки Чернова: они
позволяют утверждать, что отклонение не превысит заданной границы **с
вероятностью `1 − 1/nᶜ`**, то есть «с высокой вероятностью».

**Типичное применение - балансировка нагрузки.** При равномерном
распределении `n` задач по `n` серверам ожидаемая нагрузка сервера равна
единице, а максимальная нагрузка с высокой вероятностью не превосходит
`O(log n / log log n)`. Оценка Чернова дает границу для одного сервера,
[неравенство Буля](probability-space.md#414-аксиомы-колмогорова-и-следствия-из-них)
распространяет ее на все `n` серверов сразу. Связка «Чернов плюс union bound» -
стандартная схема доказательств этого типа.

### Типичные ошибки

1. **Неравенство Маркова применяют к величине, принимающей отрицательные
   значения.** Условие `X ≥ 0` обязательно.
2. **Закон больших чисел толкуют как выравнивание сумм.** Стремится к нулю
   отклонение **доли**; абсолютное отклонение суммы растет как `√n`. Ошибка
   игрока.
3. **Закон больших чисел смешивают с ЦПТ.** Первый утверждает сходимость
   среднего к константе, вторая описывает распределение отклонения от нее.
4. **ЦПТ применяют при бесконечной дисперсии или доминирующем слагаемом.**
   Для распределения Коши среднее `n` наблюдений не концентрируется вовсе.
5. **Считают, что точность симуляции растет линейно с числом опытов.**
   Погрешность убывает как `1/√n`: уменьшение вдесятеро стоит стократного
   увеличения выборки.
6. **Оценку Чернова применяют к зависимым слагаемым.** Доказательство
   опирается на факторизацию `E e^(tX)`, которая без независимости неверна.
7. **Оценку Чебышева принимают за точное значение.** Это верхняя граница; для
   конкретного распределения истинная вероятность обычно на порядки меньше.
