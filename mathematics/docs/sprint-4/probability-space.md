# Вероятностное пространство

[← К содержанию спринта](README.md)

Теория вероятностей начинается не с формулы, а с выбора модели: что считать
исходом опыта и почему исходы равноправны. Классическое определение сводит
вероятность к подсчету и потому опирается на
[комбинаторику](../sprint-2/README.md), но работает лишь при конечном числе
равновозможных исходов. Аксиоматика Колмогорова снимает оба ограничения и
делает вероятность частным случаем меры.

---

## 4.1 Вероятностное пространство

### 4.1.1 Испытание, элементарный исход, событие

**Испытание** - воспроизводимый опыт с неоднозначным результатом.
**Элементарный исход** `ω` - один из взаимоисключающих результатов испытания.
**Пространство элементарных исходов** `Ω` - множество всех таких результатов.

**Событие** - подмножество `A ⊆ Ω`. Событие **наступило**, если реализовавшийся
исход принадлежит `A`.

```
   Бросок двух различимых костей

   Ω = {(1,1), (1,2), ..., (6,6)},   |Ω| = 36

   A = «сумма равна 7» = {(1,6), (2,5), (3,4), (4,3), (5,2), (6,1)}
   |A| = 6
```

Два крайних случая: `Ω` - **достоверное** событие, `∅` - **невозможное**.

Выбор `Ω` не диктуется задачей, а является модельным решением, и от него
зависит ответ. Классический пример - ошибка д'Аламбера в задаче о двух
монетах:

```
   Ω₁ = {ГГ, ГР, РГ, РР}       четыре равновозможных исхода
   Ω₂ = {0 гербов, 1, 2}       три исхода, но не равновозможных

   P(ровно один герб) = 2/4 = 1/2  по Ω₁,  и ошибочно 1/3 по Ω₂
```

Правильно `Ω₁`: монеты независимы и каждая пара результатов встречается
одинаково часто. `Ω₂` получается из `Ω₁` склейкой двух исходов в один, и
равновозможность при склейке теряется.

Практическое правило: элементарные исходы выбираются так, чтобы их
равновозможность следовала из симметрии самого опыта. Если этого обосновать
не удается, классическое определение неприменимо.

### 4.1.2 Операции над событиями, несовместность

События - множества, поэтому операции над ними теоретико-множественные, а
читаются они на языке логики.

| Запись | Теория множеств | Логика |
| --- | --- | --- |
| `A ∪ B` | объединение | наступило `A` **или** `B` |
| `A ∩ B` | пересечение | наступили `A` **и** `B` |
| `Ā` | дополнение до `Ω` | `A` **не** наступило |
| `A \ B` | разность | `A` наступило, `B` нет |
| `A ⊆ B` | включение | `A` **влечет** `B` |

События **несовместны**, если `A ∩ B = ∅`: вместе наступить не могут.

**Полная группа событий** - набор `H₁, ..., Hₙ`, попарно несовместных, в
объединении дающих `Ω`. Полная группа - это в точности
[разбиение](../sprint-1/relations.md#133-отношение-эквивалентности-и-разбиение)
множества `Ω`.

Законы де Моргана переносятся дословно и дают основной рабочий прием -
переход к дополнению:

```
   A₁ ∪ A₂ ∪ ... ∪ Aₙ  =  Ā₁ ∩ Ā₂ ∩ ... ∩ Āₙ
```

Читается так: «хотя бы одно из событий наступило» равносильно «неверно, что
ни одно не наступило». Считать вероятность отрицания почти всегда проще: одно
пересечение вместо суммы по всем непустым подмножествам.

### 4.1.3 Классическое определение и комбинаторный подсчет

Если `Ω` конечно и все исходы равновозможны, то

```
   P(A) = |A| / |Ω|
```

Вычисление вероятности сводится к двум задачам подсчета, то есть целиком к
комбинаторике. Схема выборки определяет, что именно считать.

```
   Урна: N шаров, из них K белых. Выбирают n шаров без возвращения.
   Вероятность ровно k белых (гипергеометрическое распределение):

   P = C(K,k) · C(N−K, n−k) / C(N,n)
```

Числитель: выбрать `k` белых из `K` и остальные `n−k` из `N−K` небелых;
знаменатель: все выборки размера `n`. Обе величины - обычные
[сочетания](../sprint-2/selections.md).

Один и тот же ответ получается при разных `Ω`, если считать согласованно.
Задача «два шара из урны с 3 белыми и 2 черными, оба белые»:

```
   Ω как неупорядоченные пары:  C(3,2) / C(5,2) = 3 / 10
   Ω как упорядоченные пары:  (3·2) / (5·4) = 6 / 20 = 3 / 10
```

Ошибка возникает, когда числитель считают в одной схеме, а знаменатель в
другой - например, сочетания сверху и размещения снизу.

Границы применимости: `Ω` бесконечно (нужна геометрическая вероятность или
общая аксиоматика) либо исходы не равновозможны (нужны веса).

### 4.1.4 Аксиомы Колмогорова и следствия из них

**Вероятностное пространство** - тройка `(Ω, F, P)`, где `F` - **σ-алгебра**
подмножеств `Ω`, то есть набор событий, замкнутый относительно дополнения и
счетных объединений и содержащий `Ω`, а `P: F → R` удовлетворяет трем
аксиомам:

```
   1. Неотрицательность:  P(A) ≥ 0
   2. Нормировка:         P(Ω) = 1
   3. Счетная аддитивность: для попарно несовместных A₁, A₂, ...
      P(A₁ ∪ A₂ ∪ ...) = P(A₁) + P(A₂) + ...
```

σ-алгебра нужна не из формальной аккуратности: на отрезке существуют
подмножества, которым нельзя согласованно приписать длину, и они исключаются
из числа событий. Для конечного или счетного `Ω` можно брать `F = 2^Ω`, и
вопрос не возникает.

**Следствия.** Все выводятся из трех аксиом, дополнительных предположений не
требуется.

```
   P(∅) = 0
   P(Ā) = 1 − P(A)
   A ⊆ B  ⟹  P(A) ≤ P(B)            монотонность
   0 ≤ P(A) ≤ 1
   P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
```

Последнее равенство - частный случай
[формулы включений-исключений](../sprint-2/inclusion-exclusion.md); для `n`
событий она выглядит так же, со знакопеременной суммой по всем непустым
подмножествам индексов.

Из монотонности и аддитивности следует **неравенство Буля**, оно же
`union bound`:

```
   P(A₁ ∪ ... ∪ Aₙ) ≤ P(A₁) + ... + P(Aₙ)
```

Несовместность не требуется. Это самая употребительная оценка в анализе
алгоритмов: чтобы доказать, что **ни одно** из `n` плохих событий не
произойдет, достаточно показать, что каждое имеет вероятность меньше `1/n²` -
тогда вероятность хотя бы одного не превосходит `1/n`.

### 4.1.5 Геометрическая вероятность

Если исход - точка области `Ω` и никакая часть области не выделена, то
вероятность события `A ⊆ Ω` определяется отношением мер (длин, площадей,
объемов):

```
   P(A) = mes(A) / mes(Ω)
```

Определение согласовано с аксиомами: мера неотрицательна и аддитивна.

**Задача о встрече.** Двое приходят в случайные моменты часа независимо друг
от друга и ждут 15 минут. Обозначив моменты прихода `x, y ∈ [0, 60]`, получаем
`Ω` - квадрат со стороной 60, событие - полоса `|x − y| ≤ 15`:

```
   Площадь дополнения - два треугольника с катетом 45:

   P = 1 − 2 · (45² / 2) / 60² = 1 − 2025/3600 = 7/16 = 0.4375
```

**Парадокс Бертрана.** «В окружность вписан правильный треугольник. Какова
вероятность, что случайная хорда длиннее его стороны?» Ответ зависит от того,
что означает «случайная хорда»:

| Способ выбора | Ответ |
| --- | --- |
| Случайные концы на окружности | `1/3` |
| Случайное расстояние от центра до хорды | `1/2` |
| Случайная середина хорды в круге | `1/4` |

Все три вычисления корректны, но задают разные меры на множестве хорд.
Парадокс показывает, что «наудачу» - не спецификация: пока не указано
вероятностное пространство, задача не поставлена. То же требование
предъявляется к генератору случайных объектов в коде: «случайное дерево» или
«случайный граф» без указания распределения смысла не имеет.

### Типичные ошибки

1. **Равновозможность принимают без основания.** Ошибка д'Аламбера: исходы
   «0, 1, 2 герба» не равновероятны, и классическая формула к ним
   неприменима. Равновозможность должна следовать из симметрии опыта.
2. **`P(A ∪ B) = P(A) + P(B)` без проверки несовместности.** В общем случае
   вычитается `P(A ∩ B)`; иначе сумма легко превысит единицу.
3. **Несовместность путают с независимостью.** Это противоположные по смыслу
   свойства: несовместные события с положительными вероятностями всегда
   зависимы, см. [4.2.2](conditional.md#422-независимость-событий-попарная-и-в-совокупности).
4. **Числитель и знаменатель считают в разных схемах.** Сочетания сверху и
   размещения снизу дают ответ, отличающийся на `k!`.
5. **«Наудачу» без указания меры.** Парадокс Бертрана: у одной формулировки
   три разных корректных ответа.
6. **Из `P(A) = 0` заключают невозможность.** Для непрерывных моделей
   вероятность нуль имеют и вполне возможные события: попадание точно в
   заданную точку отрезка.
