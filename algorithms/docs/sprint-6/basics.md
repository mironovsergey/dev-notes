# Основные понятия теории графов

## 6.1 Основные понятия теории графов

**Граф** - способ описать объекты и связи между ними. Объекты называются
вершинами, связи - ребрами.

Графы - самая общая из структур, разобранных в курсе.
[Дерево](../sprint-5/binary-trees.md#51-бинарные-деревья) - частный случай
графа (связный, без циклов),
[связный список](../sprint-2/linked-lists.md#22-связные-списки) - частный случай
дерева. Поэтому алгоритмы на графах применимы и к тому, и к другому.

---

### 6.1.1 Основные понятия теории множеств

Граф записывается как пара множеств `G = (V, E)`.

| Обозначение | Смысл |
| --- | --- |
| `V` | множество вершин |
| `E` | множество ребер |
| `\|V\|` | число вершин |
| `\|E\|` | число ребер |
| `v ∈ V` | `v` является вершиной графа |
| `e = (u, v)` | ребро задано **упорядоченной** парой - ориентированное |
| `e = {u, v}` | ребро задано **неупорядоченной** парой - неориентированное |

Различие круглых и фигурных скобок существенно: `(u, v) ≠ (v, u)`, тогда как
`{u, v} = {v, u}`.

Оценки сложности в этом спринте всегда записываются через `|V|` и `|E|`, потому
что от их соотношения зависит выбор алгоритма и способа хранения графа.

---

### 6.1.2 Основные понятия теории графов

**Смежность и инцидентность.** Вершины `v` и `w` **смежны**, если между ними
есть ребро. Вершина и ребро **инцидентны**, если вершина - конец этого ребра.

У каждого ребра ровно две инцидентные вершины; у вершины может быть любое число
инцидентных ребер, включая ноль.

**Степень вершины** - число инцидентных ей ребер. В ориентированном графе
различают **степень входа** (число входящих ребер) и **степень выхода** (число
исходящих).

```
Неориентированный граф            Ориентированный граф

      (A)───(B)                        (A)──→(B)
       │  ╲  │                          │  ╲  ↑
       │   ╲ │                          ↓    ╲│
      (D)───(C)                        (D)←──(C)

  степень A = 3                   вход A = 0, выход A = 2
```

**Виды графов:**

- **ориентированный** (орграф) - ребра имеют направление;
- **взвешенный** - каждому ребру приписано число, его вес;
- **петля** - ребро из вершины в саму себя;
- **кратные ребра** - несколько ребер между одной парой вершин;
- **простой граф** - без петель и кратных ребер.

**Пути.**

- **Маршрут** - последовательность вершин, в которой соседние соединены ребрами.
- **Путь** - маршрут, в котором не повторяются ребра.
- **Простой путь** - маршрут, в котором не повторяются вершины.
- **Длина пути** - количество ребер в нем.
- **Вес пути** - сумма весов его ребер.
- **Расстояние** между `v` и `w` - длина кратчайшего пути из `v` в `w`.
- **Цикл** - путь, у которого начальная и конечная вершины совпадают.

Разница между маршрутом и путем часто теряется, но она важна:
`A → B → A → D` - маршрут длины 3, а не путь, потому что ребро `AB`
использовано дважды.

Путей между двумя вершинами может быть много или не быть вовсе. Расстояние
определяется по кратчайшему: в графе выше `A → B` дает расстояние 1, хотя
существуют и `A → C → B`, и `A → D → C → B`.

### 6.1.3 Разбиение графа на части

**Связный граф** - граф, в котором между любой парой вершин существует путь.
Иначе граф **несвязный**.

**Компонента связности** вершины `v` - множество всех вершин, до которых
существует путь из `v`. Любой неориентированный граф однозначно разбивается на
компоненты связности; между вершинами разных компонент ребер нет по
определению.

```
   компонента 1        компонента 2      компонента 3

     (A)───(B)            (E)───(F)          (H)
      │                    │
     (C)───(D)            (G)
```

В связном графе ровно одна компонента связности.

Для **ориентированных** графов понятие расщепляется на два:

- **слабая связность** - граф связен, если забыть про направление ребер;
- **сильная связность** - из каждой вершины достижима каждая.

Алгоритм поиска компонент из [раздела 6.4](dfs.md#64-связность-неориентированного-графа)
работает только для неориентированных графов; для сильных компонент нужны более
сложные алгоритмы.

---

### 6.1.4 Плотность графа

**Полный граф** - граф, в котором ребро есть между каждой парой вершин.
В неориентированном полном графе `|E| = |V|·(|V| − 1) / 2`, то есть
`|E| = Θ(|V|²)`.

Это верхняя граница: в простом графе не может быть больше ребер.

- **Плотный граф** - ребер близко к максимуму, `|E| ≈ |V|²`.
- **Разреженный граф** - ребер мало, `|E| ≈ |V|`.

Дерево - предельно разреженный связный граф: в нем ровно `|V| − 1` ребер.

Плотность определяет и способ хранения, и оценки сложности:

```
разреженный                                            плотный
|E| = Θ(|V|)                                     |E| = Θ(|V|²)
    │                                                     │
    ├── списки смежности                матрица смежности ─┤
    ├── Дейкстра на куче: Θ(|E|·log|V|)   Дейкстра на массиве: Θ(|V|²)
```

Запись `O(|E|) = O(|V|²)` формально верна для любого графа, но для разреженного
она сильно завышает оценку. Поэтому сложность алгоритмов на графах принято
записывать через оба параметра - `O(|V| + |E|)`, а не сворачивать к одному.
