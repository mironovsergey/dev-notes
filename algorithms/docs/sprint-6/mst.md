## 6.7 Минимальное остовное дерево

**Остов** (остовное дерево, spanning tree) - подграф связного неориентированного
графа, который содержит **все** его вершины и является деревом, то есть связен и
не содержит циклов.

В остове ровно `|V| − 1` ребер: меньше не хватит для связности, больше - появится
цикл.

**Минимальное остовное дерево** (minimum spanning tree, MST) - остов наименьшего
суммарного веса ребер.

```
   Граф:                        Одно из остовных деревьев:

     (1)──2──(2)                   (1)──2──(2)
      │  ╲    │                     │       │
      6   3   5                     6       5
      │     ╲ │                     │       │
     (3)──8──(4)                   (3)     (4)

   вес остова = 2 + 6 + 5 = 13     минимальный остов: 2 + 3 + 5 = 10
```

Задача возникает всюду, где нужно связать объекты минимальной ценой: прокладка
сети, водопровода, дорог.

MST существует тогда и только тогда, когда граф **связен**. Для несвязного графа
говорят о минимальном остовном **лесе** - по дереву на компоненту.

### Свойство разреза

Оба алгоритма опираются на одно утверждение.

**Разрез** - разбиение вершин на два непустых непересекающихся множества.
Ребро **пересекает** разрез, если его концы лежат в разных множествах.

> **Свойство разреза.** Для любого разреза минимальное по весу ребро,
> пересекающее его, входит в некоторое минимальное остовное дерево.

Доказательство от противного: пусть `e` - минимальное ребро разреза, и есть MST
`T`, не содержащий `e`. Добавим `e` к `T` - образуется цикл, который обязан
пересекать разрез еще раз, каким-то ребром `f`. Тогда `weight(f) ≥ weight(e)`.
Заменив `f` на `e`, получим остов не большего веса. Значит, MST с `e`
существует.

Оба алгоритма - жадные, и оба применяют это свойство, только разрезы выбирают
по-разному.

### 6.7.1 Алгоритм Прима

**Идея.** Растить одно дерево от произвольной вершины, каждый раз присоединяя
самое дешевое ребро, ведущее наружу.

Разрез здесь - «вершины дерева» против «всех остальных».

Алгоритм:

1. взять произвольную вершину, объявить ее деревом;
2. среди ребер, выходящих из дерева наружу, выбрать минимальное по весу;
3. добавить это ребро и его внешний конец в дерево;
4. повторять, пока в дереве не окажутся все `|V|` вершин.

```
   Шаг 0: дерево = {1}          Шаг 1: добавили ребро 1-2 (вес 2)

     (1)  2   2                    (1)══2══(2)
      ║  ╲    │                     ║  ╲    │
      6   3   5                     6   3   5
      ║     ╲ │                     ║     ╲ │
      3   8   4                      3   8  (4)

   Шаг 2: из {1,2} наружу ведут ребра 1-3 (6), 1-4 (3), 2-4 (5).
          Минимум - 1-4 весом 3.

   Шаг 3: из {1,2,4} наружу ведут 1-3 (6) и 4-3 (8). Минимум - 1-3 весом 6.
          Итог: 2 + 3 + 6 = 11.
```

```js
/**
 * Строит минимальное остовное дерево алгоритмом Прима.
 *
 * Дерево растет от стартовой вершины: на каждом шаге присоединяется самое
 * дешевое ребро, ведущее из дерева наружу. Куча хранит ребра-кандидаты, а
 * признак inTree отбрасывает те из них, чей внешний конец уже присоединен.
 *
 * Время: O(|E|·log|E|). Память: O(|E|).
 *
 * @param {Array<Array<{to: number, weight: number}>>} adjacency Списки
 *   смежности неориентированного графа.
 * @param {number} n Количество вершин.
 * @returns {{weight: number, edges: Array<[number, number, number]>}|null}
 *   Суммарный вес и ребра остова либо null, если граф несвязный.
 */
function prim(adjacency, n) {
  const inTree = new Array(n + 1).fill(false);
  const edges = [];
  let weight = 0;

  // Куча на минимум: [null, [вес, from, to], …]
  const heap = [null];

  inTree[1] = true;

  for (const edge of adjacency[1]) {
    heapAdd(heap, [edge.weight, 1, edge.to]);
  }

  while (heap.length > 1 && edges.length < n - 1) {
    const [edgeWeight, from, to] = popMin(heap);

    // Ребро внутрь дерева цикла не дает пользы и отбрасывается
    if (inTree[to]) {
      continue;
    }

    inTree[to] = true;
    weight += edgeWeight;
    edges.push([from, to, edgeWeight]);

    for (const edge of adjacency[to]) {
      if (!inTree[edge.to]) {
        heapAdd(heap, [edge.weight, to, edge.to]);
      }
    }
  }

  return edges.length === n - 1 ? { weight, edges } : null;
}
```

**Сложность.** Каждое ребро попадает в кучу не более двух раз (по разу с каждого
конца), операции с кучей стоят `O(log|E|)`, итого `O(|E|·log|E|)`. Поскольку
`|E| ≤ |V|²`, это то же самое, что `O(|E|·log|V|)`.

Наивная версия, ищущая минимальное ребро перебором массива кандидатов, работает
за `O(|V|·|E|)` - на каждом из `|V| − 1` шагов просматриваются все кандидаты.

### 6.7.2 Алгоритм Крускала

**Идея.** Не растить одно дерево, а рассматривать ребра **по возрастанию веса**
и добавлять каждое, если оно не образует цикл. Растет лес, который постепенно
сливается в одно дерево.

Разрез здесь - компонента, которой принадлежит один конец ребра, против всего
остального.

```
   Ребра по возрастанию: 1-2 (2), 1-4 (3), 2-4 (5), 1-3 (6), 3-4 (8)

   1-2 (2): концы в разных компонентах  →  берем   {1,2} {3} {4}
   1-4 (3): концы в разных компонентах  →  берем   {1,2,4} {3}
   2-4 (5): оба конца в {1,2,4}         →  цикл, пропускаем
   1-3 (6): концы в разных компонентах  →  берем   {1,2,3,4}
   3-4 (8): ребер уже |V| − 1           →  останавливаемся

   Итог: 2 + 3 + 6 = 11 - тот же вес, что у Прима.
```

Ключевой вопрос - как быстро проверять, лежат ли концы ребра в одной
компоненте. Для этого нужна структура **системы непересекающихся множеств**
(disjoint set union, DSU).

#### Система непересекающихся множеств

DSU хранит разбиение элементов на множества и поддерживает две операции:

- `find(x)` - вернуть представителя множества, содержащего `x`;
- `union(x, y)` - объединить множества, содержащие `x` и `y`.

Множество представляется деревом, корень которого и есть представитель.

```js
class DisjointSet {
  /**
   * @param {number} n Количество элементов, нумерация с единицы.
   */
  constructor(n) {
    this.parent = Array.from({ length: n + 1 }, (_, i) => i);
    // Ранг - верхняя оценка высоты дерева
    this.rank = new Array(n + 1).fill(0);
  }

  /**
   * Возвращает представителя множества, содержащего элемент.
   *
   * Применяется сжатие путей: все вершины на пути к корню переподвешиваются
   * прямо к нему, поэтому повторные вызовы обходятся почти бесплатно.
   *
   * Время: O(α(n)) амортизированно.
   *
   * @param {number} x Элемент.
   * @returns {number} Представитель множества.
   */
  find(x) {
    let root = x;

    while (this.parent[root] !== root) {
      root = this.parent[root];
    }

    // Второй проход выполняет сжатие путей
    let current = x;

    while (this.parent[current] !== root) {
      const next = this.parent[current];

      this.parent[current] = root;
      current = next;
    }

    return root;
  }

  /**
   * Объединяет множества, содержащие два элемента.
   *
   * Меньшее по рангу дерево подвешивается к большему: это удерживает высоту
   * логарифмической и не дает вырождения в цепочку.
   *
   * Время: O(α(n)) амортизированно.
   *
   * @param {number} x Первый элемент.
   * @param {number} y Второй элемент.
   * @returns {boolean} false, если элементы уже были в одном множестве.
   */
  union(x, y) {
    const rootX = this.find(x);
    const rootY = this.find(y);

    if (rootX === rootY) {
      return false;
    }

    if (this.rank[rootX] < this.rank[rootY]) {
      this.parent[rootX] = rootY;
    } else if (this.rank[rootX] > this.rank[rootY]) {
      this.parent[rootY] = rootX;
    } else {
      this.parent[rootY] = rootX;
      this.rank[rootX]++;
    }

    return true;
  }
}
```

Два приема - **сжатие путей** и **объединение по рангу** - вместе дают
[амортизированную сложность](../sprint-1/complexity.md#амортизированная-сложность)
`O(α(n))`, где `α` - обратная функция Аккермана. Она растет настолько медленно,
что для любых `n`, помещающихся в память, `α(n) ≤ 4`. Практически это
константа.

#### Сам алгоритм

```js
/**
 * Строит минимальное остовное дерево алгоритмом Крускала.
 *
 * Ребра рассматриваются по возрастанию веса; ребро добавляется, если его концы
 * лежат в разных компонентах. Проверка выполняется системой непересекающихся
 * множеств.
 *
 * Время: O(|E|·log|E|) - доминирует сортировка ребер. Память: O(|V| + |E|).
 *
 * @param {Array<[number, number, number]>} edges Ребра в виде [u, v, weight].
 * @param {number} n Количество вершин.
 * @returns {{weight: number, edges: Array<[number, number, number]>}|null}
 *   Суммарный вес и ребра остова либо null, если граф несвязный.
 */
function kruskal(edges, n) {
  const sorted = [...edges].sort((a, b) => a[2] - b[2]);
  const disjointSet = new DisjointSet(n);
  const result = [];
  let weight = 0;

  for (const [u, v, edgeWeight] of sorted) {
    if (result.length === n - 1) {
      break;
    }

    if (disjointSet.union(u, v)) {
      result.push([u, v, edgeWeight]);
      weight += edgeWeight;
    }
  }

  return result.length === n - 1 ? { weight, edges: result } : null;
}
```

Петли отбрасываются автоматически: у петли оба конца в одной компоненте, и
`union` вернет `false`. Кратные ребра тоже не мешают - лишнее будет отброшено
как образующее цикл.

#### Прим или Крускал

| | Прим | Крускал |
| --- | --- | --- |
| Растет | одно дерево | лес из многих деревьев |
| Представление графа | списки смежности | **список ребер** |
| Вспомогательная структура | приоритетная очередь | система непересекающихся множеств |
| Время | `O(\|E\|·log\|V\|)` | `O(\|E\|·log\|E\|)` |
| Несвязный граф | найдет дерево одной компоненты | **сразу строит остовный лес** |

Асимптотика совпадает. На практике:

- **плотный граф** - Прим, особенно в версии на массиве с `O(|V|²)`;
- **разреженный граф или ребра уже отсортированы** - Крускал; если сортировать
  не нужно, он работает практически за `O(|E|·α(|V|))`.

Максимальное остовное дерево строится теми же алгоритмами с обратным порядком
сравнения: у Крускала ребра сортируются по убыванию, у Прима куча становится
кучей на максимум.
