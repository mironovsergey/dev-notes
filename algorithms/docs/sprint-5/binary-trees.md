## 5.1 Бинарные деревья

**Дерево** - связная совокупность вершин и ребер без циклов, в которой у каждой
вершины не более одного родителя.

### Терминология

- **Вершина** (узел, нода) - объект, хранящий данные и ссылки на другие
  вершины.
- **Ребро** - направленная связь между двумя вершинами. Направление задает
  иерархию: одна вершина выше, другая ниже.
- **Корень** - единственная вершина без родителя.
- **Лист** - вершина без детей.
- **Путь** - последовательность вершин, соединенных ребрами. Поскольку ребра
  направлены, путь идет только сверху вниз.
- **Предки** вершины `X` - все вершины на пути от корня до `X`. Ближайший
  предок - родитель.
- **Потомки** вершины `Y` - все вершины, до которых есть путь от `Y`.
- **Братья** (siblings) - вершины с общим родителем.

```
                  (8)          ← корень
                 /   \
              (3)     (10)
             /   \       \
          (1)    (6)     (14)  ← лист
                /   \
             (4)    (7)        ← братья
```

Здесь предки вершины `4` - это `6`, `3`, `8`; потомки вершины `3` - `1`, `6`,
`4`, `7`.

### Высота и глубина

**Высота** дерева - количество вершин в самом длинном пути от корня до листа.

Соглашение принципиально: при таком определении высота одиночной вершины равна
`1`, а высота пустого дерева - `0`. Существует и второе, столь же
распространенное соглашение - считать ребра, тогда одиночная вершина имеет
высоту `0`. Формулы в этих двух системах различаются на единицу, поэтому нужно
всегда знать, какая используется.

**Здесь и далее высота измеряется в вершинах**: `height(null) = 0`,
`height(лист) = 1`. Именно эта система принята в
[коде АВЛ-дерева](balanced.md#542-балансировка-авл-дерева).

**Глубина** вершины - длина пути от корня до нее. Корень имеет глубину `0`.

### Арность

Если максимальное число детей ограничено числом `k`, дерево называется
`k`-арным. **Бинарное** (двоичное) дерево - дерево, у которого не более двух
детей у каждой вершины, и эти дети различимы: левый и правый.

Различимость важна. Дерево, у которого единственный ребенок - левый, и дерево,
у которого он правый, - это **разные** бинарные деревья, хотя как обычные
деревья они изоморфны.

```js
/**
 * Узел дерева произвольной арности.
 */
class TreeNode {
  /**
   * @param {*} value Значение узла.
   * @param {TreeNode[]} children Дочерние узлы.
   */
  constructor(value, children = []) {
    this.value = value;
    this.children = children;
  }
}

/**
 * Узел бинарного дерева.
 */
class BinaryNode {
  /**
   * @param {*} value Значение узла.
   * @param {BinaryNode|null} left Левый потомок.
   * @param {BinaryNode|null} right Правый потомок.
   */
  constructor(value, left = null, right = null) {
    this.value = value;
    this.left = left;
    this.right = right;
  }
}
```

### Базовые операции

Почти все, что делают с деревьями, - это рекурсия по определению структуры:
обработать вершину и рекурсивно спуститься в поддеревья. Пустое поддерево -
базовый случай.

```js
/**
 * Возвращает высоту дерева в вершинах.
 *
 * Время: O(n). Память: O(h) на кадры стека вызовов.
 *
 * @param {BinaryNode|null} root Корень дерева.
 * @returns {number} Высота: 0 для пустого дерева, 1 для одиночной вершины.
 */
function height(root) {
  if (root === null) {
    return 0;
  }

  return 1 + Math.max(height(root.left), height(root.right));
}

/**
 * Возвращает количество вершин в дереве.
 *
 * Время: O(n). Память: O(h).
 *
 * @param {BinaryNode|null} root Корень дерева.
 * @returns {number} Количество вершин.
 */
function size(root) {
  if (root === null) {
    return 0;
  }

  return 1 + size(root.left) + size(root.right);
}
```

Глубина рекурсии равна высоте дерева. Для сбалансированного дерева это
`O(log n)` и совершенно безопасно; для вырожденного - `O(n)`, и при `n = 10⁵`
[стек переполнится](../sprint-2/stack-and-queue.md#применение-стек-вызовов).

### Полные и почти полные деревья

**Полное** дерево - все листья расположены на одной глубине, и у каждой
не-листовой вершины ровно два ребенка. В полном дереве высоты `h` ровно
`2ʰ − 1` вершин.

**Почти полное** дерево - все уровни заполнены полностью, кроме, возможно,
последнего, который заполняется слева направо без пропусков.

```
Полное (h = 3, 7 вершин):        Почти полное:

        (·)                            (·)
       /   \                          /   \
    (·)     (·)                    (·)     (·)
   /   \   /   \                  /   \   /
 (·)  (·) (·)  (·)              (·)  (·) (·)
```

Почти полнота - ключевое свойство для
[представления дерева массивом](priority-queue.md#551-дерево-на-массиве): без
дыр в структуре массив расходуется без пропусков.

### Формат представления в задачах

Деревья в задачах курса задаются так:

- первая строка - число вершин `N`;
- следующие `N` строк - описания вершин в формате
  `<id> <значение> <id левого потомка> <id правого потомка>`;
- значение `-1` вместо `id` потомка означает его отсутствие.
