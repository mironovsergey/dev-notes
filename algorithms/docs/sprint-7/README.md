# 7 Жадные алгоритмы и динамическое программирование

Конспект седьмого спринта: два подхода к задачам оптимизации. Жадный строит
ответ, принимая на каждом шаге лучшее решение сиюминутно; динамическое
программирование строит ответ из решений меньших подзадач.

Спринт отвечает на три вопроса: когда жадность дает верный ответ, что делать,
когда не дает, и как из перебора получить динамическое программирование.
