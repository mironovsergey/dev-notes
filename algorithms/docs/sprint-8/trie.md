## 8.6 Префиксное дерево

**Префиксное дерево** (trie, бор) - дерево для хранения набора строк, в котором
общие префиксы хранятся один раз.

Каждое слово задает путь от корня; ребра пути помечены символами слова.

```
   Набор слов: cat, car, card, dog

                    (корень)
                    /       \
                   c         d
                  /           \
                (·)           (·)
                 |             |
                 a             o
                 |             |
                (·)           (·)
                /   \          |
               t     r         g
              /       \         \
           [cat]    [car]      [dog]
                       \
                        d
                         \
                        [card]

   [x] - терминальный узел: здесь заканчивается слово
   (·) - промежуточный узел: это лишь префикс
```

Два вида узлов:

- **терминальные** - соответствуют словам, добавленным в бор;
- **промежуточные** - не соответствуют словам, но являются префиксами.

Терминальный узел не обязан быть листом: слово `car` заканчивается в узле, из
которого путь продолжается к `card`.

### Как хранить переходы

От выбора зависит и скорость, и расход памяти.

| Способ | Переход по символу | Память на узел |
| --- | --- | --- |
| Список ребер | `O(\|Σ\|)` - перебор списка | по числу реальных детей |
| Сбалансированное дерево поиска | `O(log \|Σ\|)` | по числу реальных детей |
| Хеш-таблица | `O(1)` в среднем | по числу реальных детей |
| Массив длины `\|Σ\|` | **`O(1)`** гарантированно | `\|Σ\|` ячеек всегда |

Массив переходов быстрее всех, но при большом алфавите расходует память даже на
узлы с одним ребенком. Для латиницы (`|Σ| = 26`) это приемлемо; для Unicode -
нет.

Ниже используется хеш-таблица (`Map`): она дает `O(1)` в среднем и не зависит
от размера алфавита.

### Реализация

```js
class TrieNode {
  constructor() {
    // Переходы по символам: символ -> дочерний узел
    this.children = new Map();
    this.isTerminal = false;
  }
}

class Trie {
  constructor() {
    this.root = new TrieNode();
  }

  /**
   * Добавляет слово в бор.
   *
   * Общий префикс с уже добавленными словами переиспользуется: новые узлы
   * создаются только начиная с первого различающегося символа.
   *
   * Время: O(|word|). Память: O(|word|) в худшем случае.
   *
   * @param {string} word Добавляемое слово.
   * @returns {void}
   */
  add(word) {
    let node = this.root;

    for (const symbol of word) {
      let next = node.children.get(symbol);

      if (next === undefined) {
        next = new TrieNode();
        node.children.set(symbol, next);
      }

      node = next;
    }

    node.isTerminal = true;
  }

  /**
   * Возвращает узел, соответствующий заданному пути по символам.
   *
   * Время: O(|prefix|). Память: O(1).
   *
   * @param {string} prefix Путь по символам.
   * @returns {TrieNode|null} Узел либо null, если такого пути нет.
   */
  findNode(prefix) {
    let node = this.root;

    for (const symbol of prefix) {
      node = node.children.get(symbol);

      if (node === undefined) {
        return null;
      }
    }

    return node;
  }

  /**
   * Проверяет, содержится ли слово в боре целиком.
   *
   * Существования пути недостаточно: узел должен быть терминальным, иначе
   * слово является лишь префиксом какого-то другого.
   *
   * Время: O(|word|). Память: O(1).
   *
   * @param {string} word Проверяемое слово.
   * @returns {boolean} true, если слово было добавлено в бор.
   */
  has(word) {
    const node = this.findNode(word);

    return node !== null && node.isTerminal;
  }

  /**
   * Проверяет, есть ли в боре слово с заданным префиксом.
   *
   * Время: O(|prefix|). Память: O(1).
   *
   * @param {string} prefix Проверяемый префикс.
   * @returns {boolean} true, если хотя бы одно слово начинается с префикса.
   */
  hasPrefix(prefix) {
    return this.findNode(prefix) !== null;
  }
}
```

Различие `has` и `hasPrefix` - в одной проверке `isTerminal`, и именно ради
этого поля бор и хранит признак терминальности. Без него нельзя отличить слово
`«car»`, реально добавленное в бор, от префикса слова `«card»`.

Построение бора из набора слов стоит `O(L)`, где `L` - суммарная длина слов.

### Поиск любого из шаблонов

Бор решает задачу, для которой одного КМП мало: найти в тексте вхождение
**любого** из набора шаблонов.

```js
/**
 * Возвращает позицию первого вхождения любого из шаблонов в текст.
 *
 * Для каждой стартовой позиции текста выполняется спуск по бору: он
 * одновременно проверяет все шаблоны, у которых совпадает текущий префикс.
 *
 * Время: O(t·m), где t - длина текста, m - длина наибольшего шаблона.
 * Память: O(L) на бор, где L - суммарная длина шаблонов.
 *
 * @param {string} text Текст, в котором выполняется поиск.
 * @param {string[]} patterns Набор шаблонов.
 * @returns {number} Позиция вхождения либо -1, если ни один не найден.
 */
function findAny(text, patterns) {
  const trie = new Trie();

  for (const pattern of patterns) {
    trie.add(pattern);
  }

  for (let pos = 0; pos < text.length; pos++) {
    let node = trie.root;

    for (let offset = 0; pos + offset < text.length; offset++) {
      node = node.children.get(text[pos + offset]);

      if (node === undefined) {
        break;
      }

      if (node.isTerminal) {
        return pos;
      }
    }
  }

  return -1;
}
```

Выигрыш в том, что один спуск по бору проверяет **сразу все** шаблоны с общим
префиксом: перебирать их по одному не требуется.

Оценка `O(t·m)` все же квадратична по длине шаблона. Убрать этот множитель
позволяет алгоритм Ахо - Корасик: он достраивает бор суффиксными ссылками -
тем же приемом отката, что и в [префикс-функции](prefix-function.md#84-префикс-функция),
- и находит все вхождения всех шаблонов за `O(t + L)`.

### Бор или хеш-таблица

| | Бор | Хеш-таблица |
| --- | --- | --- |
| Проверка наличия слова | `O(\|word\|)` | `O(\|word\|)` на хеш |
| Поиск по префиксу | **`O(\|prefix\|)`** | невозможен без перебора |
| Перебор слов в лексикографическом порядке | **есть** | нет |
| Память при общих префиксах | **экономнее** | хранит слова целиком |
| Память при непохожих словах | накладные расходы на узлы | компактнее |

Хеш-таблица отвечает только на вопрос «есть ли такое слово». Бор отвечает и на
вопрос «есть ли слова, начинающиеся так» - на этом строятся автодополнение,
`T9`, словарные проверки и маршрутизация по префиксам.

Отдельное следствие структуры:
[обход бора в глубину](../sprint-6/dfs.md#631-алгоритм-dfs) с посещением детей в
порядке возрастания символа выдает слова в
[**лексикографическом порядке**](strings.md#лексикографический-порядок), без
сортировки.
