# Алгоритмы и структуры данных

Конспект курса алгоритмов и решения задач к нему.

## Состав раздела

```
   docs/          конспект, по каталогу на спринт
   tasks/         решения тренировочных задач
   final-tasks/   решения финальных задач спринтов
   lib/io.js      общий модуль чтения стандартного ввода
```

Задача запускается напрямую, вход подается через стандартный поток:

```sh
   node algorithms/tasks/sprint-1/j.js <<< '1000000000'
```

Файлы без ввода-вывода - те, где проверяющая система вызывает функцию
самостоятельно, - содержат встроенные проверки и запускаются без аргументов:

```sh
   node algorithms/tasks/sprint-5/n.js      # n.js: OK
```

## Сквозные темы

Некоторые идеи проходят через весь курс и разобраны в нескольких местах.

**Амортизированный анализ.** Введен при разборе
[динамического массива](docs/sprint-1/complexity.md#амортизированная-сложность),
затем применяется к [реаллокации](docs/sprint-2/arrays.md#212-реаллокация-в-динамических-массивах),
[очереди на двух стеках](docs/sprint-2/stack-and-queue.md#244-очередь-на-двух-стеках),
[монотонному стеку](docs/sprint-2/histogram.md#разбор-сложности),
[рехешированию](docs/sprint-4/collisions.md#441-изменение-размера-хеш-таблицы),
[префикс-функции](docs/sprint-8/prefix-function.md#почему-это-on) и
[системе непересекающихся множеств](docs/sprint-6/mst.md#система-непересекающихся-множеств).

**Размен памяти на время.** [Решето Эратосфена](docs/sprint-1/primes.md#182-решето-эратосфена),
[максимум в стеке за `O(1)`](docs/sprint-2/stack-and-queue.md#применение-максимум-в-стеке-за-o1),
[префиксные хеши](docs/sprint-4/string-hashing.md#хеши-подстрок-за-o1),
[размеры поддеревьев](docs/sprint-5/kth-statistic.md#571-вспомогательные-данные-о-дереве),
[мемоизация](docs/sprint-7/dynamic.md#от-перебора-к-динамике).

**Глубина рекурсии.** Ограничение стека вызовов впервые разобрано
[при изучении стека](docs/sprint-2/stack-and-queue.md#применение-стек-вызовов) и
дальше определяет выбор реализации в
[рекурсии](docs/sprint-3/recursion.md#хвостовая-рекурсия-и-почему-на-практике-пишут-цикл),
[быстрой сортировке](docs/sprint-3/sorting.md#глубина-рекурсии),
[обходах дерева](docs/sprint-5/traversal.md#обход-без-рекурсии) и
[обходах графа](docs/sprint-6/dfs.md#632-алгоритм-dfs-без-рекурсии).

**Отсечение перебора.** [Перебор с возвратом](docs/sprint-3/recursion.md#отсечение),
[поиск в интервале BST](docs/sprint-5/traversal.md#535-поиск-элементов-в-интервале),
[динамическое программирование](docs/sprint-7/dynamic.md#72-динамическое-программирование).

Чтение стандартного ввода вынесено в общий модуль [lib/io.js](lib/io.js):

```js
   const { run, readInt, readArray } = require('../../lib/io');

   function solve() {
     const n = readInt();
     const numbers = readArray();
     process.stdout.write(`${n + numbers.length}`);
   }

   run(solve);
```
